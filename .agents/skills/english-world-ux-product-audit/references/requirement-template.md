## 单条发现

每条发现使用以下完整结构：

```markdown
## EW-UX-001 标题

- 用户目标：
- 复现步骤：
- 当前结果：
- 预期结果：
- 证据：
  - 浏览器观察：
  - 代码/规格：
- 证据类型：浏览器观察 / 代码证据 / 规格事实 / 推断 / 待验证
- 根因：
- 严重度：P0 / P1 / P2 / P3
- 置信度：高 / 中 / 低
- 用户影响：
- 产品影响：
- 发生范围或频率：
- 推荐需求：
- 验收标准：
  - Given ...
  - When ...
  - Then ...
- 端范围：桌面 / 移动 / 两端 / 后台
- 依赖：
- 非目标：
```

要求：

- 标题描述用户问题，不写“优化页面”“提升体验”等空话。
- 验收标准必须可由测试或浏览器步骤判定，避免“更清晰”“更美观”。
- 推荐需求描述能力和约束，不提前指定组件、颜色或实现方案，除非证据要求。
- 同一根因只保留一条主需求，在影响范围中列出受影响页面。
