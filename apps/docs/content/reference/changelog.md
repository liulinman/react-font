## 2026-10-26：已有交付基线

MCP 相关实现提供 Streamable HTTP 入口、独立 Bearer 授权和按账号隔离的词库工具。授权管理可以查看连接信息、创建授权、查看有效期与最近使用、撤销授权以及读取最近访问摘要。完整密钥只在创建时显示。对应前端入口为 `apps/english-world/src/page/englishWorld/component/McpAccessCard.tsx`；后端入口为 `src/interface/mcp-access/mcp.controller.ts`、`mcp.service.ts` 与 `mcp-security.ts`。

工具侧已有查询、读取、新增、预览覆盖与确认覆盖、预览删除与确认删除。覆盖复用 `src/interface/english/safe-overwrite.ts` 的空值保护，预览与确认之间检查词条是否变化，并用请求 ID 保存幂等结果。这些是 English World 的实现规则，并非 MCP 协议对所有产品的统一要求。

同日交付背景还包括 HTTPS 访问入口与设置整理。本文不公开服务器参数、证书位置或部署账号，也不根据日期推断所有客户端兼容性。连接地址应始终取平台当前展示的信息，而不是从历史记录复制某台机器的地址。

## 文档中心：本次内容范围

本批文章围绕概念、连接、查询实现、安全写入、客户端接入和参数参考展开。查询文章引用经过审核并纳入文档构建的源码片段，维护时需要显式同步，不能假定兄弟仓库改动会自动更新公开网站。发布后读者应能从概念一路走到参数、失败原因与验证方法，不必读取私有需求文档。

例如核对查询变化时，可以比较以下教学参数与返回形状：

```json
{
  "input": { "keyword": "learn", "limit": 5, "offset": 0 },
  "outputShape": { "items": [], "total": 0, "limit": 5, "offset": 0 }
}
```

这是形状说明，不是本次真实查询结果。若未来接口改为其他字段，维护者需要同时更新工具参考、源码片段、实例和对应验证，不应只把更新时间改成当天。
