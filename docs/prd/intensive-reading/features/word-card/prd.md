# 精读词库浮动卡片

状态：用户授权实现，常规细节由实现者决定；2026-11-03。

## 背景与范围
电脑端学生在文章精读中点击单词，直接复习个人词库已经保存的内容，避免离开文章。用户要求弹窗卡片可自由拖拽。已有高亮编辑、选区标注、正文和笔记保持原业务语义。初始范围不增加自动收词、AI释义或移动端；r04按用户明确追加纳入手动查询语境释义与确认收词，仍不自动收词。2026-11-03用户后续明确要求先使用AI找原型再查询，词形识别纳入本轮。

## 功能需求
- FR-01：正文单词可点击查看本人词库内容；高亮引用也可查看，同时保留原笔记编辑。支持选区工具“查看词库”，用于短语及键盘操作。
- FR-02：已收集内容显示实际保存的拼写、音标、词性、释义和笔记；缺失字段如实提示，不生成资料。单词先按FR-06通过AI确定词典原型，再按忽略大小写的完整原型拼写查询本人词库；短语/句子沿用完整原文查询。不将子串、近义词或同根派生词冒充已收集。
- FR-03：无背景遮罩的单个卡片，可通过标题栏拖拽；切换查询保持拖动位置，滚动正文保持打开。窗口缩小时卡片保持可见，长笔记内部滚动。支持键盘方向键移动、Escape/按钮关闭及关闭后焦点恢复。
- FR-04：加载、未收集、失败及重试状态可区分；快速切换仅显示最新查询。只读查询不更新词库、精读正文或笔记。
- FR-05：服务端按登录用户隔离，未知和他人词均返回未收集；不返回他人字段。

- FR-06：点击英文单词后，先由现有AI服务结合该处原句识别词典原型，再查本人词库。复数、第三人称单数、过去式/分词、比较级等均适用，包括不规则变化；base保持原词，不把派生词改成同义或同根词。词形与原型的对应关系清楚可见。
- FR-07：原型不确定时明确提示，不把不确定或AI失败当作未收集；网络、限额、供应商错误可重试。复用现有服务配置、并发/预算/鉴权；不修改真实配额。短时仅缓存原型（含用户及语境），不缓存个人词条内容；同词不同语境重新判定。AI统计与用量记录不属于词库或精读笔记写入。

- FR-08：已匹配词条的卡片音标旁提供发音按钮，点击后沿用词库现有语音服务，按本人词条ID播放匹配原型的发音；不自动播放。加载与失败重试沿用现有组件。无已匹配词条时不提供词条发音入口。

## 验收
- AC-01：点击已收集词及高亮词，展示本人的真实词条内容，原高亮笔记仍可编辑；未收集词不显示子串匹配内容。
- AC-02：拖动到页面其他位置、切换单词、滚动及调整窗口后卡片仍可操作；长文不溢出。
- AC-03：失败可重试，连续点击不会回显旧词；关闭后迟到响应不会重开卡片；可键盘打开/移动/关闭。
- AC-04：两账号相同及独有词查询隔离，查询前后业务数据不改变。

- AC-05：词库仅有sprawl时，正文sprawls经真实AI识别后可查到该词；显示sprawls→sprawl，原文及笔记保持。went→go、saw在名词/动词语境下分辨，派生词保持本身。
- AC-06：AI不确定、错误、格式异常均不显示“未收集”；重试可恢复；连续同词去重，换语境及换账号隔离；原型查询不直接提供释义或读取其他用户词条；r04的显式“查询本句含义”单独提供语境释义。

- AC-07：正文sprawls匹配sprawl后，点击发音调用已有speech/word接口，传入sprawl的本人词条ID；卡片仍保持打开。失败后显示明确重试入口，用户点击才显式重试；未匹配/不确定状态不显示词条播放按钮。

## 来源与决定
用户截图及“弹窗卡片，位置可以拖拽…已经收集的单词”；用户随后“现在使用我们skill帮我实现”。词库解释为前一轮建议的默认实施方向，非额外确认；若实际意指精读笔记，保留标注编辑便于兼容。大小写、边界限制及单卡片为实现者决定。

2026-11-03后续用户截图sprawls未命中，明确指示“首先，应该找到这个的单词原型在匹配，使用AI帮我找到，然后再查询”，修订原FR02精确表层拼写决定；其余FR01/03–05及AC01–04继续适用。当前修订开发和验证，沿用同功能发布授权。

2026-11-03 r03：用户指出“发音没有加进来”，补充复用词库语音组件及原型词条ID的播放入口，沿用本功能发布授权。

## r04 未收集词的语境释义与确认收词

- **FR-09**：词库未命中时，可点击“查询本句含义”，使用现有AI结合实际点击处原句确认原型并解释该处中文含义；区分原文词、原型、本句含义与用法，标明AI参考。确定性不足或语境缺失时不编造释义，不展示可添加结果；原型查询本身仍只读，不自动额外生成释义。
- **FR-10**：AI预览只在用户点击“添加到词库”后写入本人词库，保存原型拼写、本句简义，并将原文词、原型、语境及用法作为词条笔记，供复习使用。成功后显示真实已保存词条及现有发音入口。不覆盖已存在词条、笔记或学习记录；重复点击、响应丢失后重试和另一窗口先添加时不重复创建。
- **FR-11**：生成和添加分别有等待/失败/重试状态；切词/换语境/关闭不回显旧结果，旧添加响应不能写到新词卡。确认仅接受当前用户的有效服务端预览，过期/他人/伪造预览不能收词；过期可重新查询。复用预算/并发/配置，不新设供应商或调整真实额度。
- **AC-08**：正文sprawls且本人词库无sprawl，查询可见sprawls→sprawl与该句“蔓延”等含义、语境和用法；在查询/预览阶段词库数量不变。saw不同语境依实际点击处解释；派生词不改同根词。真实AI结果另留证据，供应商替身不证明真实语义质量。
- **AC-09**：点击添加仅新增本人sprawl，简义/语境笔记正确，表层sprawls不另建；成功后可发音。重复/并发/丢响应重试只保留一条；另一窗口已有词时保留其全部字段和学习记录。
- **AC-10**：生成/添加失败可重试；切词与关闭忽略迟到结果，后确认的旧词可以完成写入但不得覆盖新卡片。无语境、不确定、无效AI输出、过期/伪造/他人预览不写词库；匿名接口拒绝。

来源：本轮用户明确追加。局部沿用现有卡片样式与按钮，采用“查询预览→确认添加”，不引入整页新设计。已收集词仍优先显示原词库真实资料。

## r05 单词点击与未收集词完整资料（2026-11-04 用户追加）

以下修订FR-01/02/08/09及AC-06/07/08中与自动释义和缺词发音冲突的部分，其余条款继续有效。来源为本轮两张截图和用户要求：已标注句子点击时查所点单词；没有加入词库也展示原型、词性、中文含义、文中含义、音标与点击播放。

- **FR-12**：点击已标注句子内单词时，只传该词及其实际出现处语境进行查词，不传整个标注句子；保留标注编辑与选择文本能力。显式选区查询仍可用于短语。
- **FR-13**：未收集词有原句语境且原型可靠时自动生成资料预览，区分通用中文释义与本句含义，显示原型、词性、音标及点击播放入口。资料标明AI参考；缺失/不可靠结果提示失败和重试，不编造资料。不自动加入词库。
- **FR-14**：未收集词发音使用已识别原型文本复用现有语音服务，不虚构词条ID；已收集词继续按本人词条ID发音。确认添加时保存音标、词性、通用中文释义，并在笔记保留本句含义和语境，不覆盖已有词。
- **AC-11**：给定整句蓝色高亮，鼠标点击或键盘打开其中linguists，只查询linguists且语境目标位置正确；原句笔记仍可打开，原文和偏移不变。
- **AC-12**：给定未收集biologist，点击后无需再次查询即可加载原型、词性、音标、中文释义与文中含义；点击才播放发音，预览不写词库。生成失败能重试，切词/关闭丢弃迟到展示。
- **AC-13**：确认添加保存原型和预览资料，语境意义进入笔记；重试/已有词保护继续满足AC-09/10。真实AI与音频质量需真实服务验证，替身测试不代表真实服务验收。

## r06 推理上下文与引用原句分离（2026-11-04 用户追加）

来源：用户截图指出语境不应显示一段，并明确“可以结合段中意思推理，但是只展示这一句话”。

- **FR-15**：AI可使用点击处周围段落信息推断词义；词卡展示的原文语境和新确认收词笔记中的原文语境，只保留点击词所在完整句子，保持原文措辞、标点和引号。展示句不由AI改写；原文与标注偏移不变。超出接口限制的长句明确失败，不截半句伪装完整。
- **FR-16**：已有自动生成词条笔记中的长语境在词卡只展示对应单句，不自动覆盖保存内容；普通手写笔记不裁剪。无法确定旧语境中同词多次出现的实际句子时如实提示，不随意选择一处。
- **AC-14**：给定前后各一句的段落，点击中间句indigenous时，AI请求保留邻近语境，而预览及新收词保存的context只有中间完整句；常见称谓缩写、引号、小数和同词不同出现位置均有检查。
- **AC-15**：旧机器生成语境块中只有一次目标词时展示其所在句，其他笔记字段保持；普通手写多句笔记完整保留；多处同词旧引用提示不能确定。此修改不批量写入旧词库。
