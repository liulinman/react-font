# 精读模块 PRD

模块 ID：`intensive-reading`；需求命名空间：`intensive-reading/intensive-reading-core`。
用户已确认电脑端交互原型与方案。本文将确认内容写成可验收要求；标为实施决定的细节由开发负责。已确认设计不表示已经开发或验收。

## 目的与范围

用户导入自己的英文材料，确认原文后进行高亮、批注和回顾。独立材料库、正文、笔记和阅读位置，不依附阅读练习、考试答卷、知识笔记或管理员发布流程。
仅电脑 Web，不新增手机入口或手机适配。第一版不含自动出题、计时评分、翻译、AI长难句分析、生词本同步、共享和笔记导出。

## 用户流程与页面

材料库 → 上传PDF/照片或粘贴文章 → 识别整理 → 原件/正文并排校对 → 确认正文 → 三栏精读 → 笔记回顾 → 下次继续。
沿用已批准原型的浅色、低字重样式。工作台左侧目录可收起，中间正文独立滚动，右侧笔记独立滚动。正式版复用现有桌面导航，独立入口名“精读”；原型中的账号、示例文章与本地保存提示不进入正式业务。

## 功能要求

### 材料导入

- FR-01：本人材料库显示标题、来源类型、处理状态、最近阅读时间，支持按标题搜索、打开与继续阅读；首次进入为空态，不自动创建示例。
- FR-02：支持粘贴文章及上传PDF、JPEG、PNG、WebP。实施决定：单文件不超过20MiB、PDF不超过20页、单次最多20文件且合计100MiB；图片最多2500万像素。前后端一致校验真实格式、大小与归属。
- FR-03：整理保留原文措辞、大小写与标点；仅处理阅读顺序、标题、段落和多余换行，不自动翻译、简写或改写。无法判断的内容标记待核对，不虚构缺失文字。
- FR-04：原文件私有保存，原件与可编辑正文并排校对；多文件显示顺序并支持开始识别前调整顺序。用户能编辑标题、修正错字、调整段落；有正文才允许确认。粘贴来源以原始输入作为对照。
- FR-05：处理阶段、失败原因和重试入口可见。刷新后恢复处理中/待校对结果；重试不重复创建材料，失败保留原文件和成功结果。文件未全部上传完成不得开始识别。不得用mock内容假装识别成功。

### 精读标注

- FR-06：正文支持选单词、短语、句子；选区工具条提供黄色重点、蓝色语言、粉色疑问和添加笔记；可调整字号、用目录定位段落。
- FR-07：笔记自动引用选区原文，可输入纯文本，分类可选词汇、语法、段意、疑问；不强制分类。笔记和高亮同时存在，编辑笔记不丢高亮。分类与颜色分别保存。
- FR-08：点击标记显示对应笔记，点击笔记引用定位原文并短暂突出；允许修改颜色、编辑笔记、删除标记。实施决定：跨段选区提示按段标注；重叠选区提示打开已有标记，第一版不创建重叠标注。
- FR-09：右侧提供全部、语言积累、待解决筛选；疑问可解决和重新打开，已解决内容仍在全部中。回顾模式清晰显示引用、笔记、分类和疑问状态，支持返回阅读。

### 保存与正文版本

- FR-10：服务端按当前用户持久保存材料、标注和阅读位置；换设备登录仍可恢复。显示保存中、已保存、保存失败和重试；失败保留本地未保存输入，不能显示成功。离开有未保存编辑时提示。
- FR-11：阅读位置保存段落ID和段内相对位置，字号及布局变化不改变标注。标注必须绑定正文版本、段落ID、字符起止及原文引用，后端核对引用一致。
- FR-12：开始精读后仍可回到校对。实施决定：确认修改时创建新正文版本，旧版本及标注可只读查看；未改段落按稳定ID及原文精确校验继承标注，变更段落的标注显示“待重新确认”，禁止静默贴到相似句子。新上传不覆盖旧材料。
- FR-13：多窗口并发写入检查版本，冲突返回明确提示且保留本地输入；不得最后写入静默覆盖。保存请求支持安全重试，旧响应不得覆盖新编辑。
- FR-14：本人才能读取/修改材料、任务、文件及笔记；不生成学生分配、通知、考试或知识笔记副本。未知与他人资源统一返回不可访问。

### 独立检查补充（实施决定）

- 文件导入先创建sourceType=file的空材料草稿，返回uploading状态和材料ID；粘贴草稿sourceType=text。两类草稿均在确认正文后进入ready。
- 语言积累按蓝色筛选；疑问状态单独用isQuestion保存。粉色创建或分类选疑问时默认开启isQuestion，改颜色不清除疑问；用户可明确取消疑问。待解决为isQuestion=true且resolved=false，允许只有高亮没有笔记的疑问。
- 标注anchorStatus取active/needs_confirmation。待确认标注显示旧引用及笔记，不绘制到新正文；用户选择新原文后点击“重新绑定”完成核对，或删除标注。重绑校验新正文版本与quote，保留笔记及疑问状态。AC-05必须覆盖该闭环。

## 验收标准

- AC-01：真实粘贴文章及真实PDF、照片分别完成上传/识别、对照校对、确认并阅读；正文不被改写，原件可查；供应商失败明确失败且可恢复。
- AC-02：黄色高亮、蓝色笔记、粉色疑问分别创建成功，刷新后保持；改颜色、改笔记、删除标记正确，其他标记不受影响。
- AC-03：三种筛选计数准确；解决后从待解决消失，全部中保留，可重新打开；点击引用能定位重复句子中被选的那一句。
- AC-04：跨段/重叠选区提示而不破坏正文；含中文、emoji及标点的偏移在前后端一致；改字号与收起目录后定位正确。
- AC-05：修改正文生成版本，未改段落保留标注，改动处待确认，旧正文及笔记可查，不产生悬空引用。
- AC-06：网络失败、刷新、重复提交、两个窗口冲突下不丢笔记、不重复创建、错误不伪装成功；重试后数据一致。
- AC-07：重新登录恢复阅读位置；两个用户无法读取彼此文件/笔记/任务，现有阅读练习与知识笔记无副作用；不改手机导航。
- AC-08：1280×800、1440×900、1920×1080桌面可用，三栏不产生页面横向溢出，工具条不出屏，正文和笔记均可独立滚动，键盘能操作标记与保存。

## 状态和实施决定

材料阶段 uploading → processing → review → ready，processing可转failed后重试；正文修订保留原ready版本至新版本确认。
限制：标题200字、正文100000字符、单条笔记10000字符。纯文本渲染，禁止把识别文字作为HTML运行。所有限制在校对前提示，不截断后假装完整。
实现与迁移方案见 [实施计划](../../superpowers/plans/2026-10-22-intensive-reading.md)。测试Case应逐条关联上述AC；真实识别未执行不得计通过。


## 2026-10-22 原文结构整理补充（用户确认）

- **FR-15**：PDF、照片与粘贴材料保留原有文字，区分文章正文、真实小标题、附带题目、作答说明和参考答案；不得改写、简化或自动补题。识别按自然段组织，不能按印刷行生成目录。
- **FR-16**：阅读区只显示文章正文和真实小标题。附带题目、说明、答案放在文末默认收起的“附带练习与说明”，保留原文并支持原有标注定位后展开。
- **FR-17**：有真实小标题时生成文章目录；没有时显示段落导航，只包含正文自然段，不纳入附带练习或作答说明。正文不额外加段落编号。
- **FR-18**：校对页允许逐项更改内容归属，归属变更不修改原文、段落 ID 和引用偏移；正文文字不变时保留有效标注，修订仍保留历史版本。归属不确定时提示人工校对。
- **FR-19**：旧材料根据明确题目区标记兼容分组，读取不回写数据库、不改原文件、不改标注。手工归属优先于自动推断，普通正文提及 questions 或 choose 不触发题目区。
- **AC-09**：给定正文后附 Questions 1–5 与作答说明，打开阅读工作台时，仅正文参与阅读区、段落计数和导航，附带内容默认折叠且仍可展开查看。
- **AC-10**：给定已有正文或附带题目上的有效笔记，点击摘录时定位对应原句；附带内容折叠时自动展开，引用文本与偏移不变。
- **AC-11**：给定一项附带题目，在校对页将其改为正文并保存后，重新打开仍显示为正文，内容与段落 ID 不变，旧标注继续有效且历史归属可查。
- **AC-12**：给定旧材料与原件，兼容分组后原文、笔记、阅读进度及数据库内容不变；新 PDF/照片识别需使用真实供应商样本验证正文/附带内容区分。
