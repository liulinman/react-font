# 知识笔记 MCP 与确认归档

功能 ID：`notes/mcp-notes`。需求状态为已确认，不代表实现、验收或上线完成。

## 背景与目标

用户希望把聊天中整理的知识保存到网站知识笔记，并通过 MCP 查找和修改。已有合适文件夹时由客户端 AI 自行归类；需要创建文件夹时必须先询问用户；修改已有笔记必须先展示修改内容，确认后再保存。保存后的笔记可在现有网站读取，不维护另一份笔记库。

## 角色、范围与非目标

角色为授权账号本人及其使用的 MCP 客户端。本次复用现有 MCP 接入与授权管理，增加本人知识笔记的查询、详情、新建、修改及所需的文件夹读取、确认创建能力。网页仅按需要补充授权选项，沿用现有界面和交互。

不新增 MCP 笔记删除、文件夹重命名/删除/移动、批量写入、自动读取聊天、后台自主归档、文件上传、协作分享或 OAuth。当前研发与网页验收范围为电脑端；移动端不新增设计与专项验收。

本需求仅在上述 MCP 会话范围扩展 [知识笔记](../knowledge-notes/prd.md) 和 [文件夹](../folders/prd.md) 中“不含 AI 自动整理/归档”的历史非目标；网站原有手动流程与其余规则保持有效。

## 用户流程

1. 用户在设置中创建具有笔记权限的 MCP 授权，并连接客户端。
2. 记录新知识时，客户端先读取本人文件夹，根据笔记主题选择合适的已有目录，再直接保存，返回笔记身份和归属。
3. 没有合适目录时，客户端展示建议目录名称及父级位置，询问是否建立；未确认前不建立，用户拒绝后保留待保存内容，可重新选择已有目录。
4. 用户同意后，创建已展示的目录，保存新笔记并回读确认结果；失败如实说明，不把“已建目录”冒充“笔记已保存”。
5. 修改时先读取最新笔记，展示修改前后内容及变化字段，包含归属或关联单词变化；用户确认后才提交预览中的内容。用户修改建议后须重新预览，不能把旧确认用于新内容。

## 功能需求

- **FR-01 查询与详情**：支持关键词、现有固定分类、文件夹和分页条件，遵循知识笔记的搜索范围及每页 20 条规则；可读取本人笔记完整内容、版本、文件夹归属及关联单词。无结果返回空列表，不将读取失败伪装为空。不存在与无权访问不泄露他人内容。
- **FR-02 自动归类**：可读取本人文件夹及其层级，客户端 AI 按主题选择合适的已有目录，不为已有目录逐次请求确认。新笔记明确指定有效目录，服务端不按标题猜目录，不静默创建目录、不静默降级到未归档。本次新建笔记须选择已有有效文件夹；不提供静默保存到未归档的替代路径。
- **FR-03 文件夹建立前确认**：没有合适目录时，先返回拟建名称、父级位置及需要用户确认的提示。未经用户明确同意不得创建；确认仅能创建已展示的目录，不能替换名称或父级。名称、同父级重名、层级、数量、系统保留名称规则继承文件夹 PRD。
- **FR-04 新建笔记**：新笔记至少有标题、正文，支持现有固定分类、例句、来源和本人关联单词；完整保留内容及换行，遵循现有字段限制。成功返回已保存记录及归属，能通过网站和 MCP 再次读取。文件夹失效、关联单词无权或输入无效时拒绝，不产生不完整笔记。
- **FR-05 修改预览**：修改必须先预览，返回原内容、拟保存完整内容和实际变化字段，包含内容、分类、来源、例句、关联单词、归属等受影响项。预览不修改笔记。未指定的字段及归属保留；明确清空可选字段按现有笔记约束处理；标题/正文不得为空。无变化时拒绝生成可执行的修改确认。
- **FR-06 确认保存**：客户端必须向用户展示修改预览，得到明确确认后才能保存。服务端仅接受有效预览对应的确认，不开放绕过预览的直接更新。确认绑定账号、授权、动作、目标、预览时版本及拟保存内容，期限沿用现有 MCP 的 10 分钟。凭证过期、目标内容或归属已变、目标不存在、跨授权/账号/动作均拒绝并要求重新预览。
- **FR-07 失败与重试**：新建和确认写入支持同一授权的请求标识；同标识同内容重试返回原结果，同标识不同内容拒绝。重复/并发确认只能执行一次，不重复建笔记、建目录或增加版本。失败不误报已保存。文件夹已建立而后续笔记未保存时，明确两者状态，重试不重复建立目录。
- **FR-08 权限与隔离**：笔记读取、新建、更新与文件夹建立使用独立于词库的授权能力；文件夹列表只向具有所需笔记能力的授权开放。既有词库授权不自动获得笔记能力。所有读写、预览及确认按授权账号隔离；无权限、撤销、到期或伪造授权拒绝，不能使用网站登录 cookie 替代 MCP 授权。
- **FR-09 兼容与审计**：沿用现有 MCP 协议、接入地址、授权期限/撤销和最近操作审计。审计记录动作和结果，不写入明文密钥、笔记全文或预览秘密。现有词库工具、知识笔记网站流程、学习统计及单词数据不因新增工具改变。

## 规则与状态

“归类”指选择笔记的文件夹；固定分类仍为语法、句型、词语辨析、阅读技巧、易错点、其他，与文件夹是两个维度。“确认”只针对当次展示的具体修改或拟建目录，不能将用户一次确认扩大成后续自动批准。客户端负责自然语言主题判断和展示/征询，服务端负责权限、有效预览、版本、输入与事务校验；服务端无法独立证明用户在第三方客户端实际看过内容，因此客户端行为也需专项验证。

笔记字段限制、关联单词数量、并发版本检测和目录规则继承对应正式 PRD。笔记和文件夹读写错误需可识别，允许用户保留输入重试，不泄露数据库细节。文件夹状态在确认时重新验证。

## 验收标准

| 编号 | 场景与可观察结果 |
| --- | --- |
| AC-01 | 授权客户端初始化、列举工具并查询/读取本人笔记；关键词、固定分类、目录/子目录与分页组合正确，返回完整内容和归属；无匹配为空。 |
| AC-02 | 已有合适文件夹时，客户端读取目录并自动选择，创建后可在 MCP 与网站读到同一笔记及目录；不出现不必要的新目录确认。 |
| AC-03 | 无合适文件夹时展示拟建名称和父级并询问；未确认、拒绝、缺少有效预览或试图替换预览内容均不建立目录；确认后仅建立展示的目录。 |
| AC-04 | 文件夹空名、超长、保留名、同父级重名、超过 5 层/200 个或跨用户父级均被拒绝；确认期间父级失效不错误创建。 |
| AC-05 | 笔记合法标题/正文、可选字段和关联单词完整保存；空白/超限字段、他人关联单词及失效目录拒绝且无半成品笔记。 |
| AC-06 | 修改预览展示 before/after 和实际变化，预览后原记录及版本不变；未提供字段保留，无变化拒绝；未经确认不能写入。 |
| AC-07 | 确认后仅保存预览内容并保持原笔记 ID，版本恰增加一次；内容、可选字段清空、关联单词和目录变更均与预览一致。 |
| AC-08 | 过期、跨账号/授权/动作凭证、目标被删除或预览后被内容编辑/移目录时拒绝，不覆盖最新内容；用户修改方案必须重新预览。 |
| AC-09 | 新建/确认在同请求标识重试、并发调用或响应丢失重试下不产生重复写入；同标识不同内容拒绝；目录成功但笔记失败时准确报告并可恢复。 |
| AC-10 | 只读授权无法新建/修改，词库授权无法访问笔记；撤销/到期/伪造授权拒绝，账号 B 无法搜索、读取、归档或修改账号 A 内容。 |
| AC-11 | 授权页面可选择笔记所需能力，创建/失败/撤销状态清楚；审计展示新动作及结果且不含密钥、笔记全文、预览秘密；既有词库工具回归通过。 |
| AC-12 | 客户端实测完成“自动归入已有目录→请求新建目录并取消/确认→新建并回读→预览修改并取消/确认→回读”流程，网站可找到结果，词汇与学习统计不变。 |
