# 知识笔记文件夹管理 PRD

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 范围与非目标

### 目标与范围

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

用户按自己的理解整理句子、单词辨析、短语辨析、课程笔记，像文件一样浏览目录、移动笔记。成功标准：可以在自建目录中创建笔记、移动已有笔记、搜索并重新找到内容，整理操作不会删除或覆盖正文。
本期以截图中的 Web 知识笔记为主要界面；保持手机现有阅读编辑兼容，不开展手机端改版。保留现有固定分类筛选作为辅助维度；不把固定分类自动改成自由标签。本期不新增共享、上传文件、AI 自动归档、拖拽排序或自由标签系统。

## 用户流程

### 用户流程

1. 在知识笔记左侧看到“全部笔记”“未归档”和自己的文件夹，右侧显示笔记列表。
2. 新建“短语辨析”，可在其中再建子文件夹；打开目录后新笔记默认归入此目录。
3. 从全部或未归档中勾选笔记，点击“移动到”，选目标并确认。也可以在编辑页调整单篇笔记的文件夹。
4. 进入目录，按标题/正文/例句/来源搜索，可叠加原分类。切回“全部笔记”即可全局搜索。
5. 删除文件夹前明确提示子文件夹一并移除，全部相关笔记回到未归档。正文、关联单词、原分类不变。

## 功能需求

### 功能要求

- FR-01 每位用户拥有独立目录；不得查看或操作他人的目录及笔记。全部笔记与未归档是系统视图，不可重命名/移动/删除。
- FR-02 文件夹名称去除首尾空白后 1–40 字符。同一父级下不允许重名（不区分大小写）；不同父级可重名。普通文件夹不能使用“全部笔记”“未归档”作为名称，避免混淆。每用户最多 200 个文件夹，最多 5 层。
- FR-03 支持创建、重命名、移动至根目录或其他文件夹。移动时携带全部子文件夹与笔记；不得移到自己或后代，不得导致树超过 5 层。以名称排序，不另做手动排序。
- FR-04 点击父文件夹显示本目录及子目录笔记，页面明确标注“包含子文件夹”；树中显示包含子目录的笔记数量，不随右侧搜索或分类筛选变化。允许展开/收起分支。面包屑显示当前位置，目录选择器显示完整路径，区分同名子目录。
- FR-05 每条笔记归属一个文件夹或未归档。创建/编辑可选择目标，默认当前目录；从全部/未归档新建默认未归档。旧笔记默认未归档，不改标题、正文、例句、来源、原分类和关联单词。
- FR-06 列表支持单条/当前页多选移动，最多 20 条；明确“本页全选”，翻页、切换目录、搜索后清空选择。移动至同一文件夹不重写内容。操作成功刷新目录数量和笔记列表，空掉最后一页时回到有效页。
- FR-07 批量移动必须原子完成：任意笔记无权限、不存在、版本已变化或目标失效时整体失败，不部分移动。移动增加笔记版本，以防旧编辑页将目录改回；旧客户端未传 folderId 时保留原归属。创建的幂等摘要包含显式传入的 folderId，未传时沿用旧摘要格式，兼容历史请求重试。
- FR-08 删除文件夹须二次确认，明确其子目录也将删除，所有笔记回到未归档且内容保留；删除与并发创建/移动串行处理，以确认提交时最新子树为准，确认框须明示这一点；移至未归档的每条笔记 version+1，不产生孤立归属。删除目录后返回全部笔记。其他设备持有失效目录时显示失效提示及“返回全部笔记”，不静默创建到错误目录。
- FR-09 搜索保持当前目录范围，原分类及关联单词筛选可叠加；全部笔记跨目录搜索。详情返回列表保留目录/搜索条件；直接访问已失效目录可恢复。
- FR-10 每个操作有处理中状态，防重复提交；失败保留输入并展示可读错误。目录加载失败可重试，不伪装为空目录。不以颜色作为唯一状态提示，按钮可键盘操作。

## 非功能约束

### 质量与兼容

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

所有校验由服务端实施；新增表/列采用增量迁移，上线前备份并验证旧数据数量与内容摘要。目录操作不触发通知或改变学生学习记录。数据库写入保持事务边界，账号隔离及并发树变更有真实 MySQL 验证。老版编辑仅改变内容、不传目录时不移除目录；返回 note 的新增字段对旧页面兼容。手机页面保留现有布局；共享接口和编辑保存需回归。

## 验收标准

### 验收

- 创建根目录及子目录，重命名、移动；拒绝重名、空名、超过层数、循环移动和跨用户目标。
- 新建自动归档、编辑改归属、本页批量移动、未归档/全局/父子目录查询与搜索组合正确。
- 删除含子目录及笔记的目录后，笔记数量、正文、分类、关联单词不变且成为未归档；并发移动/删除无孤立数据。
- 编辑版本冲突、批量部分无权限导致全部不写入、重复提交和目录失效错误可理解。
- Web 浏览器完成目录创建→新建笔记→批量移动→搜索→删除目录→找到原笔记流程；构建、相关组件和 MySQL 集成通过后部署。
