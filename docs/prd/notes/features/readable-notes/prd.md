# 笔记统一阅读展示

需求命名空间：`notes/readable-notes`。2026-10-20 用户确认实施、测试后上线。本补充明确修订 knowledge-notes 原“正文先纯文本”的展示约定；存储、原文、字段上限及账号隔离规则不变。

- AC-01：知识笔记正文/例句、词条展开笔记、手机词条详情/学习笔记、复习册笔记/要点使用同一渲染规则，标题、加粗、列表、引用、表格、链接、代码可读；普通文本保留换行。
- AC-02：知识笔记列表及收起的词条笔记显示去除Markdown语法的摘要，不出现格式符号堆叠；展开阅读完整原文，摘要不回写数据。
- AC-03：知识笔记正文及例句、单词笔记专注编辑提供编辑/预览切换，预览与阅读共用渲染组件；切换不清空或规范化源字符串，保存原文，原提交/失败/冲突/未保存保护继续生效。
- AC-04：HTML文本不执行，危险链接不可点击；图片显示替代文字而不自动请求外部资源。代码、链接、表格和长单词不撑破390px手机页面，宽表允许局部横向滚动；浅/深色可读，打印复习册保留排版和正文。
- AC-05：不批量重写旧笔记、不改变学习状态、答卷、权限或复习册快照；真实线上只读验证，不创建测试笔记。

实现使用成熟Markdown语法树解析，不用正则拼HTML；首期不引入所见即所得编辑器。
