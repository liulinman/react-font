# 单词与知识速读复习册

## 1. 背景与目标

当前词库以列表和卡片为主，适合查找与维护，但连续阅读时需要频繁展开笔记和切换词条。新增“复习册”，把已有单词与笔记提炼为有主题、有重点、便于扫描的复习材料。用户能够快速回顾核心词义、搭配、辨析和知识要点，退出后接着读，后续可打印。书籍感来自连续的知识组织与讲义排版，不是把原始词条或卡片搬到纸张背景上。

本功能以现有词库为依据，允许对已有知识做摘要、归类与对照，不生成故事或连续文章。阅读不会自动改变单词熟练度，也不会计作背诵或练习完成。

### 已确认与建议默认值

| 项目 | 定义 | 依据 |
| --- | --- | --- |
| 内容来源 | 选中单词、当前筛选结果、全部单词，三选一 | 用户确认 |
| 体验方向 | 快速阅读单词与知识的复习材料，相关知识分组、重点提炼、对比与提醒 | 用户确认，替代初版“词条书页”方向 |
| 打印 | 后续支持打印 | 用户确认 |
| 首发端 | Web 桌面优先，窄屏可阅读；原生 App 暂不新增入口 | [ASSUMPTION] 建议默认值 |
| 阅读内容 | 单词、核心词义、常用搭配、笔记要点、辨析与易错提醒；原文可追溯 | 用户确认方向，具体提炼规则见下文 |
| 组织形式 | 可命名、可保存、多本单词书，目录、阅读位置记忆 | [ASSUMPTION] 支撑持续阅读 |
| 内容稳定性 | 创建时保存内容与顺序，后续词库编辑不自动改变已生成书籍 | [ASSUMPTION] 方便续读及后续打印 |

上述默认值用于形成可评审方案，尚不代表用户已经逐项确认。

## 2. 范围与阶段

**第一期：** 词库入口、三种范围、创建与命名、单词书列表、目录、阅读、字号调整、进度保存、重命名与删除；包含内容提炼、知识分组、对照阅读、原文追溯与生成失败恢复。

**本期打印交付：** A4 打印预览、浏览器打印和保存 PDF、封面与页码、长内容分页处理。提供打印 / PDF 入口，使用浏览器打印；不额外提供服务端 PDF 文件托管。

不包含电子书文件导入、真实书籍版权内容、故事或文章创作、无依据的知识扩写、多人共享、自动同步词库变更、翻页动画、付费功能和阅读统计看板。

## 3. 页面与主流程

词库工具栏增加“制作复习册”；导航增加“复习册”，可查看已有书籍。

主流程：词库勾选或筛选 → 制作复习册 → 选择范围并核对数量 → 输入书名 → 整理与预览 → 确认保存 → 打开阅读 → 自动保存位置 → 从单词书列表继续阅读。

创建弹窗展示册名、三种来源及各自数量、已应用筛选摘要。整理后预览分组目录、代表性知识块、覆盖词数与内容不足提示，用户可确认保存或返回调整。阅读页由简洁工具栏、可收起的主题目录和连续讲义正文构成；窄屏目录进入抽屉。复习册列表展示名称、词数、创建时间、阅读位置与继续阅读入口。

## 4. 功能需求

### 4.1 范围选择与创建

- **FR-001** 三种范围使用单选控件，不能把已选词与筛选结果隐式合并。有勾选时默认“选中单词”，否则有已应用筛选时默认“当前筛选结果”，其余默认“全部单词”。
- **FR-002** “选中单词”只使用已勾选的有效词条 ID，去重；无勾选时禁用并提示“请先在词库勾选单词”。展示真实已选数量，不能把本页条数当作全部已选数。
- **FR-003** “当前筛选结果”使用最后一次成功查询所应用的条件，涵盖所有分页。输入但尚未点击查询的条件不生效。摘要显示筛选条件与匹配数量；没有筛选时标注“未设置筛选，与全部单词相同”。
- **FR-004** “全部单词”使用当前用户有权访问的完整词库，忽略筛选、勾选、当前页和每页条数。必须独立显示总量，不能复用筛选结果数量。
- **FR-005** 任一范围为 0 时不可创建。范围计数加载失败显示可重试状态，不显示为 0；用户仍可切换其他已成功加载的范围。
- **FR-006** 书名必填，去除首尾空格后 1–60 字，默认“我的复习册 YYYY-MM-DD”。允许重名，按创建时间与独立标识区分。创建前展示范围、数量和“按相关知识整理，保留全部所选词”的说明。
- **FR-007** 优先按有来源依据的主题、用法或辨析关系分组；每个单词只能归属一个主要小节，覆盖词数按源词条 ID 去重。没有足够依据的词归入“其他词汇速览”，组内按 A–Z 稳定排序，不强行推断关系；生成完成后目录、知识块与顺序固定。
- **FR-008** 创建结果必须是完整的一本书。创建期间防止重复提交，失败允许重试；响应丢失后的重试不得重复创建。同一次创建采用一致的数据范围与内容，禁止跨页获取时静默漏词、重复或混入后来新增词。
- **FR-009** 提交时重新验证权限与有效词条。如选中词已删除或范围数量发生变化，明确展示变化并让用户核对后重新创建，不静默跳过。书籍创建完成后固定内容、数量和顺序。
- **FR-010** 展示“正在制作”，提供取消/离开；取消未完成创建不会留下半本书。离开后已成功完成的书籍应能在列表找到。超时明确反馈，不能显示假成功。

### 4.2 阅读体验

- **FR-011** 正文由“分组标题 → 词汇速览 → 要点/搭配 → 可选辨析或提醒”组成。核心词义优先呈现；音标与词性为辅助信息。长笔记提炼为短句与要点，完整原文不默认铺满正文，可通过“查看原笔记”追溯。
- **FR-012** 只呈现来源支持的内容，缺失搭配、例句或辨析时省略相应模块，不凭空补齐。仅有词头的词仍纳入速览，标明“暂无释义”；不能为了版面丰富而重复或编造内容。
- **FR-013** 正文采用讲义式层级：主题标题、加粗词头、简短释义、紧凑知识块；相关词可并排对照，窄屏改为纵向。少量提示色突出易错点，黑白下仍能识别。正文不默认显示编辑按钮、熟练度控件和逐词折叠卡片。
- **FR-014** 默认按知识小节连续滚动，提供上一节、下一节和小节位置。小节围绕同一知识关系组织，不再固定每页 10 词；长内容可自然延伸。首尾操作禁用，目录跳转不打断内容完整性。
- **FR-015** 目录展示小节标题和覆盖词数，支持按词头搜索并定位到对应知识块；每词定位到其主要归属。搜索不改变正文、内容与顺序。
- **FR-016** 提供小、标准、大三档字号，默认标准；字号变化不改变知识小节分组。设置按用户保存，内容需支持浏览器放大和键盘操作。
- **FR-017** 展示阅读位置，例如“第 3 / 8 节”及“共收录 83 词”，准确区分位置与掌握程度。阅读不触发词库编辑、不提高熟练度、不产生练习成绩。

### 4.3 保存与管理

- **FR-018** 书籍归当前用户所有，列表、详情、目录、创建和删除均校验访问权限。不能通过猜测书籍 ID 访问他人内容。
- **FR-019** 阅读位置按用户和书籍保存，以稳定的小节、知识块标识和块内位置为依据；切换小节、目录跳转及停留后保存。重新打开恢复到最近成功保存位置，字号变化后至少能恢复到同一知识块。
- **FR-020** 保存失败展示“进度尚未同步”，恢复连接后重试；不能把未保存位置宣称为已同步。多端同时阅读采用最后一次成功保存的位置，不累加阅读量。
- **FR-021** 列表支持打开、继续阅读、重命名、删除。删除需展示书名并二次确认；删除只删除这本书及阅读位置，不删除原词条。删除最后一本时展示创建引导。
- **FR-022** 词库后续修改或删除不改变已有书籍快照；详情提示“内容保存于创建时”。如需最新内容，重新制作一本；本期不提供自动更新或合并。

### 4.4 打印要求

- **FR-023** 支持从一本已保存单词书进入 A4 纵向打印预览，内容和顺序与书籍快照一致。预览明确书名、创建日期、总词数及输出范围。
- **FR-024** 打印时移除导航、目录抽屉、操作按钮和阅读进度；黑白可读，不依赖背景色，包含页码。尽量保持小节标题与首个知识块同页，对比表重复列头；超过一页的知识块可自然续页，不裁切或隐藏正文。
- **FR-025** 支持调用浏览器打印与保存 PDF；取消打印不改变书籍或进度。阅读小节编号与 A4 物理页码可以不同，界面应明确区分。


### 4.5 知识整理与内容可靠性

- **FR-026** 提炼仅使用本次源词条快照的释义、笔记与来源信息，不自动纳入未选中的关联词或其他知识笔记库。后续若扩展知识来源，单独确认权限与范围。
- **FR-027** 每条摘要、搭配、辨析与提醒都需关联支持它的源词条与原文片段，阅读时可按需查看出处。提炼不得改变否定、条件、词性与例外，不把个人疑问或不确定笔记写成确定结论。
- **FR-028** 相同知识可合并去重，但不能遗漏范围内词条；多义词保留源材料中的不同义项及适用条件。对原文中的不同表述保留来源，不自动裁决或生成统一结论；本期不承诺自动识别所有原笔记冲突。
- **FR-029** 生成期间展示获取、整理、检查、可预览等状态。预览须区分已整理内容与未提炼原文。生成失败保留重试入口；允许用户主动选择“基础速览版”（词头与原有简短释义），明确不含知识提炼，不自动用其冒充整理完成。
- **FR-030** 确认保存前允许返回调整来源；变更范围需重新生成，旧结果不能混入。保存后固定本版内容，不因重开页面重复生成或改变知识顺序。
- **FR-031** 内容质量验收使用人工核对的代表性样本，至少包含多义、搭配限制、易混词、否定条件、冲突笔记、无笔记及长笔记。范围内词条覆盖率 100%，展示知识均可追溯；发现无依据结论或改变关键语义即不通过。

## 5. 数据与权限边界

一本书需记录书名、所有者、创建时间、来源类型、筛选摘要、源词条快照、提炼结果、分组及知识块顺序、内容与来源对应关系、生成版本及阅读位置。书籍 ID 与词条 ID 不混用。现有词库数据不得被创建、阅读或删除书籍操作修改。

笔记沿用现有安全展示规则，禁止执行脚本或危险链接。来源中不复制访问凭据；私有附件继续进行权限检查，不因生成单词书变成公开资源。退出账号后不得向其他账号展示此前账号书籍与位置。

## 6. 非功能要求

- **NFR-001 正确性：** 书籍词数等于去重后的有效来源词数；目录、正文和进度使用同一顺序；跨页数据完整性属于发布门槛。
- **NFR-002 容量：** [ASSUMPTION] 第一期验收覆盖 1、10、11、100、1,000、5,000 词及长笔记。全部单词在此基线内不得截断；超过已验证容量时须明确提示并允许缩小范围，不可静默取前 N 个。上线前按真实最大词库核实容量，若超过基线必须扩大验证或确认清晰上限。
- **NFR-003 性能：** [ASSUMPTION] 在约定测试设备与网络下，创建操作 1 秒内反馈任务状态，超过 30 秒展示仍在整理及可离开提示；整理总耗时在技术验证后确定，不以超时静默降质，打开已创建书籍首个阅读页 3 秒内可读，已加载小节切换 300 毫秒内反馈。验收报告记录设备、网络、笔记体量与实际耗时。
- **NFR-004 可访问性：** 主要操作可键盘完成，按钮有可读名称，焦点可见；文字放大至 200% 和 390px 窄屏下可读。
- **NFR-005 兼容性：** 第一期验收桌面 Chrome、Edge 和 Safari 当前项目支持版本，并验证手机浏览器窄屏阅读；具体版本在测试报告记录。

## 7. 验收标准

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| AC-01 | 勾选 3 个词制作 | 书内恰好 3 个词，其他未选词不进入 |
| AC-02 | 筛选匹配 83 个，每页 10 个 | 制作后为 83 个，不是当前页的 10 个；未提交的新条件不生效 |
| AC-03 | 筛选 12 个，完整词库 200 个 | 选择全部后生成 200 个；筛选与勾选不干扰 |
| AC-04 | 空词库、无勾选、零匹配 | 对应范围不可提交，说明清楚；数量请求失败可重试 |

| AC-06 | 创建时源数据或权限变化 | 提示变化并要求重新核对，不漏词、不越权 |
| AC-07 | 词头大小写相近、同词头 | 重开后的顺序稳定，目录与正文一致 |
| AC-08 | 相关词与超长笔记 | 按知识小节呈现，笔记被提炼且保留关键条件，原文可追溯，不是原始词条顺序堆叠 |
| AC-09 | 阅读到某个辨析块退出后重开 | 返回同一知识块；目录跳转和字号变化后仍可定位 |
| AC-10 | 断网保存进度 | 明示未同步，恢复后重试，不误报成功 |
| AC-11 | 修改、删除来源词 | 已有书籍内容和顺序保持；原词库不因书籍操作被修改 |
| AC-12 | 另一账号访问详情或共享设备切换账号 | 无权读取或修改他人书籍，不泄露缓存 |
| AC-13 | 重命名、删除与取消删除 | 名称约束生效；取消保留书籍，删除不删除词条 |
| AC-14 | 5,000 词及桌面/窄屏 | 内容完整，达到约定性能，正文无横向溢出 |
| AC-15 | 脚本笔记、坏图、缺失字段 | 不执行脚本，其他内容可继续阅读 |
| AC-16 | A4 预览、打印、保存 PDF | 输出完整、无控件和正文裁切，长笔记正常续页，取消无副作用 |

| AC-17 | 多义、否定、条件与冲突笔记 | 摘要保留关键限制，不替原文裁决对错，所有知识点可查看支持原文 |
| AC-18 | 整理失败或内容缺失 | 可重试；基础速览需主动选择并标识，不冒充提炼完成 |
| AC-19 | 调整词条归属 | 每词恰好归属一个小节，覆盖数正确，目录可定位 |
| AC-20 | 生成预览后修改范围 | 重新整理，保存内容与最终确认范围一致 |

## 8. 成功判断与发布条件

第一期以“知识被清晰提炼、有依据地组织、可快速回顾且能续读”为成功判断，所有第一期验收项必须通过。重点观察创建失败率、恢复位置错误和内容缺失；不能用阅读次数代替正确性，也不能把阅读位置当作掌握程度。

开发前明确提炼能力的技术可行性、原文追溯方式和生成耗时；发布前确认首发端范围、快照方式与容量。快速阅读体验应使用同一批词的原词库与复习册做人工对照走查，确认核心词义、搭配与易错点可直接扫描，无须逐词展开。产品已批准实施、测试与部署；实施结果与发布证据见同目录 acceptance.md。

## 9. 2026-10-19 实施批准与覆盖修订

用户批准开始实施、测试、部署。覆盖前文阶段约定：打印在本次交付，A4 双栏、正文 10pt、词头 11pt、页边距 12mm，黑白紧凑布局，不含快速回顾、填空或练习留白。分组目录先预览，允许改组名和调整词条归属；每词一个主要归属，组数不固定，可跨打印页。分组标题为知识小节编号，不是页码。以上覆盖前文有冲突的未来打印及多处引用规定。

## 10. 实施细化

- 制作使用后台任务，每账号一个活动任务；关闭后可在制作入口查看上次结果。重启中断明确失败可重试；已保存的任务恢复直接打开原册，不重复创建。
- 为保持知识可靠，重点采用原笔记完整短句的摘录，每词最多 3 条、每条不超过 180 字符；长笔记原文保留。主题依据词义与已有笔记归组，不新增例句或用法结论。
- 大分组预览每批最多 50 词，可切换小节和批次，保存仍包含全部选词。单册支持最多 5,000 词，超过时明确要求缩小范围。
