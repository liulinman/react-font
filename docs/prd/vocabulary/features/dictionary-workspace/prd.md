## 范围与非目标

### 目标与范围

把学习词条与笔记阅读从后台表格和四列布局转为词典与文档阅读。现有数据不迁移、不改写，不引入静态公开个人内容。设计来源：docs/design/vocabulary/dictionary-workspace/revisions/r02，用户已确认的逐次修订优先于早期默认折叠记录。

## 功能需求

### 需求

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- FR-01：桌面词库默认左侧词条索引、右侧完整详情；不以后台表格承载默认阅读。词头、主释义、发音、掌握程度、笔记有明确主次。索引保留词头、短释义和程度。
- FR-02：保留英文、中文、类型、音标、词性、时间、程度筛选、分页与卡片切换；选中词以ID绑定，列表变化不得展示其他词的草稿。新增和修改继续沿用真实接口及错误反馈。
- FR-03：详情保留所有 WordList 字段、多词性、图片预览、完整笔记、来源及创建/更新时间/覆盖次数/编号；选择词条后全部展开，来源中的内部任务可打开。编辑、删除确认、外部查词、英式发音、知识笔记复制及关联入口均保留。
- FR-04：当前筛选范围学习、勾选学习、手册、批量程度、语境练习、场景听力、AI查词、地图、导入、覆盖统计等现有能力不删除；低频入口可收进更多工具，批量操作集中呈现。实际限制继承对应原需求与现有服务契约。
- FR-05：词条编辑弹窗固定标题及提交操作，中部表单滚动；保留AI建议、校正、长笔记专注编辑及未保存保护。图片支持点击/拖入、选择预览、替换和移除、链接输入；校验PNG/JPEG/WebP与5MB限制，失败保留表单。上传走既有服务，只有保存成功才改变词条关联。
- FR-06：知识笔记列表页占满工作区；打开、新建或编辑笔记默认全宽阅读，收起列表和文件夹。可通过“展开笔记列表”切回列表＋文档正文，再通过“全宽阅读”收起列表；文件夹可开关；查询、分类、分页、文件夹树管理、批量移动、选中及列表位置可恢复。打开笔记在同一工作区阅读，保持URL可深链。
- FR-07：复用已有VitePress正文主题排版，正文根据真实标题生成可定位目录及当前位置提示；普通长文无标题提供合理空目录状态。正文、例句、来源、版本及关联单词全部保留，标题/引用/表格/代码/长链接可读。编辑继续使用既有原文编辑与预览，保护保存失败、冲突与离开草稿。
- FR-08：沿用服务端账号隔离，不生成可公开访问的个人笔记静态HTML/搜索索引，不执行原始HTML、危险链接或自动请求Markdown图片。加载、空列表、错误重试、删除确认保留。桌面1440和1100宽无整页横向溢出，手机原行为不回退，浅深色可读。

## 验收标准

### 验收

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- AC-01：登录后打开词库，筛选和分页正确，默认词典索引；选词后全部字段与笔记完整可读，所有详情区展开。
- AC-02：编辑词条及长笔记、改程度、删除、复制知识笔记、打开来源和发音/外查可达；保存失败仍保留输入，既有批量学习/手册及入口可达。
- AC-03：图片选择即时预览，替换和移除正确；无效文件有提示，上传/保存失败不丢其他字段。
- AC-04：知识笔记列表页占满工作区，打开笔记默认全宽显示，可展开列表并排浏览并恢复全宽；返回列表、文件夹开关保留查询范围；URL直接打开/返回/前进有效；目录从正文真实标题生成并定位，不重写正文。
- AC-05：笔记创建、编辑、搜索、分类、分页、批量移动、文件夹管理、删除、来源和关联词条通过原接口完成；保存冲突/失败/草稿及账号隔离继承原规则。
- AC-06：1440与1100桌面视觉和键盘验证，390手机回归；Markdown安全规则和原文不变，私有数据不导入公开站。
