# 单词 MCP 与授权管理

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

功能 ID：`vocabulary/mcp-access`。用户授权自主完成 PRD、开发、测试与上线。本功能不代表词库模块全部需求已完整确认。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 范围与非目标

### 目标和范围

用户在平台授权后，可让支持 MCP 与手动 Bearer 认证的模型客户端管理自己的单词。提供查询、新增、覆盖更新和删除。复用词库数据和覆盖计数；无需把平台登录凭据交给模型。仅支持单条写入；不包含 OAuth 自动授权、批量删除、第三方账号词库、AI 自动补全或后台自主执行。

## 功能需求

### 功能需求

- FR-01：系统设置提供 MCP 授权管理，显示公网 HTTPS 接入地址和 Streamable HTTP 接入说明。明确兼容条件，不声称所有模型客户端均兼容。配置示例使用占位符，不把实际密钥嵌入 URL。
- FR-02：登录用户创建命名授权，查询、新增、更新、删除四项独立权限；默认仅查询、有效期30天，可选1～365天。至少一项权限，名称1～60字。生成高强度随机令牌，只显示一次；列表、审计、日志、数据库不保存或返回明文令牌，数据库仅保存不可逆摘要。遗失需重新创建。
- FR-03：授权列表显示名称、权限、创建时间、到期时间、最后使用时间及有效/过期/已撤销状态。用户确认后可撤销自己的授权，即时生效，不能撤销他人授权。审计展示最近50条操作的时间、动作、结果、授权标识；不记录密钥或完整词条内容。
- FR-04：MCP 查询和详情只能返回授权账号自己的词条。支持关键词、分页，单页1～50，稳定排序；无匹配为空。他人词条与不存在词条对外等价。
- FR-05：新增要求英文及有效字段，规范化空白和大小写，与已有词条判重。同词已存在时返回冲突与覆盖流程说明，不新增副本、不直接覆盖。
- FR-06：更新必须先预览，展示原值、拟覆盖值和实际变化字段，返回10分钟有效的确认凭证。遵循已有安全覆盖规则：空白内容不清空原值，不更改单词主键、所属人和英文词头；只有明确提供的非空有效字段参与覆盖。确认覆盖后原记录的覆盖计数加1，不能旁路计数。
- FR-07：确认凭证绑定授权、账号、动作、词条版本和拟更新内容；提交要求显式确认。过期、错账号/授权、动作不符、词条预览后变化均拒绝并要求重新预览。确认凭证单次执行，重试返回原结果，不重复写入或计数。
- FR-08：删除必须先预览词条及不可恢复提示，再显式确认；仅删除指定所属词条，与现有词库删除行为一致。不批量删除、不删除其他词条、账号或知识笔记。凭证约束和重试行为同 FR-07。
- FR-09：新增携带调用方请求ID，同一授权和同一请求ID重试返回首次结果；同ID不同内容冲突，不能重复创建。覆盖/删除确认也必须具备事务原子性，并发重试只执行一次。
- FR-10：缺失、伪造、过期、撤销的 Bearer 令牌拒绝；MCP 不接受平台登录 cookie 替代授权。无对应权限的操作拒绝，包括预览。撤销与提交并发时按事务顺序执行，撤销生效后不得再写入。管理端状态变更防跨站请求。错误信息不暴露数据库或敏感信息。

## 验收标准

### 验收标准

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- AC-01：Given 已登录且无授权，When 创建默认授权，Then 仅查询、30天有效，令牌仅本次弹窗可见；刷新列表不再取回令牌。
- AC-02：Given 两个用户，When 查询/预览/确认对方词条或撤销对方授权，Then 无内容泄露或数据改变；无权限及无效令牌请求被拒绝。
- AC-03：Given 支持手动 Bearer 的 MCP 客户端，When 初始化、列举工具、查询词条，Then 返回符合官方 MCP 协议的数据，分页有效。
- AC-04：Given 可新增授权，When 同词不同大小写/多余空格或同请求ID重试，Then 无重复词条；同ID不同内容拒绝。
- AC-05：Given 原词已有内容和覆盖计数，When 先预览再确认有效更新，Then 仅变化字段被覆盖，空值保留原内容、ID不变、计数恰加1；再次确认返回首次结果。
- AC-06：Given 更新或删除预览，When 凭证过期/被他人授权使用/原词已改变/未显式确认，Then 拒绝操作且原词不变。
- AC-07：Given 删除权限，When 预览且确认删除并并发重试，Then 只删除该词一次并返回一致结果；未确认不得删除。
- AC-08：Given 已使用授权，When 撤销或到期，Then 后续 MCP 请求拒绝；列表状态正确，审计不含明文密钥及词条全文。
- AC-09：Given 桌面及390px手机，When 打开管理、创建、复制、撤销和错误状态，Then 无横向溢出，操作按钮可见且有间距，失败不误报成功。

## 来源、决策与待决项

### 非功能与发布

公网仅经已配置 HTTPS 入口访问。令牌不进入本地存储、示例文件、截图或报告。迁移可重复执行且只新增本功能表，不改旧业务表结构。写入、凭证消费和审计成功记录保持事务一致；故障回滚不产生部分覆盖。上线前隔离库真实 HTTP/MCP 与界面测试，线上仅未授权/只读冒烟，不删除真实词条。现有学习、管理和 HTTPS 续期配置必须保留。
