# Chrome 阅读查词与网页引用

状态：用户于 2026-11-09 确认按方案开发。范围为桌面 Chrome 普通网页及 English World 学习者个人词库。

- FR-01：选中一个英文单词后，用右键查本句含义。卡片显示原形、中文语境释义、完整原句和来源。已有词条也按当前原句释义。
- FR-02：点击「加入词库」保存新词及本句引用。已有词条可用「保存本句」追加出处，保持原笔记及学习记录。同一引用重试不重复创建。
- FR-03：词条详情展示每次主动保存的原句、本句释义和可打开的网页来源。优先展示网页标题，缺失时用域名。
- FR-04：连接账号前说明网页文本的发送范围。查词和收词限本人账号，授权可撤销。只在用户主动查词时处理必要上下文，链接经过安全校验。
- FR-05：显示查询、保存、失败和授权状态。失败可重试，过期预览可重新查询，关闭或切词后忽略过期响应。

## 验收

- AC-01：两篇网页的 bank 分别解释为银行和河岸，即使词库已有 bank 也展示本次释义。选中重复拼写时按实际位置取词。
- AC-02：查词阶段无收藏写入。收藏后仍只有一条 bank，包含两个出处。并发及重试不重复保存，已有学习字段完整。
- AC-03：刷新词条详情后两个出处均可查看，分别链接到原文。文章查询参数和普通锚点保留，危险协议或凭据地址被拒绝或清理。
- AC-04：未授权、撤销、过期及跨账号请求无法收藏或读取他人引用。失败可恢复，关闭后迟到响应不重开卡片。

## 0.2.0 阅读资料补全（2026-11-09 用户要求）

- FR-06：词卡显示词典原形音标，并提供主动点击的英语发音按钮。不能播放时给出可恢复错误，不自动朗读；关闭或替换词卡停止本次发音。
- FR-07：将本句词义、完整英文原句和整句中文译文分别展示。译文只翻译目标句，不能用单词释义或邻段译文替代。不可靠或缺失译文不能伪装为完整结果。
- FR-08：保存前可编辑单词笔记。新词预填当前用法说明，已有词默认不覆盖原笔记；主动填写后追加保留，重试及并发不重复追加。保存失败保留输入。执行细节：单次笔记最多4000字符；超过存储容量明确拒绝，不截断。
- FR-09：词卡明确显示“原文来源”、网页标题和可点击链接；词库出处持久保存原句、整句译文和来源URL，刷新后可打开。历史出处无译文时保留原文，不编造旧译文。

- AC-05：Given查询bank，when资料完成，then音标、单词义、完整原句、整句译文及发音按钮分别可见；点击发音使用英语语音，不自动播放；失败可重试，关闭停止。
- AC-06：Given新词且编辑笔记，when确认保存并刷新词库，then笔记内容完整且新引用包含本句译文和链接。查询前后词库不被自动写入。
- AC-07：Given已有笔记和学习状态，when追加新出处及笔记并重试，then旧笔记/学习状态保留，仅增加一次新笔记和出处；越权、过期、无效笔记拒绝且不写入。
- AC-08：Given旧Worker控制浏览器，when下载0.2.0并加载，then下载ZIP而非进入平台；使用同一扩展ID，旧0.1.0接口调用保持兼容。保存后网站出处显示译文和来源，历史出处兼容。

## 词库来源链接（2026-11-12 用户要求）

- FR-10：桌面词库在「引用」旁单独展示「来源链接」，用于打开通过扩展收藏的原网页。
- AC-09：刷新词库后，已收藏过网页出处的词条可直接打开最近保存的原文，包括功能更新前保存的出处。无网页出处时显示空值，同一词的全部历史出处可在详情查看，原有「引用」保留原内容。

## 标题与短片段查词（2026-11-23 用户要求）

- FR-11：标题、单独出现的词和缺少完整句子的片段可查词。词卡显示常见释义和原文片段，可收藏来源。没有完整句子时省略整句译文。正文中的完整句子继续适用 FR-01 和 FR-07。
- FR-12：查词失败时显示易懂的中文提示并保留重试入口。授权失效时引导重新连接账号。服务端错误的内部细节留在日志。
- AC-10：在标题里选中 `Considerations`，词卡显示词典原形和常见释义，保留所选片段与来源。保存后可从词库打开原文，整句译文为空。
- AC-11：`bank` 在不同完整句子里继续展示各自的语境含义和整句译文。接口返回 5xx 时，词卡显示中文提示，点击「重试查询」会再次发起原查询。
