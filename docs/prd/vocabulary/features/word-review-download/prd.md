# 单词复习资料下载

用户已在 2026-11-23 确认精简样稿并授权研发。适用于桌面学生词库。

## 功能需求

- FR-01 桌面词库提供「下载单词」。可选已勾选单词、当前筛选、全部单词。沿用词库当前页勾选行为。优先预选已勾选范围，其次已生效的筛选，最后是全部。当前筛选涵盖所有结果页，全部忽略当前筛选。范围内仅导出单词。
- FR-02 选择 PDF、Word 或 Excel。默认 PDF，全部单词默认 Excel，手动选择的格式保留。显示实际词数和最多三行预览。无词时禁用下载并说明，查询或生成失败时提供中文反馈和重试。
- FR-03 三种文件共有「单词、这次要记的词义、记忆线索」三列。词义取原有语境义，缺失时取已保存释义的第一项。记忆线索用已保存的短搭配或原文短片段，缺失时留空。PDF 和 Word 使用小号 Freewing 品牌和词数，紧接表格，不加大标题或操作说明。
- FR-04 导出仅使用当前登录账号的词库，不修改词条。预览后导出范围内数据变化时，刷新预览后再下载，避免导出与确认数或内容不符。

## 验收标准

- AC-01 勾选当前页的单词或应用跨页筛选时，预览数量、范围和实际导出一致。只有短语、句子或零条匹配的范围会显示空态。
- AC-02 实际下载的 PDF、DOCX、XLSX 能打开，中文可读，表格列与预览一致。较大的 PDF 延续表头，Word 可编辑，Excel 可按列筛选。
- AC-03 词义使用已保存的数据，缺少记忆线索的单词仍保留。文件没有完整笔记、链接、重复说明或大标题。
- AC-04 两个账号的词库互相隔离。接口错误有中文反馈。修改范围内词条后返回冲突，引导刷新。下载前后词库数据相同。
