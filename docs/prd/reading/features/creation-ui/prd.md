# Web新建练习界面

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

命名空间：reading/creation-ui；2026-10-22 用户批准界面分析方向，只考虑Web。补充automatic-review的创建及最终接收人确认，不改变自动检查和阻断规则。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本次整理不新增使用角色或业务要求。

## 功能需求

- FR-01 新建页分导入材料/AI出题。默认突出PDF/照片拖拽上传，支持切换粘贴文本，两类材料切换保留并可组合提交。
- FR-02 标题、已有答案和特殊处理折叠为更多选项，普通创建不必展开；接近正文上限才显示计数；文件上传全部完成前不能开始、关闭或切换新建方式。
- FR-03 AI出题先写生成要求，默认5题/雅思6分/400词用一行摘要展示，展开可调整难度、词数、题数、题型及可选标题。
- FR-04 抽屉底部固定取消与开始按钮，首屏能看到操作。字段宽度和间距统一，不横向溢出；错误保留输入并明确提示。生成成功同导入一样直接打开结果工作区。
- FR-05 创建不配置接收学生；统一发布确认框可选全部/指定学生，选择框不遮挡最终确认。取消无写入；空/失效学生拒绝发布。接收范围在发布事务中保存，无需重复内容检查。
- FR-06 发布幂等必须包括接收范围；相同requestUid改范围返回冲突，重复原请求不重复投递，旧客户端不传新参数仍兼容。沿用权限和版本检查。

## 验收标准

### 验收

- AC-01 给定新建导入页，上传为默认入口，开始按钮固定可见；切换粘贴文本→文件→文本后输入保留，可直接创建并进入工作区。
- AC-02 给定AI出题页，默认设置折叠且摘要正确，填生成要求后用默认值成功生成并打开结果；展开后设置可编辑。
- AC-03 给定审核完成草稿，最终确认选择指定学生后只分配该学生；取消无发布，重复同请求不增加通知，更换接收范围的同请求409。
- AC-04 给定空/失效/未授权接收范围，数据库中草稿、配置及通知不发生部分变更。只调整接收范围不改变qualityRevision。

真实SQL/HTTP验证FR-05/06；Web fixture浏览器验证UI交互和布局；不把fixture计作真实AI或数据库验收。

## 来源、决策与待决项

### 2026-10-22 导入后处理状态面板（用户确认优化）

- FR-07 无结果的等待、处理中、失败任务使用“原始材料预览＋任务状态”双栏布局。可以切换查看各份原稿；文本材料直接显示保存的原文，补充答案仍保留。原稿链接保留，长文件名和多文件列表不撑宽页面。
- FR-08 状态显示已排队、正在整理或需重试；只展示已知任务阶段，不虚构百分比或预计时间。说明关闭后可回列表查看，完成后需人工审核才能发布。失败展示原因并提供重试。
- FR-09 未产出结果时隐藏上传、排序、移除、题数、接收范围、版本难度、学生预览及已发布说明，底部仅保留关闭与材料已保存提示。有结果后恢复既有审核与发布流程。
- AC-05 给定文件导入任务等待或处理中，打开面板可看到原稿预览、切换文件和任务说明，在1280/1440/1920桌面宽度内不横向溢出，可关闭后重开查看。
- AC-06 给定失败的文本导入任务，原文与补充输入可见，失败原因明确，重试成功或后台轮询获取结果后进入既有审核界面，不能自动发布或改变接收范围。

本次为展示及交互优化，不改变导入接口、任务执行或发布校验；使用UI接口样本覆盖各状态，不把样本执行称为真实OCR或完整模块验收。
