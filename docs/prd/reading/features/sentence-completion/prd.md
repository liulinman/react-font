# 阅读练习句子填空

命名空间：`reading/sentence-completion`。来源：2026-10-21 用户反馈审核发布页不支持填空，并用 Questions 1–5 / ONE WORD ONLY 的句子填空截图确认“这种啊，可以填写”。

## 用户目标

导入原有阅读材料后，可以保留句子中的空位，让学生直接填写答案，再按老师审核的答案提交判分。

## 验收标准

- AC-01：导入识别句子填空为独立题型，保留题号、题干、原始空位和英文作答要求，不转换为选择题。缺少答案时保留待补全状态，不凭空确认。
- AC-02：管理员可以选择句子填空，编辑可接受答案、题目要求和最大词数，查看解析与原文依据；答案缺失不得完成核对或发布。
- AC-03：学生在空位输入文本，保留题目要求；填写计入完成数，支持切题、草稿恢复和提交，提交前不返回标准答案。
- AC-04：服务端按照可接受答案判分。实现默认：忽略大小写、首尾和连续空白；保留拼写与标点差异，不模糊匹配。最大词数按空白分词，连字符词作为一个词；答案超限不得提交。未配置词数时不擅自推定，导入时根据原始要求设置。
- AC-05：提交后展示填写答案、标准答案、正误、解析和依据；教师答案更正、重评及成绩统计能够处理文本答案。
- AC-06：选择、判断和人物匹配题继续使用原选项契约；历史题目和答卷不被批量重写。

## 边界与实施决定

本轮针对截图中的每题一个空位的句子填空，不声明完整雅思题型或整套考试已实现。可接受答案列表、大小写/空白规范化和词数计算是为实现目标采用的默认决定，并非用户逐项指定的官方考试规则。图片/PDF真实识别质量须有真实供应商执行证据才能验收，提示词或模拟返回的测试不能替代。
