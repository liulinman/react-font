# 学生练习列表移除与恢复

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

命名空间 `reading/personal-removal`。2026-10-20 用户确认按方案实施；接续本会话测试、发布流程。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 验收标准

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- AC-01：学生收到的待做、已撤回、已完成练习均可“从我的列表移除”；确认框指明标题并说明“从列表移除后，学习记录仍会保留”，可取消，确认前不写入。
- AC-02：移除状态保存到账号，默认列表不显示；“已移除”入口分页查看，可恢复到练习列表。刷新/换设备保持；列表模式保存在URL，恢复或移除后总数和空态正确，末页无条目回到有效页。
- AC-03：仅更新本人接收记录的列表可见性；不删除原题、分配、通知、答案、成绩、错题、学习记录、开始记录或本机草稿。管理员完成/接收统计不变，其他学生不受影响。
- AC-04：已移除练习仍可由通知、收藏URL、学习记录访问；已开始练习仍可提交，成绩/解析读取不变。重新发布版本按独立练习处理；对同一分配的追加接收人不擅自恢复。
- AC-05：未登录401；非接收人或不存在练习404；服务端从会话获取用户ID。重复移除/恢复幂等，不接受客户端指定其他用户；失败保留当前条目并可重试，进行中防重复点击。
- AC-06：桌面和390px手机入口可达、无横向溢出；深色模式可读。已有数据默认显示，不做管理员原题删除或自动清理旧练习。
