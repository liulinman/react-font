# 阅读练习 AI 检查与修复

命名空间：`reading/ai-review-repair`。来源：2026-10-21 用户反馈第5题引用段落错误导致审核卡住、问题没有明确标记，批准统一检查并修复、问题就地定位方案。

## 目标

管理端用一次“AI 检查并修复”处理明确的小错误并重新检查，把无法确定的问题直接标在对应题目上。不能把AI自动修复当作老师核对或代为发布。

## 验收标准

- AC-01：审核页提供统一的“AI 检查并修复”入口，未保存编辑时提示先保存。串联可确定错误修复、缺失答案解析证据补全与最新内容检查。
- AC-02：当既有原文引句只出现在一个段落中，自动修正错误的引用段号，并记录原位置、新位置和修复题目；原句出现在多个段落、找不到原句或资料缺失时不猜测。
- AC-03：保留文章、题号、题干、选项、作答要求和已存在的合法答案，补全仅合并缺失或无效的答案/解析/证据。不能任意更正有争议答案。
- AC-04：检查成功后保存修复和当前问题，清除已被本轮修复解决的旧结构/AI检查提示；真正缺页、缺图的材料阻断仍保留。界面展示修复结果和剩余待处理题数。
- AC-05：按题显示问题状态、问题数与定位入口；同题多个提示只算一个待处理题。点击摘要或问题能跳到对应题目，直接看到具体错误与原文依据，避免只在页顶堆积提示。
- AC-06：引用错误显示“原标第6段，实际第7段”等用户可理解的说明，显示引用原句；隐藏空的“依据/建议”，不把 evidence.paragraph 等内部字段作为主说明。
- AC-07：底部明确显示待处理原因并提供“前往处理”；没有阻断后仍需老师逐题确认，再发布。AI修复不自动勾选、不自动发布。
- AC-08：AI失败或内容版本冲突时不部分覆盖草稿；以当前修订检查并一次提交，保留错误提示和用户原有编辑。重复检查不得重复累积旧问题。

本需求补充既有一键补全与质量检查流程，不替代学生填空题契约或变更已发布练习、答卷及通知。
