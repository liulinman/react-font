# 收到的阅读练习使用雅思工作区

命名空间：`reading/received-ielts-workspace`。来源：2026-10-21 用户以当前简易填空页与已有IELTS界面对比截图明确要求替换，包含界面与功能。

## 用户目标

管理员发布给学生的阅读练习直接使用已有雅思单篇工作区，保留填空、选择、判断和人物匹配，练习、答案与成绩继续使用收到练习的真实服务契约。

## 验收标准

- AC-01：桌面收到练习和成绩回看入口统一采用IELTS工作区。保留标题与文章段落；左右独立滚动，底部题号导航/前后跳题、已答数量和Review标记；不重复逐题堆叠相同作答说明。
- AC-02：复用计时、字号/高对比/阅读区宽度、Hide/Resume、Help、划选高亮和Notes便签、点击重开与清除等已实现功能。计时从服务端开始作答成功后启动，默认20分钟单篇训练，仍保留既有时长选择；不宣称正式全套考试。
- AC-03：填空题直接输入答案，保留词数要求；选择、判断、匹配选项完整且标签不变；作答、高亮笔记、Review、开始和截止时间在本机按用户和练习独立保存，刷新后恢复。
- AC-04：手动交卷确认提示未答数量；允许确认后交卷，未答计错。到时自动交卷，超词数答案计错，不能因未答或超词数卡住交卷；手动交卷对超词数提示修改。普通严格提交契约继续保留。
- AC-05：仍使用收到练习的开始、提交和结果接口，所有题号身份和接收人权限继续校验，重复请求幂等且不能覆盖正式成绩。默认保留每份练习一次正式提交，不提供额外正式重考次数。
- AC-06：成绩在相同雅思布局中查看，展示学生答案、正确答案、解析/依据，支持老师纠错、作废和最新评分；服务端结果优先于本机缓存，旧结果不能遮蔽最新重评。
- AC-07：旧简易页草稿答案和请求标识尽可能迁移；存储空间失败仍能交卷并提示，提交失败保留原答案并能用同一请求重试。不同用户/练习和ContextLab不能串用草稿或提交服务。
- AC-08：窄屏保留可用的阅读/题目切换，基本答题与提交可操作；退出返回原练习列表，不丢失草稿。

## 边界

沿用已有单篇机考工作区，不新增整套三篇试卷、正式成绩校准、跨设备笔记同步或多次正式提交。计时与笔记是训练功能，本机恢复不代表服务器强制考试时限。考试模式标志随结果持久化并用于重评，避免未答/超词数答卷重评失败。


## 2026-10-22 普通文章排版补充

- AC-09：阅读区只显示文章真实标题和自然段，不额外显示“Reading Passage 1”或系统生成的“Paragraph N”；顶部提示改为“阅读文章”。保留原文已有的小节标题/标签。
- AC-10：排版调整不改变底层文章来源文本或已保存答卷的内容标识；旧高亮、笔记、作答与成绩回看继续恢复，新划选位置仍准确。
