# 管理员永久删除阅读练习

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

命名空间：`reading/permanent-deletion`。来源：2026-10-22 用户要求删除全部关联，并批准删除方案。

修订：管理员删除不再限制为未发布草稿。学生个人移除/恢复仍遵循 personal-removal，不改变其保留成绩规则。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 功能需求

- FR-01 所有练习状态均提供永久删除；默认当前版本，可选择同时删除同族全部版本。
- FR-02 确认前实时展示版本标题/数量、接收记录、答卷与成绩、通知与阅读回执、事件、运行记录、专属及共用原稿数量。明确不可恢复。
- FR-03 删除需明确确认及匹配预览令牌；关联内容变化时阻止旧确认，重新加载并确认。
- FR-04 一并删除所选版本专属记录、内容、审核聊天历史、反馈纠错、答卷成绩、分配开始记录、通知回执和生成运行记录。清除独占PDF及页面；共用材料保留。
- FR-05 删除族根版本后保留版本仍能修订；已运行生成任务不能写回复活。数据库失败原子回滚，文件失败持久重试并显示清理中。
- FR-06 仅管理员可执行。取消无写入，失败保留确认框可重试；成功刷新列表并修正空末页。
- FR-07 用户、词库、笔记、其他练习和定时任务模板不属于此删除范围。

## 验收标准

### 验收

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- AC-01 给定已撤回且有成绩的练习，确认删除当前版本后，专属关联不存在，管理端学生端列表消失，旧链接不可访问。
- AC-02 给定多个版本共用PDF，删除一个版本后，共用PDF及其他版本答卷保留，剩余版本仍可创建修订。
- AC-03 给定全版本预览后新增版本，旧令牌返回冲突，不能静默扩大范围删除。
- AC-04 给定生成任务运行中删除，生成完成也不恢复练习；并发提交/修订不能产生孤儿数据。
- AC-05 给定事务中途失败，数据完整回滚；给定磁盘失败，反馈附件清理中且后台可重试完成。
- AC-06 给定取消或未确认，不发送删除；学生/匿名删除被拒绝。管理端桌面/手机均能查看范围并确认。

实际真实练习删除由管理员确认执行，发布验收不得删除用户真实数据。

## 来源、决策与待决项

### 2026-10-23 删除弹窗优化

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- FR-08：使用当前版本/所有版本两张互斥范围选项，默认当前版本。最终确认独立控制，勾选或取消确认不改变范围；范围变化或重载预览仍必须重新确认。
- FR-09：紧凑展示标题、删除对象及版本、版本/接收/答卷摘要，完整影响清单可展开，保留所有FR-02统计及共用原稿说明。明确不可恢复，取消/删除按钮间距至少12px，手机不横向溢出。
- AC-07：Given 所有版本已选，when 连续勾选和取消最终确认，then 所有版本始终选中；when 改为当前版本，then 确认清空且重新核实预览，发送范围与预览一致。
