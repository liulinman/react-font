# 统一阅读工作区与体验整改

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

需求命名空间：`reading/unified-workspace`。来源：2026-10-20 用户截图反馈及本会话确认。用户确认阅读入口统一为“雅思考试 / 自主练习”，并要求改善搜索、去除黄色主题、修复管理端刷新位置。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本次整理不新增使用角色或业务要求。

## 范围与非目标

### 边界

本次确认的“不一致”指入口和用途混杂，不代表用户报告了具体错误答案；不擅自改动历史题目、正确答案、答卷或正式难度。后续完整雅思套卷及原生填空等题型需另行定义内容与评分契约。

## 用户流程

### 2026-10-28 作答与标注交互补充

- AC-08：点击或切换答案时保持阅读/作答区域滚动位置，首次作答及清除答案不改变题目高度；题号导航及切换作答面板仍定位当前题。
- AC-09：题干（含填空题空格前后文字）和各选项支持划词后右键 Highlight / Notes；划词和点击标注不改变答案，高亮按用户及练习保存，刷新恢复。

- AC-10：雅思考试工作区打开期间拦截 Ctrl+F / Command+F 网页查找快捷键，包含准备、作答与成绩回看；退出工作区后恢复，不影响普通文字输入。

## 验收标准

### 验收要求

- AC-01：阅读练习为统一入口，有“雅思考试”和“自主练习”两种模式，模式保存在 URL，刷新后可恢复。
- AC-02：自主练习集中提供“收到的练习”与“自己出题”，复用原练习、生成历史、作答记录、解析与错题；保留原数据和评分规则。
- AC-03：雅思考试模式复用已有单篇机考工作区，支持限时、独立阅读/答题区、标记、交卷与恢复；页面明确标注单篇模拟。完整套卷、完整官方题型不是本次已有能力，不得以界面改名冒充。
- AC-04：侧栏不再提供重复的语境实验室入口；旧生成入口转到统一阅读，来源文章参数和微语境复习闭环继续可用。
- AC-05：词库默认突出英文、中文搜索，其他条件通过更多筛选展开；回车与按钮走同一查询流程，输入去首尾空格，收起条件不丢失已选值。
- AC-06：桌面学习工作区采用浅灰背景、白色内容面与蓝色强调，去掉米黄纸张与棕色装饰；深色模式保持可读。
- AC-07：管理端当前菜单保存在 URL，刷新及浏览器前进后退恢复菜单；未知菜单参数回退用户管理。

### 2026-11-11 电脑端阅读子菜单

- AC-11：电脑端侧栏「学习 → 阅读练习」下并列显示「老师发的题」「自己出的题」「雅思考试」。默认打开老师发的题，列表可切换「全部」和「已移除」。个人题入口提供生成和历史练习，雅思考试保留单篇模拟。
- AC-12：电脑端由侧栏切换入口，原有模式、来源和题目直达链接仍可打开对应内容，刷新按 URL 恢复选中项。
- 本节修订 AC-01、AC-02 的电脑端导航层级，原条款中的数据、记录、解析和评分要求继续适用。
