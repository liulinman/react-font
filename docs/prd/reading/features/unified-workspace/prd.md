# 统一阅读工作区与体验整改

需求命名空间：`reading/unified-workspace`。来源：2026-10-20 用户截图反馈及本会话确认。用户确认阅读入口统一为“雅思考试 / 自主练习”，并要求改善搜索、去除黄色主题、修复管理端刷新位置。

## 验收要求

- AC-01：阅读练习为统一入口，有“雅思考试”和“自主练习”两种模式，模式保存在 URL，刷新后可恢复。
- AC-02：自主练习集中提供“收到的练习”与“自己出题”，复用原练习、生成历史、作答记录、解析与错题；保留原数据和评分规则。
- AC-03：雅思考试模式复用已有单篇机考工作区，支持限时、独立阅读/答题区、标记、交卷与恢复；页面明确标注单篇模拟。完整套卷、完整官方题型不是本次已有能力，不得以界面改名冒充。
- AC-04：侧栏不再提供重复的语境实验室入口；旧生成入口转到统一阅读，来源文章参数和微语境复习闭环继续可用。
- AC-05：词库默认突出英文、中文搜索，其他条件通过更多筛选展开；回车与按钮走同一查询流程，输入去首尾空格，收起条件不丢失已选值。
- AC-06：桌面学习工作区采用浅灰背景、白色内容面与蓝色强调，去掉米黄纸张与棕色装饰；深色模式保持可读。
- AC-07：管理端当前菜单保存在 URL，刷新及浏览器前进后退恢复菜单；未知菜单参数回退用户管理。

## 边界

本次确认的“不一致”指入口和用途混杂，不代表用户报告了具体错误答案；不擅自改动历史题目、正确答案、答卷或正式难度。后续完整雅思套卷及原生填空等题型需另行定义内容与评分契约。
