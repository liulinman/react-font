> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 用户流程

### 用户流程

新建 → 上传PDF/照片或粘贴文章 → 开始自动整理 → 后台识别、格式整理、缺失答案补全、确定性修复、质量检查 → 自动进入审核 → 必要时就地改题并保存复查 → 统一确认发布。

## 功能需求

### 功能要求

- FR-01 Web材料导入支持PDF/照片/粘贴文本；默认自动整理。一次开始后无需再点补全和检查。文章和已有题目保持原意，不擅改源事实或已有答案。只有文章没有题目时明确提示，可选择生成题目。
- FR-02 识别结果先持久保存，再执行补全与检查。后台任务可恢复，防重复并有租约/修订保护；刷新页面不丢进度，迟到结果不能覆盖用户新修改或恢复已删除练习。
- FR-03 原文唯一定位时可修复引用与解析段号；缺答案可根据完整文章推理并标为AI来源。有歧义、缺页、模糊OCR、不支持题型应明确提示用户，不编造材料。
- FR-04 自动处理结束直接展示审核页，文章和题目可浏览，问题定位到题。显示处理中、可审核、有问题需处理、处理失败各状态；失败保留已识别内容与重试入口，失败检查不得显示已通过。
- FR-05 修改本题在审核页内展开编辑答案、解析、原文引用，保存并复查一次完成；保存成功检查失败时明确说明内容已保存，不以旧版本重存。未修改题目确认信息保留，修订检查仍可靠。
- FR-06 默认隐藏逐题复选框、独立完成核对按钮和误报输入；误报处理折叠在高级操作。审核页提供统一确认并发布，确认框显示接收范围/题数；服务器原子校验当前修订、真实检查结果和阻断问题。前端绕过不可发布未检查内容。
- FR-07 真实来源缺失、题型不支持、无题、无答案/解析/有效证据阻止发布。AI提示按其blocking语义处理，非阻断建议不应禁用发布；误报关闭需原文理由，不可关闭结构/来源缺失。
- FR-08 未经用户确认不发布、不发通知；沿用管理员权限、发布requestUid幂等与单次学生提交。旧草稿进入审核后如尚未检查，自动检查一次，失败不无限循环。

## 验收标准

### 验收

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- AC-01 给定可用的PDF/图片/文本材料，用户开始一次后任务自动执行识别→补全→检查并显示审核结果，无需中间操作。
- AC-02 给定不能识别/缺页/无题材料，具体提示并阻止发布，已有转录可查看且不被伪造内容替换。
- AC-03 给定第5段的唯一原文，解析写第4段，自动修复段号，答案与其他内容保持不变；多处匹配保持人工处理。
- AC-04 给定自动处理后可审核内容，只需确认发布，无逐题勾选/完成核对要求；重复发布不重复投递。
- AC-05 给定只修改一题解析，在同页保存并复查后问题更新；失败保留修改并可重试；并发修订冲突不覆盖新内容。
- AC-06 给定后台处理阶段中断，恢复后可完成；重试次数有限，原稿和识别内容保留；过期租约不能写回。
- AC-07 给定建议性提示允许最终审核发布，结构和来源阻断仍拒绝；匿名/学生不能处理或发布。
- AC-08 Web浏览器完成导入→处理进度→审核→就地修改→确认发布；取消最终确认不产生通知。移动端不在本轮验收范围。

## 来源、决策与待决项

### 范围与修订

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

修订 ai-review-repair 中强制逐题勾选和独立完成核对/发布步骤：保留人工最终确认，但不要求逐题打勾。默认自动处理完整流程，仍提供高级仅转录模式。不包含移动端UI、学生考试改版、全局删除或真实学生数据变更。

### 自审结论

已检查：默认模式与高级仅转录兼容；自动补全不等于自动发布；后台恢复与修订并发有保护；检查失败保留识别内容；来源问题不可被误报关闭；一次确认必须在服务器校验而非仅前端合并。真实供应商OCR质量须与fixture测试分开报告，不将模拟AI当真实识别通过。

### 2026-11-03 审核阻断恢复补充（用户批准）

以下补充修订 FR-07 中“来源问题不可关闭”的范围：真正缺页、缺图、关键材料缺失及不可读原稿仍不可忽略；来源文字的拼写、印刷、OCR疑问可由老师对照原稿核实，不等同于材料缺失。

- FR-09 导入、编辑、检查和发布采用相同题型/答案约束。雅思判断题按原稿保留 True/False/Not Given 或 Yes/No/Not Given，保留选项顺序和答案，不因标签大小写误阻断。
- FR-10 来源文字疑问提供原稿核对入口，老师选择当前原稿、查看原件并填写核对说明与位置/文字依据后确认。确认仅处理该条提示，记录操作者、时间、原稿和内容绑定，不自动修改正文、答案或发布；真实材料缺失不可通过该入口关闭。旧草稿中的纯拼写误分类也提供此恢复路径，不自动放行。
- FR-11 重新检查以当前修订更新问题，去重旧提示，保留仍未核实的来源问题。相同内容/原稿已核实的问题不重复阻断；内容或原稿改变后原确认失效。检查失败或并发修订时不部分覆盖，也不把AI遗漏来源问题视为已解决。
- FR-12 每类阻断给出明确处理入口：修改内容、核对原稿或补充材料；发布按钮附近显示仍待处理的原因与入口。
- AC-09 给定原稿文字存在拼写疑问或旧草稿纯拼写误标缺材料，当老师查看当前原稿并提交有效理由与依据，则只解除该项提示并留审计记录，真实发布仍需最终确认；无原稿、不可读原稿、陈旧修订或真实材料缺失时拒绝确认。
- AC-10 给定已核对的来源文字提示，当重复检查相同内容与原稿，则不重复阻断；当内容或原稿变更，则需要重新核对。未核实的来源问题不因本次AI未返回而消失，同一问题不累积重复项。
- AC-11 给定当前有阻断，当查看审核页，则能看到对应处理入口和发布前剩余原因；缺材料只进入补充材料，不出现直接忽略入口。匿名和学生不可核实原稿或发布。

批准来源：本聊天用户确认四点修复建议并要求“修复，然后发布”。该补充不扩展到移动端，不变更已有答卷和已发布正文。
