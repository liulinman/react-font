# 阅读练习完成情况与成绩分析

## 背景与目标
老师目前只能在阅读练习列表看到“完成/接收”数量，难以确认哪些学生没交、谁分数低、哪些题错得最多。新增按篇、按已发布版本的“完成情况”视图，支持总览、学生成绩和逐题错题分析，并查看具体学生的答题明细。

本次沿用原练习、分配、开始记录、提交及纠错评分，不修改学生数据，不产生新的分发或通知。

## 使用流程
1. 老师在阅读练习列表点击“完成情况”；已发布和已撤回练习均可查看，点击“完成/接收”数字也可进入。
2. 页面显示文章标题、内容版本、评分修订、统计更新时间，以及接收人数、完成/未完成人数、完成率、平均分和整体错误率。
3. “学生明细”列出所有当前接收人，区分未开始、作答中、已完成；可搜索用户名/ID、按状态筛选、按分数或错题率排序和分页。
4. 点击已完成学生的“答题详情”，查看每题的作答、当前正确答案、对错、解析和原文证据；默认显示错题，可切换全部题。未提交学生显示状态说明，不捏造答案或0分。
5. “逐题分析”按错误率从高到低呈现题干、答题人数、答对/答错人数、错误率、各选项分布。可查看答错该题的学生并打开其明细。
6. 老师点击刷新获取最新分配、提交与评分；已撤回练习只读保留历史数据。

## 统计口径
| 指标 | 定义 |
|---|---|
| 接收人数 | 当前练习版本存在分配记录的人数；含停用但未删除用户，停用单独标记 |
| 已完成 | 存在成功提交记录；即使全部题作废仍属于已完成 |
| 未完成 | 接收人数减已完成，细分未开始/作答中 |
| 未开始 / 作答中 | 无提交时，分别无/有服务器开始记录；旧数据有提交但无开始记录仍算完成 |
| 完成率 | 已完成÷接收人数；无接收人显示“—”，不显示NaN或虚构100% |
| 分数 | 与学生当前成绩相同，采用最新有效评分规则，满分100；未提交显示“—”，全作废显示“不可评分” |
| 平均分 | 所有已完成且可评分学生当前分数的算术平均；无可评分提交显示“—” |
| 学生错题率 | 当前有效题中答错题数÷有效题数，仅对已完成且可评分学生计算 |
| 整体错误率 | 全部已提交答卷的有效错题次数÷有效作答题次；未提交、作废题不进入分子分母 |
| 单题错误率 | 该题答错人数÷该题已提交答题人数；没有作答显示“—”；作废题显示“已作废，不计入统计” |
| 选项分布 | 该题各选项被已提交学生选择的人数及占比，不用全部接收人数作分母 |

平均分使用已取整的学生显示分数，例如两份2/3均为67分，平均67.0分，而整体错题率为33.3%。

历史提交若缺题、重复题或选项非法，整份排除成绩、逐题和选项统计，但仍保留已完成状态；概览显示异常份数、学生行显示“数据异常”，不默默按0分计算。

百分比/平均分展示一位小数，同时保留原始计数。100%错误率、0分、0%错误率均为真实值，不能被当成空值。未经提交的本地草稿不可读取，也不计入错误。全体按最新评分修订统一计算，不能混用纠错前后结果。

## 功能要求
- FR-01：列表提供直接入口和完成数字入口；不同内容版本独立统计，不合并原版与修订版。
- FR-02：概览、学生列表、逐题分析来自同一个一致的数据快照；追加学生立即影响下次刷新分母，但不改变已完成学生成绩。
- FR-03：学生明细展示用户名/ID、账户停用标识、完成状态、分数、正确/有效题数、错题数/率、开始与提交时间；未记录时间显示“—”，不推算耗时。
- FR-04：支持未完成总筛选及两个子状态、已完成筛选、用户名或ID搜索、排序、分页。筛选影响列表，概览仍为全篇统计，并明确标注。空分数/空错题率在升降序中均置后，并列按用户ID升序；筛选或搜索变化回到第1页。
- FR-05：答题详情仅对本练习的已分配且已提交学生可读；题目使用当前评分答案和解析，展示作废标识。零错题有清晰空态。
- FR-06：逐题分析显示题号、题型、题干、答案、答对/答错/提交人数、错误率和选项分布；错误率并列按原题序稳定排序；作废和无作答题置后。查看答错学生时只列当前有效评分下答错的人。
- FR-07：改答案、作废、恢复后刷新所有指标同步变化；全部作废不失去完成记录。详情与概览评分修订不同则明确提示并刷新统计，不能静默混用。
- FR-08：页面加载中、无接收人、无人提交、零错题、加载失败和重试均有明确反馈；异步旧响应不得覆盖新练习/新请求数据。
- FR-09：只有管理员可读；学生、匿名、跨练习未分配用户的详情请求必须拒绝。不修改提交/分配/评分，不发通知。
- FR-10：桌面可扫描表格；窄屏控件换行，表格在自身区域滚动，页面无横向溢出。

## 范围边界
本次不增加导出、自动催交、补考/多次提交、跨篇排行榜、知识点AI诊断、学生成绩修改或第三方图表依赖。页面用现有组件展示必要统计，不以人工测试修改真实学生作答。

## 验收条件
- AC-01：A已完成、B作答中、C未开始时显示3接收/1完成/2未完，完成率33.3%；名单状态和筛选正确。
- AC-02：三道有效题，A对2题、B对1题，平均分50；整体错误率50%，单题统计与两份答卷相符，C未交不影响成绩与错题率。
- AC-03：从A明细看到具体所选选项、当前正确答案、解析与证据；“只看错题”仅显示当前有效错题，切换全部可见正确题和作废题。
- AC-04：更正答案、作废/恢复后概览、个人分数、错题列表、逐题错误率一致更新；所有题作废时完成数不变，平均分与错误率为“—”。
- AC-05：追加未完成用户只改变接收/完成率；不同版本独立统计；已撤回仍能查看已提交数据。
- AC-06：重复刷新不写入数据库；无接收人和无人提交不出现NaN/Infinity，权限测试拒绝学生与匿名用户。
- AC-07：快速切换学生详情或重试加载不会展示前一学生的答案；评分修订变化可识别。
- AC-08：桌面和390px窄屏浏览器验证入口、筛选、错题详情、逐题错误率及空态。

## 发布与验证
沿用当前生产源码为基线合并，保留已有导入、追加接收人及学生端功能。补聚合逻辑测试、真实MySQL/HTTP权限与重评分测试、管理端组件测试和完整浏览器流程。备份后发布，生产仅只读核验，不给真实用户分配测试练习。
