首期为独立电脑端教师 Web 应用及现有学生 Web 端入班和作答流程。现有管理端是出题流程参考。首期包含旧作业手动补发、PDF／图片导入、AI 出题和作业成绩统计。协同授课、课堂归档和移动端范围待后续定义。
