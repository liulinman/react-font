# 技术与实践文档中心

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

用户确认以知识解释、真实项目技术和动手实例结合的独立多篇文章网站，随项目发布并线上预览；不维护多个产品。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 功能需求

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- FR-01：提供公开的 `/docs/` 文档中心，七栏目共25篇独立文章及首页：开始阅读2篇、AI与MCP5篇、AI学习4篇、后端与数据4篇、前端交互3篇、部署排障4篇、开发参考3篇。栏目和主题以用户确认目录为准，不用空占位页代替内容。
- FR-02：重要文章包括问题/目标、必要知识、真实项目实现和源文件位置、具体输入输出示例、验证或排错方法；区分协议规定、项目业务选择、演示与实际验证，未经执行的示例不写成测试通过。
- FR-03：桌面侧栏分类导航、文章小节目录、前后篇、全文本地搜索；中文内容可搜索。手机390px可展开导航、阅读与搜索，无页面横向溢出，长代码块独立横向滚动。支持亮暗主题、代码复制。
- FR-04：平台桌面导航及手机更多提供文档中心链接；真实页面导航进入独立文档站，文档站可返回平台。文档无需平台登录，页面不读取用户词库、笔记或令牌。
- FR-05：只发布新建的公开技术文章和审核的源码片段，不直接打包现有PRD、历史交付目录、生产日志、私有原件、配置文件或密钥。所有认证示例使用明确占位符；发布内容不包含真实凭据与用户数据。
- FR-06：教程与代码绑定：关键MCP查询/覆盖实现取审定源码片段，记录相对源路径与来源版本。提供显式同步命令，不依赖CI读取兄弟私有仓库。现有PRD保留唯一来源，不复制成另一份需求正文。
- FR-07：本地文档预览和生产构建命令明确；常规构建/镜像/CI同步携带文档产物，文档构建失败不发布。子路径静态资源、深层地址刷新、未知页404正确，不能回退到学习平台SPA。
- FR-08：现有PWA不得把 `/docs/` 导航拦回旧平台首页；电脑端提供现有更新机制的可见提示，沿用活动锁与用户确认，禁止强制中断学习。保持手机更新提示单份显示。
- FR-09：发布仅增量更新前端与文档静态资源，不重启后端或数据库、不改变业务数据；保留HTTPS443、证书挂载、续期和现有MCP配置。生产验证文档首页/深层页/404、搜索导航及平台匿名接口保护，记录回滚方法。

## 验收标准

### 验收

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

- AC-01：Given文档构建，when遍历栏目，then25篇正文均有知识、实现与实例，内部链接无缺失；来源外链标记，错误链接使构建或检查失败。
- AC-02：Given1280及390px浏览器，when访问/搜索query_words并展开目录，then能进入对应文章、找到代码和验证方法；刷新深层URL正常、无横向溢出。
- AC-03：Given发布产物，when扫描公开文件，then只有专用文档源和审核片段，真实令牌/私钥/环境文件不出现，内部PRD目录不能被访问。
- AC-04：Given常规前端发布，when构建镜像，then包含文档；文档深链不受SPA或PWA接管；后端/管理资源/HTTPS保持正常。

具体选择VitePress稳定版、公开新文章、人工确认更新为实施决定；文件上传、Word在线编辑、OAuth文档后台和多个产品/多版本文档不属于本次范围。
