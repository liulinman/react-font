# 管理端产品需求模块

> 当前研发范围：电脑端学生端与管理端，按本功能实际角色适用。移动端仅作历史范围保留，不纳入当前设计、研发与验收；混合条款中的电脑端、业务及数据保护要求继续有效。历史“后续适配移动端”等计划不再默认启动。

## 背景与目标

本需求由用户确认：独立于公开技术文档，迁至管理端并使用 VitePress 展示；必须通过管理员登录才可查看，先只做桌面版。2026-10-26 修订替代本功能上一轮学习端入口设计。

## 用户角色与使用端

当前适用端为电脑端学生端与管理端；角色权限以原条款为准。本文件含移动端历史条款，适用规则见下方历史范围标记。

## 功能需求

- FR-01：管理端导航提供“产品需求”，独立于公开文档中心；使用现有管理员权限，移除学习端入口。
- FR-02：采用 VitePress，按正式模块索引浏览、全文搜索需求，阅读 Markdown 正文和小节目录；保留原需求编号、状态和来源路径。
- FR-03：支持正式 PRD 目录内相对文档链接及锚点；不提供在线编辑。
- FR-04：整套 VitePress 产物由后端逐次校验管理员登录后提供，包括HTML、深链、JS、CSS、搜索索引、哈希映射与资源。禁止复制到公开文档或前端静态目录，成功响应禁止缓存。
- FR-05：`docs/prd/` 为唯一维护源；后端从可验证的生成快照构建私有 VitePress 站点，更新后需显式同步、构建并随后端交付。需求状态不等于实现、验收或发布状态。

## 验收标准

### 验收

- AC-01：Given 未登录、仅普通用户登录或管理员登录失效，when 请求HTML、深链、索引或资源，then 返回401且不含需求内容；有效管理员登录可读取。
- AC-02：Given 已登录管理员，when 点击产品需求，then 可按模块浏览、全文搜索、阅读原始需求及小节目录。
- AC-03：Given 正式目录内相对链接，when 点击，then 跳转对应正文与锚点；不存在文档明确提示，目录穿越请求不返回文件。
- AC-04：Given 前端生产构建，when 检查静态产物，then 不含正式PRD正文；后端镜像携带私有站点与同步快照；普通前端产物中不含PRD正文或搜索数据。
- AC-05：Given 空搜索、加载失败或失效登录，when 操作，then 展示明确提示和恢复入口；登录失效时重新登录管理端后可重新加载阅读器。

> 历史范围标记：以下原文涉及的移动端界面、适配、专项测试及移动端后续计划仅供历史追溯；其中共用业务规则、账号隔离、原文与数据保护仍适用于当前电脑端/管理端。

本期不增加手机入口，不在线修改PRD，不自动发布部署。

## 2026-10-28 只读交付产线

用户确认扩展现有产品需求入口，左侧模块/功能，右侧 PRD → Spec 正文 → 用例 → 测试结果。

- FR-06：按正式模块/功能分类查看各环节是否齐全，阅读 PRD 和 Spec 正文；不纳入 plan/tasks，不提供编辑、生成或执行按钮。
- FR-07：查看验收条款对应的用例、具体断言、最近结果和历史运行；支持失败原因、截图、分析及对应 Cloud 记录。
- FR-08：标明需求、规格及受测代码版本；新需求不得沿用旧版本通过结论。缺规格、未覆盖、未执行、环境阻塞及缺失归档分别展示。
- FR-09：仅经显式归档的白名单资料进入管理员保护目录；不暴露仓库根、原始日志、密钥或浏览器存储，不自动发布。

- AC-06：选择模块与功能后可依次打开 PRD、Spec 正文、Case 和结果；没有资料显示真实空态。
- AC-07：切换历史运行能查看当次条款结果、失败原因、分析、可用截图及 Cloud；保留首次失败。
- AC-08：来源摘要改变显示过期；缺版本显示无法核对；draft、mock、未执行和缺失结果不算通过。
- AC-09：匿名、普通用户、过期管理员无法读取产线 JSON 与截图，合法管理员可读取且禁止缓存；路径越界和符号链接不能导出文件。
- AC-10：加载中、加载失败、重试、无匹配功能和登录失效均可辨识；保留原 VitePress 阅读入口。
