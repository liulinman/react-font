# AI 场景听力与服务管理

## 目标与边界

词库记录可能存在拼写或释义错误，现有单词发音听感不佳，单一默写难以帮助用户理解场景。本功能让用户使用自己的词库完成“直接看词复习 → 听新场景填空 → 查看反馈 → 后续复查”。DeepSeek 校验词条和生成内容，豆包合成包含答案的完整句子或对话。

用户于 2026-10-22 确认该流程、去掉本流程独立默写，并要求同时完成 PRD、审核、研发、测试、发布。本文不删除既有独立学习模式、阅读、笔记等功能，不把新流程的简化扩展为全站删除默写。正式生产发布遵循实际环境与发布权限，文档 final 不代表实现或上线。

主要角色：学生在桌面及移动端学习；管理员在现有管理平台配置两家 AI 服务。用户不需提供个人 API Key。词库所有权与现有分享权限继续生效。

## 核心旅程与状态

学生选择有权限的现有单词，系统核对其词义和版本，展示可直接阅读的词卡。完成看词后生成新场景；页面仅展示场景说明和留空的句子。音频准备成功后由用户点击播放，听到含完整答案的句子或双人对话。用户填空、提交，看到规则判定及解释，学习记录保留后用于复查。

状态：`待校验 → 可复习/待确认 → 看词 → 准备场景 → 准备音频 → 可作答 → 已提交 → 已反馈`。生成失败停留在当前准备状态并可重试或跳过；播放失败不触发提交。全部词均待确认时显示原因及返回词库入口，不创建空白计分练习。

## 功能要求

以下 FR 与 AC 为稳定 ID，引用须使用 `review/ai-listening/FR-01` 等完整命名空间。除明确 P1 外均为 P0。

### 服务配置

- **FR-01 管理入口与权限**：现有管理平台新增“AI 服务管理”，分别管理 DeepSeek 与豆包。仅管理员可查看配置、保存、清除、测试或启停；未登录拒绝，普通用户拒绝，所有写操作校验管理员身份。学习接口只允许访问有权限的词条及当前用户的会话、答案、音频。
- **FR-02 DeepSeek 配置**：管理 API Key、接口地址、模型和启用状态。页面提供明确字段说明，保存后刷新仍保留非秘密配置；Key 留空代表保持原值，清除必须独立操作。接口地址仅接受受支持的 HTTPS 服务地址，拒绝本地、私网和非 HTTP(S) 地址；连接测试必须验证实际鉴权和模型响应，保存成功不等于测试通过。
- **FR-03 豆包配置**：管理 API Key、实际 API 所需模型/资源标识及音色、启用状态。按官方接口与账号权限展示必需字段，不根据 Key 格式推断可用。音色必须与资源匹配，允许保存未通过测试的草稿但不能标记可用；提供固定英文短句真实合成试听。双人场景可以分别指定两个已验证音色，未配置两个声音时可使用明确标识的单声对话。
- **FR-04 秘密生命周期**：Key 服务端加密持久化，加密主密钥独立配置；缺少主密钥拒绝保存秘密，不降级明文。读取仅返回 configured、掩码和非秘密字段，保存/测试响应、日志、错误、审计和浏览器存储不得包含明文。更换/清除后新请求立即使用新版本，清除后不可继续用旧凭证发起请求。记录操作者、时间、动作、结果和版本，不记录秘密。
- **FR-05 测试、开关及额度**：分别展示未配置、已禁用、待测试、可用、测试失败。测试显示时间和认证失败、权限/模型、限流、额度、超时、服务异常等可操作原因；原始敏感上游报文不得直接展示。测试调用明确告知会消耗供应商用量。DeepSeek 禁用不阻止看词；豆包禁用不以浏览器低质量朗读伪装正式音频成功，显示暂不可用。缓存音频仍可播放，禁用阻止新合成。

### 词条可信与复习

- **FR-06 词条校验**：DeepSeek 核对拼写、词性、目标义项、例句匹配，返回可用、疑误或无法确认及理由/建议。保留原始记录，AI 不静默改词。疑误/无法确认不进入计分题，用户主动确认或编辑后产生新版本并重新校验；主动确认不等于替代 AI 校验通过。内容、词义或词性修改后原校验及生成结果失效。AI 拒绝、格式损坏或服务失败不能被标为校验通过。
- **FR-07 看词复习**：学生从现有词库选择有权限的单词，查看英文、目标义项、词性、已有音标和简短例句，点击发音。看词完成后进入场景听力，无独立中文到英文默写步骤。没有音标等资料时不编造资料。学习批量有明确数量和进度，单词无法使用时列明原因。
- **FR-08 统一单词发音**：桌面与移动词库、复习中单词发音走同一豆包服务，显示准备/播放/失败状态，支持重播。以词义、词性和必要上下文处理多音词，不仅凭拼写认定唯一读音。切词或离开页面停止旧播放；重复点击不叠加播放。发音失败可重试且不改变掌握记录。

### 场景与听力

- **FR-09 受约束生成**：DeepSeek 根据选中的可用词条及义项生成新的短场景、完整英文句子或对话、目标词形、空缺位置及反馈说明。不得复用刚看过的例句充当新场景。每题明确关联词条 ID 和版本，目标词必须实际出现在完整台词并与当前句意一致。支持原词、合理屈折变化及同词族的常见派生形式，随机偏好并在不适合变形时回到原词；答案使用句中实际词形。派生词需独立确认词族关系、相关核心语义和词性变化，禁止以近义词或无关词替代。作答后说明原词与本题词形的关系，提交前不返回词形说明。首版每题一个空缺、多题覆盖所选词；无需强行把所有词放在一个不自然的场景。
- **FR-10 内容门禁**：服务端验证非空、长度上限、结构、目标词关联、空缺唯一映射、台词与答案一致性，以及明显词义冲突。AI 自称“已校验”不能绕过结构门禁。失败可在限额内重新生成；仍失败显示原因，不进入计分。词条文本当内容处理，不执行其中提示指令；不向供应商发送密钥或无关用户资料。
- **FR-11 完整音频与播放**：播放入口使用有无障碍名称的图标按钮，慢速入口用0.8×表示，按钮之间统一间隔。中文场景默认不展示，学生可主动展开/隐藏中文提示，提交后自动展示；中文提示不等于揭示英文答案。发送豆包的是含答案的完整台词，不朗读下划线、角色标签或提示说明。准备成功后显示播放入口，由用户点击开始；支持重播和慢速。双人音色按角色保持一致。音频生成失败、空文件、无声/不支持的音频应显示失败，保留题目和输入并允许重试/跳过，不记错。实际发音准确性和自然度必须用真实样本试听验收，不能只验有文件。
- **FR-12 答案揭示边界**：首次提交前，学习页面和返回给客户端的题目数据不包含完整台词、标准答案、答案词形或解释；gap 不暴露字数长度。完整台词仅供服务端合成，音频允许包含答案，这是听力任务本身。查看答案须作为独立揭示动作记录，已揭示题不计首次独立答对；开发者检查网络响应也不能直接取得文本答案。已学词表本来可见，不宣称防止用户查词或转写音频。

### 判题、反馈与持续学习

- **FR-13 提交与判定**：按服务端保存的题目版本及句中词形确定答案，忽略首尾空格和大小写；内部拼写、词形错误不自动算对，不由 AI 临时改变计分规则。未播放/未填内容不能默默提交为错误，显示提醒。首次提交产生稳定结果；重复请求幂等，不重复累计掌握或错误次数。已提交后可再练但保留首次结果、尝试次序、播放次数、慢速和揭示使用记录。
- **FR-14 反馈与辨析**：提交后显示用户答案、标准答案、完整台词、目标义项及简短解释。系统可确定的拼写/词形错误与听辨练习结果分开呈现，不凭错误拼写断言用户“没听清”或“不理解”；允许学生选择原因。按需展示两三个近义词在当前语境的差异，明确其他表达可能合理，但本题练听到的原词。解释生成失败不丢失规则判定，允许单独重试。
- **FR-15 持久化和恢复**：保存会话、词条版本、场景版本、音频配置版本、首次及后续作答和反馈；刷新/重新登录恢复本人进度。生成/播放/内容故障单列为系统事件，不计学习错误。已提交记录跨桌面和移动可见；复查入口展示需要再练的词并生成新场景，记录听力成功不自动宣称主动表达掌握。具体复查间隔沿用现有调度，未配置时显式提供“再练”，不得宣称已设置自动提醒。
- **FR-16 并发与缓存**：相同文本、口音、模型、音色、语速和词义/读音版本复用持久化音频；变更任何影响发音因素不得误命中旧内容。并发相同合成合并为一个上游任务；生成、提交和重试均有请求身份及状态，刷新、双击和网络重发不重复计分。过期内容、失去权限的词或会话不能通过音频链接越权取得。用户原始输入不得作为缓存文件路径。
- **FR-17 成本与失败恢复**：服务端限制单次文本长度、每组词数、用户请求频率、并发、超时、最大重试数及日用量上限；达到上限拒绝新付费请求并解释，不无限重试。管理员可见本地累计请求、字符/token用量（有供应商返回时）、缓存命中、失败和限额；无准确报价时不显示伪造金额。超时任务幂等恢复，无法确定上游是否已收费时显示状态未知，不以无限重发处理。预算/频率限额必须由后端执行。

## 非功能要求与发布门禁

- **NFR-01 安全与数据**：供应商密钥只留服务端秘密存储；非秘密配置可审计，返回错误脱敏；传给 AI 的仅为本次必要词条和学习内容。自定义接口地址不得成为访问内网的代理。秘密填写与更换只允许 HTTPS 或 SSH 隧道的 localhost 管理入口，公网 HTTP 不传输 Key；本次可用安全本地入口满足，无需扩大为全站 HTTPS 改造。
- **NFR-02 可用性**：所有准备操作均有可见状态和有限等待，刷新不丢已提交记录；上游不可用时仍可看词，明确哪些功能不可用。移动端输入、播放器和提交按钮无需横向滚动可用。
- **NFR-03 观测与回滚**：以请求 ID 关联生成、缓存、播放故障和提交，记录版本但不记录秘密；功能开关可停用新流程并保留学习数据。数据库变更需迁移验证和回滚/兼容方案，不破坏现有记录。
- **NFR-04 发布验证**：发布前完成权限与秘密、供应商契约、幂等/并发、持久化、失败恢复测试，以及真实 DeepSeek+豆包桌面/移动整轮验收。Case 引用本文 FR/AC 并记录环境、版本、运行 ID、证据和缺口；未执行/模拟/阻塞不得标为通过。生产环境秘密只经管理页或受保护部署配置注入。

成功观察：整轮完成比例、首次填空正确率、复查表现、音频失败率与每轮用量；不预设未经用户确认的业务提升数值。反向指标：错误词进入计分、答案提前泄漏、重复收费请求和故障被误算错题，均应为零。
