# 实现与接口补充

本文记录实现约束，不构成另一份 PRD。正式需求以 prd.md 为准。

- 后端供应商调用、秘密加密、内容门禁、音频缓存和会话记录通过独立模块接入；保留现有 LearningSession 等功能，不以本地旧源码覆盖生产新版本。
- DeepSeek 使用官方兼容 chat completion 接口；实施时核对当前模型列表及账号授权，默认候选 deepseek-flash。模型可配置，不能把历史模型名视为永久可用。官方接口：https://api-docs.deepseek.com/api/create-chat-completion/
- 豆包使用官方开放接口；新版所需 X-Api-Key 与 X-Api-Resource-Id 及资源 seed-tts-2.0 以接入时官方文档和账号授权为准。UI 展示音色名称与 API 音色 ID 分开保存，不把 Zendaya 等展示名直接作为 ID。
- 音频合成接收完整台词，学习题接口返回删去答案及台词的投影。提交后返回反馈；服务器对每次读取做归属鉴权。
- 音频缓存键至少含规范文本、音色 ID、模型/资源、语速、口音、词义/读音版本；音频地址不能作为绕过鉴权的永久公共入口。
- 发布从最新生产源取增量变更，确认迁移、构建、启动、健康检查和功能回退；发布操作和证据单列交付记录。用户当前明确授权发布覆盖旧稿 Ask First 的再次确认要求，不豁免真实环境权限检查。
- 部署必须提供独立加密主密钥；已有聊天中的真实凭据不进入文件、测试、日志或文档，管理员在安全界面自行填入。真实联调若凭据/余额/权限不足应报告阻塞，不把 mock 结果替代真实通过。
- 当前公网 HTTP 管理地址不能用于填 Key；使用 SSH 隧道到 localhost 后操作管理页，或已配置的 HTTPS 地址。UI 在非安全远程地址阻止秘密提交；安全管理入口须列入发布说明。


## 2026-10-22 试听收敛

用户指出默认女声带哭腔，要求保留贴合场景的自然情绪。已确认采用同一Zendaya音色的轻微自然情绪指令版本；单词优先清晰准确，场景保留自然语气。指令作为发音因素进入缓存键，避免沿用旧情绪音频。用户认可自然语气样本，不把此认可扩展为所有多音词已验收。

## 2026-10-22 管理页视觉优化

用户截图反馈样式粗糙，要求优化。管理页改为双服务独立卡片，桌面双列、窄屏单列；统一字段间距与按钮层级，保存为主操作，清除保留危险提示；音色试听归入豆包卡片，连接结果展示易读时间，用量独立分区。仅调整呈现，沿用原权限、配置、计费提示和密钥行为。本次为局部视觉回归，不代表全 PRD 验收通过。

## 2026-10-22 学习页重排及导入来源修正

用户两张截图反馈选词和看词页不可用、信息拥挤。选词改为紧凑行式选择并显示已选数量，最多10词；看词突出英文、音标、词义与发音，校验细节可展开，下一步采用主按钮；选词、复习、听力、反馈显示当前步骤。听力输入和播放分层，窄屏单列。导入字段值“AI 批量导入”仅为来源标签，不作为例句传给校验，不写回原词；真正疑误仍不可计分。网络中断保留状态并给中文重试提示，不自动重发付费请求。


## 2026-10-22 中文提示、播放与词形拓展

用户要求中文背景默认隐藏，提交后展示或主动点击查看；播放改图标，慢速为0.8×，按钮留足间距。出题随机偏好原词、屈折变化或同词族派生词，不强迫没有合适形式的词变形；派生形式需独立语义/词族验证，提交后解释原词→实际答案及词性。扩展FR09与FR11，旧题保留原样，仅新场景应用词形偏好。


## 2026-10-22 使用限制必须可配置

用户明确要求所有此类平台限额提供管理配置。管理页编辑每用户每分钟请求、每用户每服务每日请求/字符、全局/服务/用户并发、音频/场景最大尝试数；保存后新请求生效，重启后保留并审计。前三项0代表不限制；并发1～64、尝试1～20；页面展示当前值、默认/已保存来源与字段含义。保留历史统计不清零，明确字符含规则/上下文、每日按服务端日期重置，平台限额与供应商余额分开解释。校验调用失败标为服务失败，不把额度、超时等故障当成词条疑误，不引导修改词条；兼容历史错误标为uncertain的记录。


## 2026-10-23 DeepSeek与豆包限制独立配置

用户确认应分开。管理端独立展示DeepSeek和豆包限制卡，分别保存每用户每分钟请求、每日请求/字符、单服务及该服务的每用户并发；DeepSeek单独设置场景最多尝试，豆包单独设置音频最多尝试。全局并发为公共设置。旧共享保存值继承为双方初始值，包含显式0和用户修改值；首次分组保存后独立持久化，不覆盖另一家，也不清零已有每日统计。每分钟计数和用户并发按服务隔离，全局并发仍共享；旧管理页共享保存入口提示刷新，不能再覆盖独立配置。


## 2026-10-23 播放状态反馈
播放准备状态不再在页面顶部插入文案，按钮尺寸与正文位置稳定。当前播放按钮内转圈代表加载，声波代表实际播放；自然结束、停止、失败、切换音频恢复。慢速按钮独立反馈状态，可再次点击当前按钮停止；旧响应不得更新新音频状态。实际 playing 事件只计播放一次，缓冲恢复不重复计数。


## 2026-10-23 选词体验收敛
采用紧凑词库与本轮已选区：单词整行可选，跨页/搜索保留选择及已加载词名；已选区可逐词移除或清空，支持从当前结果快速补选最多5词，总量不超过10。快速选择不宣称随机或智能推荐，也不自动创建收费AI会话。开始按钮固定在已选区，必须主动点击才校验。搜索短暂防抖并取消旧请求，加载/失败/空结果状态区分；旧结果加载期间不可选择。桌面词列表独立滚动，手机已选区在前且无横向溢出。


## 2026-10-23 题目反馈、整轮总结与记录管理
- 每次提交后紧邻操作区显示明确的正确/错误文字和符号，绿/红辅助区分；展示本次输入及正确答案，再练独立展示本次结果但不修改首次成绩。完整句子、中文解释、词形、近义词与历史尝试默认折叠。
- 一次展示一道题；编号可切换并标注首次对错/跳过，始终显示完成数。第4步学习反馈可主动进入：未全部完成显示进度并能继续未完成题，不伪称已完成；完成后展示本轮总结，可回看任意题。最后提交先保留即时反馈。
- 学习记录每页4条，继续练习/查看结果按状态命名。每条记录支持删除，确认文字明确不可恢复且不影响词库/其他记录。服务端事务校验所有权后仅删除该会话行，取消或未确认不能执行；前端失败保留记录并可重试，删除当前会话退出当前视图。发布验收不删除生产真实记录。当前历史接口最多返回最近30条，分页在此范围内；全历史检索不在本次范围。
