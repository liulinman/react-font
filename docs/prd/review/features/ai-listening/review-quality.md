日期：2026-10-22；范围：prd.md、addendum.md、用户已确认对话与旧方案；性质：文档静态复核，不是功能验收。

## 已修订的高优先问题

1. 旧方案只配置豆包，遗漏 DeepSeek 的管理和启停：FR-02、FR-05 补齐。
2. 页面隐藏 gap 但网络响应仍可能泄漏完整答案：FR-12 明确提交前返回数据裁剪、主动揭示及音频边界。
3. AI 校验失败可能被误认为通过，或修改词义后复用旧题：FR-06、FR-09 加入未确认不计分、版本失效与目标映射。
4. 缺少支付放大防护和并发语义：FR-16、FR-17 明确合并、幂等、重试与服务端限额。

## 其他修订

- 区分系统故障与学习错误；不凭拼写错误断言理解能力。
- 词库所有权、学习会话、答案与音频均鉴权；自定义接口防止访问内网。
- 单词多音、词形、慢速缓存、切词停止、桌面移动恢复纳入验收。
- 留存首次结果，近义词合理不代表等于听到的原词；解释失败不丢判分。
- 保留旧功能，采用最新生产源增量发布。复查规则沿用现状，不新增未经确认提醒策略。

## 质量维度

- 决策准备：范围、角色、状态、来源和交付边界明确。
- 实质：校验、生成、音频、作答和复查形成闭环，异常状态有退出及恢复路径。
- 可验收：稳定 FR/AC 与 P0 标识，真实供应商与模拟结果分离。
- 安全及运行：秘密生命周期、越权、答案、成本、并发和回退有明确约束。
- 未验证事项：全部为实现、供应商或部署运行事项，须在测试/交付报告给证据，禁止隐含通过。
