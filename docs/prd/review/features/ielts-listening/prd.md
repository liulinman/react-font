# 雅思听力题型与模拟练习 PRD

需求命名空间：`review/ielts-listening`。用户已授权审核后开发；交互采用用户提供的 Inspera 原型；不代表功能、题库、测试或上线已完成。

## 背景与目标

用户希望参考 Inspera 雅思听力页面，在 English World 中完成雅思形式的听音作答，重点包括填空、地图及其他考试场景和题型；最新要求为“按雅思考试的那种来，先调研，结合现有资源”。目标是形成选材料、连续听音、作答、交卷、核对及错题复盘的完整流程。

现有 [AI 场景听力](../ai-listening/prd.md) 以选词、看词、生成短场景和单空练习为主。本需求新增材料驱动的多题连续作答，不要求先看答案词表，不覆盖旧功能的 FR/AC。地图指地点、建筑或示意图标注，不是现有词汇记忆地图。

## 角色、端与范围

- 学生：选择有权限的材料、作答和查看自己的记录。
- 管理员：维护材料、题目、答案、音频、图示、来源和可用状态。
- 当前按项目约定以电脑端学生端、管理端为基线。原话提及“平板”，但其是否为设备要求尚未确认；平板适配作为待决项，不自动扩大研发范围。
- 本稿保留起草时的题型优先级供追溯，本轮以实施修订确定的六题型、单部分与全套模拟执行。需求定稿不表示功能已通过全部真实供应商验收。
- 不承诺复刻 Inspera 全部界面、接管官方考试会话、抓取受限题库、认证 Band 分数或提供正式考场平板考试。

## 官方考试依据与产品应用

雅思官方将听力组织为四部分，每部分10题，共40题，录音约30分钟且仅播一次；题目跟随录音的信息顺序。听力适用于 Academic 和 General Training。以下场景用于材料分类，题型与场景独立，不规定地图只能出现在某部分。

| 部分 | 官方场景结构 | 本产品可选的原创主题示例（非官方固定目录） |
|---|---|---|
| Part 1 | 日常生活中的双人对话 | 家具购买、租房、预约、出行报名、服务咨询 |
| Part 2 | 日常生活中的单人介绍 | 公园导览、设施介绍、活动说明、社区服务 |
| Part 3 | 教育或培训场景的讨论 | 课程选择、小组作业、导师反馈、研究计划 |
| Part 4 | 学术主题独白 | 环境、历史、科技、社会及研究讲座 |

| 官方题型族 | 需要支持的表现形式 | 核心作答行为 | 建议优先级 |
|---|---|---|---|
| 选择题 | 单选、多选 | 按要求选一个或多个选项 | P1 |
| 配对题 | 人物、特点、方案等与选项配对 | 每个题位选择字母/选项，明确是否可重复 | P1 |
| 平面图/地图/示意图标注 | 地点、建筑内部、设备或结构 | 按材料要求填词或匹配备选标记 | P0 |
| 表单/笔记/表格/流程图/摘要填空 | 预约表、商品笔记、对照表、流程、摘要 | 保留上下文结构，在指定空位填写 | P0 |
| 句子填空 | 含固定上下文的句子 | 填入符合题干限词要求的听到的信息 | P0 |
| 简答 | 依据听音回答简短问题 | 在限词和数字规则内作答 | P1 |

以上依据来自[官方格式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-listening)和[官方样题](https://ielts.org/take-a-test/preparation-resources/sample-test-questions/academic-test)。摘要填空归入填空表现形式，不另称新增官方题型。

## 用户流程与模式

建议流程（待用户确认）：进入听力 → 按部分、题型、主题和来源筛选 → 查看题目说明并检查声音 → 开始 → 听音与连续作答 → 标记疑问/跳题 → 交卷 → 看结果 → 定位原文与音频复盘 → 收集生词和再次练习。

**考试模拟：** 正式全套为四部分40题，音频仅播放一次，不提供暂停、倒带、慢速、原文、翻译或答案；读题、过渡和检查阶段以该材料的实际指令与配置为准，不叠加音轨已包含的等待时间。机考结尾检查时间按官方资料为2分钟，不套用纸考10分钟誊写。单部分练习明确标“单部分模拟”，不得算完整考试。模拟需主动开始，开始前说明规则。

**专项训练（建议）：** 可选择单部分或题组，允许暂停、重听、慢速；提交或主动揭示后才能看原文和解析。记录辅助行为，首次一次听、反复练习、查看答案后的订正分开统计；不把训练结果标为严格模拟成绩。模式开始后固定，不在中途切换以改变本次计分口径。

FR/AC 为本功能独立稳定编号。P0/P1 是讨论建议，不是已批准发布范围。

| ID | 优先级 | 需求与可观察行为 |
|---|---|---|
| FR-01 | P0 | 材料列表支持题型、部分、主题、来源和完成状态筛选；展示题数、音频时长、可用模式、原创/官方/导入标识，无可用材料时显示空态，不用生成中内容冒充成题。 |
| FR-02 | P0 | 材料含标题、语言、部分、音频、题组、题号、说明、答案规则和版本；图示题有图及稳定题位对应。发布前须验证音频可播放、答案对应完整、题号唯一，题干与答案一致；未准备好不允许开始计分。 |
| FR-03 | P0 | 一段材料可连续承载多个题组和题型，题号连续且与材料版本绑定；题号导航显示已答/未答/标记，支持跳转并保持输入；不得因切题而重播音频或提前揭示答案。 |
| FR-04 | P0 | 填空保留笔记、表格、流程及句子上下文，每组显著展示英文限词/数字指令；输入可含多词、数字及单位，不统一限制为单词。保留用户原始答案；输入不因自动修正改变。 |
| FR-05 | P0 | 地图/平面图/示意图保持方向、图例、题号及题位对应；依据题目支持字母配对与文字标注。允许放大查看并能复位；缩放和窗口变化不让标记错位。无须在静态地图上模拟真实导航。 |
| FR-06 | P1 | 单选可替换和清除；多选显示需选数量，超选提醒；配对明确重复使用规则。拖拽有点选和键盘替代操作，不能以拖拽作为完成题目的唯一手段。 |
| FR-07 | P0 | 模拟模式音频准备好后由用户主动开始，禁止用户控制暂停、跳播、倍速和重播；播放、阶段与时间状态一致，结尾进入检查再提交。音频故障/断网/刷新打断时保留答案并标中断，重听后不再标严格一次听成绩。 |
| FR-08 | P0 | 训练模式支持正常播放、暂停、重播及慢速；切换材料停止旧音频，不叠播。复盘可按题定位已核实的音频片段；无准确时间定位时提供整段重听，不伪造精确定位。 |
| FR-09 | P0 | 交卷前显示未答数并允许返回；未答可以交卷并按未答计零。交卷后固定首次结果，重复提交不重复累计；到时冻结当前输入并提交；网络失败显示待提交，恢复后提交冻结快照且不能修改。无法核实截止快照时标异常模拟，不显示虚假成功。 |
| FR-10 | P0 | 按该版本的标准答案、允许变体、限词/数字和评分键判定，去首尾空格并忽略大小写；不自动接受同义词、丢失单位或错误词尾。拼写与语法要求按题目规则，疑似答案问题可反馈复核，AI不能临时改变首次成绩。 |
| FR-11 | P0 | 结果展示总分/可计分题数、未答及逐题原答案、标准答案和判定；完整材料可显示 /40，部分或混合训练按实际题数。不以简单比例生成官方 Band；如以后显示估算，必须注明参考范围和非官方结果。 |
| FR-12 | P0 | 提交后提供可用的英文原文、答案证据、中文解释和错题回听；缺原文时明确暂不可用，不生成文字冒充录音原文；区分未作答、拼写、限词、数字/单位等规则事实。听不出、词不认识、跟丢、定位错误由用户自选或标AI建议，不从错答武断推断原因。 |
| FR-13 | P0 | 保存材料版本、模式、答案、首次及后续结果、播放/辅助记录、标记、提交及中断状态；刷新能恢复本人已保存进度，提示最后保存状态。新版本不覆盖历史卷，训练再练创建独立尝试。 |
| FR-14 | P0 | 题库维护支持草稿、校验失败、可发布、已发布、停用；修改已发布材料生成新版本。音频、题目、评分键及适用图示为计分必需；原文与时间定位为复盘字段，按实际具备情况校验；无发布权限不得维护公共题库。 |
| FR-15 | P0 | 开始前客户端只获取作答所需题干、选项、音频及图示，不获取答案、完整原文或解释；服务端校验记录归属，其他用户不得读取私有材料、答案和记录。题目自身合法展示的文字不算泄露答案。 |
| FR-16 | P1 | 错题词可经用户选择进入已有词库/笔记流程，保留来源；不批量静默写入、不覆盖已有词条，也不把整段听力正确等同于其中每个词已掌握。 |

### 判题边界

- 例如题干空后只有 `old`，实际答案需 `12 years` 时，只填 `12` 不足；题干已提供单位时不能重复要求单位。
- 长度与高度同时出现时，判对应属性的答案；不得仅因录音出现过某数字就算对。
- `NO MORE THAN TWO WORDS AND/OR A NUMBER` 与 `ONE WORD ONLY` 需要不同规则；连字符词的计词按官方说明。标点、数字写法、英美拼写及允许单位变体在材料发布前形成显式评分键。
- 多选/配对的每个分值单位须在材料中明确；全套总分40。缺少评分键的导入材料只可浏览，不得宣称完成自动计分验收。
- 主动看答案后保留原始答案和揭示事件，订正记录与独立成绩分开。

### 题源方案（尚未决定）

1. 官方公开样题：首选规则与交互参照；可先提供外链练习，站内收录需核实授权、素材完整性与可用性。
2. 管理员或用户导入：需音频、题目、评分键和图示；原文、时间定位如缺失应明确复盘能力受限。个人导入和公共发布的权限边界需确认。
3. AI 原创：沿用 DeepSeek 和豆包作为候选服务，必须生成完整材料并核验音频、台词、题干、答案及图示一致性；标明“原创模拟”，不能标“官方真题”。现有短场景生成不保证能直接生成四部分40题。

地图原创材料另需验证：路线与空间关系自洽、题位唯一、描述和答案一致；仅生成一张看起来像地图的图片不算合格。AI 出题与人工复核的发布门槛、费用上限留待决定。

## 异常与非功能约束

- 音频不可播、图示缺失、题目未就绪时不得开始正式计时；保存失败显示未保存状态，保留本地输入以供重试。
- 模拟中切后台、网络故障或设备中断的计时和音轨恢复政策须明确；本稿建议恢复为“已中断模拟”，不补造连续播放证据。
- 桌面键盘可完成答题、题号跳转及交卷；焦点可见，结果不只用颜色区分。地图有文字题号和非拖拽作答入口；替代说明不能提前透露空间答案。
- 不请求麦克风权限；本需求是听音作答。既有AI服务秘密、额度和并发保护继续生效。
- 性能阈值与支持浏览器待设计前确定；应记录实际首播等待、卡顿和保存失败，而非以音频文件存在判定体验通过。
- 衡量首轮完成率、音频故障率、未保存次数、填空/地图独立正确率和同题重练增益；区分熟题、未练题及辅助使用，不用重练高分证明首次能力提升。数值目标待确认。

## 验收标准

以下为候选验收全集。专项版仅验用户选定的题型和训练规则；完整模拟版另适用 AC-05 与 AC-14 全套要求。用户选定范围前，不将本表作为发布门禁。

| ID | 对应需求 | 可复现验收 |
|---|---|---|
| AC-01 | FR-01/02 | 列表按题型和来源筛选；缺音频、缺答案或图示错配的材料不能发布/开始计分；展示明确原因。 |
| AC-02 | FR-03/04 | 同一音频的笔记、表格及句子题间切换，答案和标记保留；多词、数字、单位输入不被强制截成一个词。 |
| AC-03 | FR-05 | 用真实可播放地图题完成字母配对及文字标注；放大、复位、调整窗口后题位对应不变，可更改或清除答案。 |
| AC-04 | FR-06 | 分别完成单选、多选、可重复及不可重复配对；鼠标与键盘均可作答，超选有提示。 |
| AC-05 | FR-07 | 一套四部分40题模拟只播一次，无暂停、倒带和倍速；阶段与音轨一致，结尾检查2分钟，不增加纸考誊写时间。 |
| AC-06 | FR-07/13 | 模拟中断/刷新后找回已保存答案，记录中断；允许重听时结果不能显示严格一次听已完成。 |
| AC-07 | FR-08 | 训练可暂停、慢速、重播，复盘时间定位命中正确音频；无时间标注时明确退回整段重听。 |
| AC-08 | FR-09/10 | 未答提示后可交卷；空答零分；大小写及首尾空格不影响正确；超限、缺必要单位、错误词尾按评分键失分。 |
| AC-09 | FR-09/13 | 双击、超时重试与到时交卷不产生多个首次结果；最后输入保存失败后到时，冻结输入并待提交，恢复后回读与冻结快照一致；无法核实快照则标异常。 |
| AC-10 | FR-11/12 | 部分题按实际分母展示，全套显示 /40；错题展示原答案和证据；未确认错因标建议；不伪称官方 Band。 |
| AC-11 | FR-13/15 | 首交前网络数据无原文和答案；用户A不能读取用户B的私有材料/记录/答案，材料更新不改变旧卷结果。 |
| AC-12 | FR-14 | 有权限者可维护、校验、发布和停用，普通学生直接请求管理操作也被拒绝；草稿不能出现在公共可做列表。 |
| AC-13 | FR-16 | 主动收集一条错题词进入既有流程，重复词遵循覆盖确认；取消操作不新增或改词。 |
| AC-14 | 全文 | 验收使用完整真实音频材料，覆盖四部分及六题型；缺题源、mock、未执行、只看文本或仅有文件都不得记为真实听力通过。首期若裁剪范围需同步修订发布标准。 |

## 本轮实施范围与审核修订（2026-10-28）

用户确认 Inspera 为交互原型并授权审核后开发，强调完整闭环。基于此委托，执行以下明确默认值：

- 首要题源为AI原创，复用已配置DeepSeek与豆包；管理员可导入完整JSON原创材料包并发布/停用；不复制官方素材。学生生成个人材料，不自动公开。
- 六题型全部实现；支持单部分与四部分40题的原创模拟。合成内容时长由材料决定，清楚显示“原创模拟，时长与正式考试可能不同”，不声称等同正式30分钟难度。
- 学习模块独立“雅思听力”入口，电脑端；未获得明确平板重新纳入指令，平板暂不实施。考试模拟与专项训练同时提供。
- 生成材料先验证结构，再用独立AI复核台词/答案及地图一致性；音频全部准备后方可开始。按部分准备并保存进度，失败显式重试、不无限付费重发；未知付费操作遵循既有供应商保护。
- 地图使用可校验的结构化题位、道路/地标和字母选项，SVG仅用于呈现几何图形；图示与题目随材料版本冻结。
- 原创默认每部分10题，所有题位各1分；多选题拆成对应数量的编号答题位，按无序选项集计各位分数，重复选择不重复计分。完整材料总计40分。
- 模拟音频分段连续播放，每段一次；播放结束进入120秒检查。刷新/离开、中途音频错误或跳播记中断；重启播放后仍保留该标记。
- 保存使用服务端递增版本防止旧请求覆盖新输入。交卷提交当前冻结答案快照，重复请求返回同一结果；训练重练新建尝试，不改首次成绩。
- 复盘先展示规则判定、原文与答案证据；没有逐题准确时间定位时只提供整段回听。用户可复制所选词后进入既有词库/笔记，不静默新增记录。
- 本轮不提交、不推送、不部署；真实供应商联调须使用已配置服务并记录实际证据。缺凭据或运行环境时保留明确待验，不将替身结果当真实通过。
- Q1–Q5依本节默认决策落实；Q6沿用现有供应商限额，生成每次一部分、最多4部分、主题80字符、每部分台词上限6000字符、按<=1400字符分段合成。桌面以1280×800与1440×900检查；无新增业务通过率承诺。


### 审核补齐的恢复规则

生成中的材料按本人归属保留，页面刷新后从列表继续；错误后立即刷新实际失败状态并保留重试入口。单次网络响应丢失按稳定请求ID找回材料/尝试，不复制新记录。显式配音重试可能新增用量并受现有限额约束。原文与固定证据随材料保存，评分成功不依赖另一次解释生成；若以后增加AI解析，其失败须独立重试且不能回滚分数。同题重练标明熟题，新题需主动重新生成。

列表本轮展示最近50份可访问材料与50次作答；在当前列表内按部分、题型、标题和就绪状态筛选，来源在每项标注；全历史分页与更多题库运营功能为后续扩展，不宣称全库搜索。正式计分材料发布前全部音频准备好并记录实际时长，缺少真实音质检查的材料不得据自动测试宣称供应商音质已验收。


### 地图内容生成的审核结论

真实供应商试验发现让模型独立生成地图坐标、路线和答案会产生方位矛盾。正式生成流程改为：AI生成同一场所的十个不同地点名与开场/结束语；服务端建立唯一场景图，从该图生成题位、方位句与答案，另行确定性校验路线。独立AI只复核地点名和背景语言，不重算已验证的几何；导入的任意材料仍须完整结构和一致性复核。历史方案混合Part2为7个地图题位和3个活动日期配对，全部编号合计10分；2026-11-04批准的多样性修订替代新材料的固定配比，旧材料保持原样。当前语音使用已配置音色单声合成，不宣称双人角色音色已实现。

雅思内容调用使用专用JSON模板，最大输出12000 tokens、超时90秒；供应商并发租约覆盖超时并留余量。内容每部分准备次数遵循DeepSeek已有场景尝试上限，音频重试遵循豆包已有上限及日用量；不能通过自动无限重试越过预算。

### 主题选填契约修订（2026-10-29）

用户最新要求主题选填。省略topic、空字符串或仅含空白时，服务端按所选IELTS Part和题型选择符合该部分场景的默认主题：Part1日常服务双人沟通，Part2公共场所单人介绍，Part3学生课程/研究讨论，Part4学术主题讲座；地图题选择可呈现设施或空间的相应场所。完整四部分分别选择不同场景，不将同一个空白主题用于四段生成。

指定主题时去除首尾空白并保留用户主题，四部分都以该主题为出题背景，同时仍遵循各Part的场景要求。topic只能是字符串或省略，原始字符串最多80字符；null、数字、数组、对象或超过80字符拒绝。该上限不因自动默认场景而扩大用户输入范围。

每部分实际主题在材料创建时保存在sectionTopics中；后续准备、显式重试与稳定requestId找回沿用首次保存的选择。历史草稿没有sectionTopics时，在下一次供应商调用前一次性补齐并持久保存；generationPrompt和mapContentPrompt均读取当前Part已保存的主题。不额外调用AI选择主题，不增加付费调用或改变已有尝试上限。默认主题只是生成输入，仍需原有结构、独立语义和真实音频校验，不因采用规范场景直接判定材料验收通过。

补充验收：省略/空/空白三类请求均能创建材料；full的sectionTopics含1–4四个不同场景；单部分地图与填空按题型使用不同适用场景；显式主题和80字符边界被保留，非法类型/81字符拒绝；生成与地图两入口在失败重试时实际收到同一已保存Part主题，首次结果与既有版本规则不变。

自动场景细化：每Part分别维护4个常规场景与4个空间/地图场景，共32个已策划候选。地图题使用空间场景；mixed的Part2也使用空间场景，其余题型使用对应Part的常规场景，不为学术Part拼接“预约笔记/服务选择”等跨场景后缀。新材料使用crypto安全随机在各Part候选中选择一次后保存；不承诺连续两次不同。幂等请求读取首次已保存材料，失败重试沿用已保存主题。目录与随机选择仅用于输入多样性，不代表材料质量自动通过。
