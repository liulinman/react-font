# 独立需求评审：雅思听力闭环

评审日期：2026-10-28。对象：同目录 prd.md。仅评审需求，不代表代码或真实服务验收。

## 结论

题型、四部分场景、模拟与训练边界、答题与恢复原则已覆盖，官方机考结尾2分钟规则未见误述。当前稿仍是上一轮讨论状态，尚不足以直接作为本轮开发基线；需同步本轮授权，并补齐AI材料生成、整卷就绪、音频失败恢复和复盘再练的明确行为。

## 重要发现

### R-01 高：本轮开发授权与正文范围未同步

正文仍称“未批准开发”，六题型含P1、题源未决定、服务仅候选；本轮交接输入已明确采用电脑端、AI原创首要题源、六题型、单部分与四部分，使用Inspera为原型并复用DeepSeek/豆包。照现稿实施会出现范围和验收依据不一致。

建议：保留历史决策，在本轮决策日志登记来源；更新正文为已授权范围和明确假设。将六题型纳入本次范围，禁止官方材料复制；导入与分享若未授权应明确后续范围。Inspera仅已实际观察的交互可记作来源，未观察部分标设计决定。

### R-02 高：AI原创为首要题源，但缺少用户生成入口及可恢复任务流程

FR-01从材料列表开始，FR-14偏公共题库管理；未定义谁发起生成、选哪些参数、生成中如何等待/离开/恢复、失败是否收费重试、结果归属。现有AI服务配置复用不等于已有雅思生成流程。

建议新增FR/AC：学生选择单部分/整卷、主题和模式后发起；DeepSeek生成并校验材料，豆包合成完整台词；展示准备状态，刷新恢复同一任务，重复点击不重复创建；失败保留已成功阶段，允许有限重试或退出，不能生成半套就开始计分。个人生成默认本人可见，公共发布走独立管理权限。沿用已有实际限额与错误分类，并覆盖禁用、额度、超时、格式损坏和不支持音色。

### R-03 高：缺少整卷与音频一致性的发布门槛

FR-02校验题号和答案，尚未明确AI整卷必须四部分各10分值单位、主题与说话结构正确、答案在完整台词中有唯一证据、地图路线与图示一致。只做JSON结构通过仍可能出现听不到答案或地图无法解的题。

建议：定义材料包就绪门槛：单部分10题；整卷四部分共40分值单位；题组可混合但不要求每套必含所有题型；全题库验收覆盖六族及约定表现形式。完整台词、评分键与对应图示须一致，语音不得朗读角色标签/空格或省略答案。音频时长和读题阶段需真实匹配；过短原创不得标成约30分钟的完整考试仿真。语义核验、地图空间核验与真实试听各有证据，不能用AI自称校验通过替代。

### R-04 高：四部分开始前的就绪与切段失败政策不完整

FR-07称音频准备好才开始，但未界定整卷所有音频是否必须预就绪。若只准备Part 1，Part 2合成失败或过期会卡住模拟；切后台、网络恢复和音轨分段时序仍留待决定。

建议：开始整卷前四部分材料和可播放音频全部就绪；声音测试使用无答案测试音，不提前播放正式材料。明确分段结束自动推进、读题/检查阶段与音轨等待不重复。若播放被系统阻止或卡顿则停止正常完成声明，保留答案并显示中断；恢复练习可继续，但本次不再计严格连续一次听成绩。AC覆盖Part 2故障和最后一段结束后的检查计时。

### R-05 中：提交结果与复盘部分失败尚未明确闭环

FR-12写提供可用解析，但未规定评分成功而解释生成失败、原文加载失败或音频回听失败时用户看到什么。若整个结果页依赖解释服务，可能已提交却无法看到分数。

建议：规则评分与首次答案先稳定保存并立即可见；解释失败单独显示与重试，不重新提交/计分，不改变旧答案与评分键；真实音频证据加载失败保留其他复盘内容。AI原创正常材料应具备原始生成台词；后续解释不得冒充录音原文。

### R-06 中：同题重练与新题再练没有明确区分

FR-13有独立尝试，FR-16只有词库收集；未明确结果页如何回到训练、哪些答案清空、已看答案材料如何标熟题、新题失败如何返回旧结果。

建议：结果页提供同材料重练和生成同类新材料两个明确动作；同题创建新尝试但保留熟题/已揭示历史，新题生成成功后才创建新作答会话，失败仍可回原结果；不修改首次成绩。覆盖完成后退出再进入历史记录、复盘回听、同题重练和新题再练全过程。

## 建议补充验收组合

1. 真实DeepSeek与豆包生成单部分材料，从等待、首次开始、答题、提交、逐题复盘到同题/新题再练，回读记录一致。
2. 四部分40题材料完整就绪后开始，跨部分播放与计时连续，结尾2分钟检查，自动交卷及断网恢复不重复计分。
3. 材料生成失败、音频合成失败、Part 2播放失败、保存失败、评分后解释失败各自恢复，不计作学习错误。
4. 六题型与多词/数字/单位、地图文字/选项标注、多选分值单位有真实样本，图示缩放不改变答案对应。
5. 客户端准备、作答、任务轮询均不提前返回完整台词、答案或解释；本人材料和记录跨用户隔离。

## 已有正确覆盖

不把官方外链可访问等同于可复制题库；不冒充官方Band；不把反复重听或揭示后的订正记作独立首次成绩；规则判定与推测错因区分；冻结截止输入并幂等提交；已发布材料版本不改历史卷。这些原则应保留。
