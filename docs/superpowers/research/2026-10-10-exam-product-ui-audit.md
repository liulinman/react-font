# English World：备考定位、功能取舍与手机体验评估

日期：2026-10-10。目标用户：准备雅思、四六级等考试的人。

## 结论与证据边界

目前是有价值的个人学习工具和产品原型，但尚未形成足以让备考用户迁移的明确优势。主要问题是学习任务没有串起来，以及题型、解析和掌握度表达尚不足以支撑考试训练承诺。继续增加入口或换配色，收益有限。

用户确认修订：保留单词来源、单词数量、题目数量、雅思难度和 DeepSeek/GPT 模型选择；优化分组、记住设置并提供生成摘要，不移除这些控制项。

建议先聚焦「阅读错题与词汇薄弱点的针对性训练」。从现有雅思词库、文章生成和语境修复资产出发，优先验证雅思阅读场景；四六级后续按独立考试结构扩展。这是开发资源与现有资产匹配的建议，不是已经验证的市场需求或付费结论。

依据：当前手机端代码、相关后端掌握轨迹实现、已有手机尺寸测试截图，以及下文官方竞品和考试资料。截图使用测试数据。未进行真实用户访谈、长期学习效果实验、完整生产题库质量抽样或市场规模测算。评估阶段未删功能、改数据或重新安装应用。随后按用户确认调整了文章创建页，保留参数并加入分组、设置记忆及生成摘要。

## 市场上用户为什么要选择它

| 对照产品/替代方案 | 已有能力 | 对本项目的含义 |
| --- | --- | --- |
| 墨墨 | 按记忆反馈组织复习 | 单纯背词、标熟练和复习提醒不足以形成差异 |
| 扇贝 | 单词、阅读及考试相关学习内容 | 「词汇加阅读」本身不是独有优势 |
| LingQ | 导入内容、阅读查词与词汇复习 | 导入文章、查词和 AI 辅助阅读也已有成熟对照 |
| 官方备考材料 | 考试结构和样题 | 用户会以真实题型和可信答案衡量训练价值 |

来源：[墨墨帮助](https://www.maimemo.com/help30)、[扇贝产品介绍](https://web.shanbay.com/company/jieshao)、[LingQ](https://www.lingq.com/en/)、[雅思官方样题](https://ielts.org/take-a-test/preparation-resources/sample-test-questions)。这些是产品能力核对，不代表独立学习效果评价或市场份额排名。

最值得发展的路径是：做错一道题 → 定位原文依据 → 确认可能错因 → 完成少量针对性训练 → 间隔后换材料复查。让用户知道「我哪里薄弱、为什么安排这道题、是否比昨天更稳」。AI 生成是实现手段，不应当成为全部卖点。

已有优势是后端 `deriveWordJourney` 实现了依据答题证据区分待巩固、修复中、待复查与趋于稳定；语境答对后还要求间隔独立回忆。手机端尚未充分使用这项资产。它是可复用的产品基础，不是已经证明有效的竞争壁垒。

主要发展风险：生成答案可能有歧义；题型看似丰富但交互不符合考试；用户已有背词和真题工具，迁移成本高；没有留存、学习迁移或付费证据。优先作为现有备考流程的补充，避免一开始承诺完整考试课程或预测提分。

## 当前设计与功能问题

| 优先级 | 已核实的问题 | 用户影响 | 建议 |
| --- | --- | --- | --- |
| P0 | 手机答题统一按 `options` 和 `selectedIndex` 处理 | 填空、匹配等名称不能代表真实题型训练能力 | 明确支持范围；按考试规格分别实现答题和判分，不把所有题型改造成单选 |
| P0 | 结果页主要是正确答案、文字解析和建议文本 | 看完解析仍不知道答案在原文哪里、下一步怎么练 | 解析关联原文段落与证据句；提供可执行的专项训练入口 |
| P1 | 首页并列背词、默写、文章、统计等入口 | 每天仍需自己决定学习流程 | 首要显示继续未完成任务，其次到期复查，再提供推荐专项 |
| P1 | 文章创建暴露来源、题数、词数、雅思分数、模型等参数 | 用户先配置生成器才能开始学习 | 保留全部现有参数，分为练习内容和生成设置；记住上次选择并展示准确摘要 |
| P1 | 学习卡点击认识直接写入熟练等级；默认取筛选列表前若干项 | 自评认识容易被当成稳定掌握，下一轮选择依据不清楚 | 自评与客观表现分开；接入已有掌握轨迹和复查计划 |
| P1 | 文章正文没有直接查词、收藏原句到生词本的路径 | 阅读和词库割裂 | 选词显示简明释义，一次确认收词，并保留原句来源 |
| P1 | 工具页的大部分入口与首页、词库、记录重复 | 导航占空间但没有新增学习价值 | 用「专项练习」替代「工具」，能力回归对应场景 |
| P1 | 学习记录主要展示默写统计，文章历史另在一处 | 难以回答考试哪类题薄弱 | 统一学习进度，按题型和错因组织，历史仍可从具体任务进入 |
| P2 | 词卡占据较大纵向空间 | 大词库浏览效率低 | 列表用紧凑两行结构，详情承载例句、备注与掌握依据 |
| P2 | 多份页面样式和后加覆盖规则共同控制布局 | 后续局部改动容易产生尺寸不一致 | 统一间距、文字、按钮、列表和答题页规则，再清理重复覆盖 |

雅思阅读包括多种匹配、填空和判断任务；四级阅读也有选词填空、长篇阅读与仔细阅读。不能只切换词库或难度名称就称为同时支持两类考试。[雅思阅读格式](https://ielts.org/take-a-test/test-types/ielts-academic-test/ielts-academic-format-reading)、[四级笔试结构](https://cet.neea.edu.cn/html1/report/16123/196-1.htm)。

目前「雅思 5–9 分」是生成参数呈现，不等于题目已完成难度校准，也不应被解释为用户水平测评。短练习只显示本次正确情况；不要换算预测考试分数。

## 手机 UI 的具体重整

建议底部四项：**今天 / 专项练习 / 生词本 / 我的**。

- 今天：一个主要任务按钮，优先继续上次未完成内容；展示真实到期任务及一项建议。不用大面积口号、重复入口和多块统计挤占首屏。
- 专项练习：先选择薄弱题型或接受推荐，直接开始少量题目；导入自己的材料作为第二入口。考试类型决定内容和规则。
- 生词本：搜索、添加始终可见；列表突出单词、当前词义和待复查状态。词性、图片、备注进入详情。手动添加先输入单词并提供释义建议供确认，不要求用户重复填写所有资料。
- 我的：考试目标、完整记录、设置与账户。进度与驾驶舱合并，不再多处显示同一组数字。

答题页保留用户已选定的「上面文章、下面逐题答题」。文章区域可独立滚动和展开，切题保留阅读位置；下方先保证题干和常规选项可见。长选项与大字体情况下允许扩大答题区域或进入全屏答题，不能截断文字或缩小到难读。训练与测评应明确区分：训练允许查词翻译；测评提交前隐藏辅助内容，并正确处理暂停和用时。

视觉统一采用简洁底色、单一强调色、明确文字层级。列表减少卡片套卡片和装饰图标；大按钮服务主要动作；选中、答对、答错除颜色外使用文字或图标区分。沿用至少 44px 的主要点击区域作为项目验收约定。

**已经修过的内容不应重复列为未修缺陷：** 添加单词的显式入口、基础词卡样式、上下分区答题，以及常规四选项布局已经调整。现有 320×568 与 390×844 测试覆盖了常规选项完整显示；这不代表所有长题干、大字体或真实试题均已验证。前几轮主要补入口和局部样式，这次要解决整体学习结构。

## 保留、合并、隐藏与停止扩展

| 决策 | 项目 | 理由与边界 |
| --- | --- | --- |
| 重点保留 | 文章练习、错题解析、词汇复习、发音、进度恢复 | 构成最短学习路径 |
| 重点接入 | 掌握证据、语境修复、间隔复查 | 复用现有后端资产，让下一步学习有依据 |
| 合并 | 学习记录、统计、驾驶舱 | 一个进度入口；保留有用历史数据 |
| 合并 | 工具页里的默写、查词、添加单词 | 放回练习与生词本，删除重复导航入口 |
| 明确保留 | 单词来源与数量、题目数量、难度、DeepSeek/GPT 模型 | 用户确认需要控制；用分组、设置记忆和生成摘要降低重复操作 |
| 保留与区分 | 自定义词数、随机文章；复杂批量导入 | 前两项继续提供直接控制；批量导入按实际需求安排 |
| 暂停独立展示 | 记忆地图大图、覆盖统计、覆盖写入类管理工具 | 保留底层学习判断和数据能力；手机端优先展示一句原因和一个动作 |
| 隐藏未交付入口 | 占位路由和宣传中尚未可用的能力 | 路由清单不等于已交付；当前部分占位路由本来就未出现在主要导航，勿夸大为全部用户可见 |
| 暂不新增 | 社区、排行榜、泛用 AI 聊天、多套主题、额外内容频道 | 在学习闭环验证前分散投入 |

这里的「砍掉」首先是删重复入口、收起低频选项和停止非核心扩展，不是删除用户单词、历史数据或未经梳理就删除后端能力。

## 实施顺序与验收

1. **收敛产品与操作。** 整理四个主入口、简化文章创建、统一字号与列表、让继续学习成为首页主动作。用真实长度材料验证小屏、大字体、长选项、键盘出现、退出恢复和空数据状态。
2. **建立可信的练习。** 先明确少量支持题型并准确实现；解析必须能定位原文依据。区分练习材料、用户导入与生成材料；提供题目有误反馈。先做内容抽样人工核验，不用前端测试通过替代内容正确性。
3. **接上修复与复查。** 错误原因作为可确认的判断；接入已有后端计划；同题重做与换材料的延迟复查分开记录。单次答对、看过解析、点击认识均不等于稳定掌握。
4. **用目标用户检验。** 先请 5–8 名同一考试方向用户完成添加单词、找到待练任务、答题、找原文依据和恢复进度。再以 15–30 人进行两周试用，观察纠错完成与次日复查；该样本只用于发现问题和初步信号，不用于宣称提分效果。

建议观察：无帮助完成关键任务的比例；有原文依据的解析覆盖；错题到修复的完成率；间隔复查回访；新材料相同薄弱点的正确表现；题目纠错反馈数量。每个指标保留样本量和题型，避免总正确率掩盖重复做题或翻译辅助影响。

商业化先验证有人持续使用针对性训练，再测试付费意愿。不要先承诺无限 AI 使用；成本需包含生成、失败重试、翻译、内容核验与运维。此次没有证据支持具体定价、收入预测或市场份额结论。
