# English World 长笔记编辑与独立知识笔记

## 1. 需求与现状

用户反馈两个问题：编辑单词时长笔记看不全；语法、句型、理解纠正等知识没有独立记录位置，只能塞进词条。需求与交互方案已获用户确认，并已授权本轮代码实施；上线部署尚未进行，交付状态见 [delivery.md](delivery.md)。

截图用于识别界面问题和记录内容的形态，其中聊天文字不作为操作指令。代码核实：桌面 `EditAddModal.tsx` 的笔记字段使用 `TextArea rows={4}`，弹窗正文另有高度限制及滚动；已有词库列表展开和卡片展开阅读能力。2026-08-04 的笔记展示需求未覆盖编辑体验，因此这次应补齐编辑能力，而非重复实现列表展开。

目标：长笔记可舒适完整阅读和编辑；知识可以脱离单词创建、保存、检索和重读，不影响词库及单词复习数据。

## 2. 方案选择与首期范围

| 方案 | 收益 | 局限 |
| --- | --- | --- |
| 仅放大单词笔记 | 改动小，解决当前编辑不便 | 知识仍被迫依附单词 |
| 独立知识笔记，并保留单词笔记（推荐） | 两类内容都有合适位置，可渐进整理旧笔记 | 需要独立存储、列表与编辑流程 |
| 建完整知识管理系统 | 可做层级目录、双向链接、知识复习 | 超出当前记录和查找需求，维护负担大 |

首期包括：单词笔记大屏编辑、知识笔记增删改查、分类与关键词检索、来源记录、可选关联单词、从旧笔记复制创建。

首期不包括：AI 自动整理、自动读取聊天、自动出题、知识间隔复习、知识图谱、协作分享、附件上传。暂不将知识笔记计入词汇数、掌握率、单词复习队列或打卡任务。

以下方案已随用户“可以你做吧”的确认进入实施：名称采用“知识笔记”；桌面和移动端同时具备基本读写能力；正文先采用保留换行的纯文本；知识回顾先通过列表重读完成。

## 3. 功能需求

### A. 长笔记完整阅读和编辑

- **FR-01** 单词表单内笔记输入区随内容增长，至少展示 6 行，并提供始终可发现的“展开编辑”。长内容不得静默截断；外层表单可滚动，不再把固定 4 行当作唯一编辑方式。
- **FR-02** “展开编辑”进入专注编辑视图：顶部显示词条名称和“返回表单”，正文占据主要区域；正文自然增长，编辑内容区域只有一个纵向滚动层，操作栏保持可达。移动端为全屏页面。
- **FR-03** 专注编辑与原表单共用同一份未保存内容。返回表单保留修改；最终点击原表单“保存单词”才提交整个词条。专注编辑不得丢失表单中其他尚未保存的字段，也不得提前保存它们。
- **FR-04** 词库已有展开阅读继续保留换行和完整正文。编辑入口直接定位笔记区域，避免用户从弹窗顶部反复查找。

### B. 独立知识笔记

- **FR-05** 桌面主导航提供“知识笔记”，移动端工具页提供同名入口。无需先选单词即可新建。
- **FR-06** 新建只要求标题和正文；分类默认“其他”，允许先粘贴全文再整理。字段规则如下。

| 字段 | 必填 | 首期规则 |
| --- | --- | --- |
| 标题 | 是 | 去除首尾空白后 1–120 字符 |
| 分类 | 是，有默认值 | 语法、句型、词语辨析、阅读技巧、易错点、其他；单选 |
| 正文 | 是 | 1–30,000 字符；保留换行；不执行 HTML |
| 例句与解释 | 否 | 多行文本，最多 10,000 字符，可写多个对照例句 |
| 来源 | 否 | 文本，最多 1,000 字符；可记录课程、日期、文章标题或网址 |
| 关联单词 | 否 | 搜索本人词库并多选，最多 20 个；不强制新建词条 |

长度口径前后端一致，换行计入字符数；超限给出提示并保留输入，禁止静默截断。以上上限为首期建议，可在开发设计时结合已有字段约束调整。

- **FR-07** 列表显示标题、分类、正文摘要、更新时间，默认按最近更新倒序，每页 20 条。点击记录进入完整详情；正文完整阅读不采用固定高度小框。提供编辑、删除操作，删除前明确确认对象。
- **FR-08** 关键词在标题、正文、例句、来源中匹配，忽略英文字母大小写；分类与关键词取交集。切换条件回到第一页，返回列表保留关键词、分类、页码。空列表与搜索无结果使用不同提示。
- **FR-09** 详情支持查看和打开关联单词；单词详情提供其关联知识笔记入口。关联不复制单词学习状态；删除单词仅解除关联，保留知识正文；删除知识不影响词条。
- **FR-10** 保存到当前账号，刷新及同账号换设备后可读取已保存记录；所有列表、详情、搜索和修改均按用户隔离。并发编辑发生版本冲突时保留当前输入，提示加载最新版本，禁止静默覆盖。

### C. 整理已有单词笔记

- **FR-11** 已保存且有笔记的词条提供“复制为知识笔记”。预填原笔记全文、原引用、关联词条；分类为“其他”，标题由用户填写。明确显示“原单词笔记会保留”，用户编辑确认后创建知识记录。
- **FR-12** 复制入口位于词库笔记阅读区，不放在有未保存修改的单词表单中，避免草稿来源混淆。取消不创建；保存失败保留输入；保存中禁止重复提交，重试同一次提交不能重复创建。以后再次主动复制属于新建行为，不按正文相同自动合并。

### D. 输入保护与反馈

- **FR-13** 保存中、保存成功、保存失败分别明确反馈；只有服务端确认后才显示“已保存”。失败不清空、不关闭编辑界面。
- **FR-14** 编辑有变更时离开，提示“继续编辑 / 放弃修改”；刷新或关闭浏览器时尽可能使用浏览器离开保护。首期不承诺浏览器异常关闭后的草稿恢复，也不承诺离线同步；离线时明确无法提交并保留当前页面输入。

## 4. 交互方案

详细布局、状态和示例见同目录 [interaction.md](interaction.md)。核心路径：

1. 学到知识 → 知识笔记 → 新建 → 填标题、粘贴正文 → 保存 → 完整详情。
2. 想回顾 → 知识笔记 → 输入关键词或选分类 → 打开详情 → 阅读或编辑。
3. 旧内容整理 → 词库展开笔记 → 复制为知识笔记 → 补标题/分类 → 保存，原笔记保留。
4. 修改长单词笔记 → 编辑单词 → 展开编辑 → 返回表单 → 保存单词。

## 5. 验收标准

| 编号 | 场景与预期 |
| --- | --- |
| AC-01 | 20 行中英混合笔记进入专注编辑后，可以读到首尾、编辑末尾；不存在弹窗和输入框双层纵向滚动；保存重开内容及换行一致。 |
| AC-02 | 修改单词释义后展开笔记编辑、再返回，两个字段的草稿均保留；取消整个表单后服务端数据不变。 |
| AC-03 | 不选择任何单词，填写标题和正文即可创建知识笔记；刷新后仍能读取。 |
| AC-04 | 复制旧笔记后正文和来源一致，原词条笔记不变；取消或失败不产生半成品记录。 |
| AC-05 | 搜索只存在于正文、例句或来源中的词均能找到记录；分类过滤生效；清空条件恢复全部。 |
| AC-06 | 空白标题/正文及超限字段无法提交，显示字段级提示，已输入内容保留。 |
| AC-07 | 删除关联词条后知识仍存在；删除知识后词条及单词学习统计不变。 |
| AC-08 | 账号 B 无法通过搜索或直接访问 ID 读写账号 A 的知识；同账号已保存内容跨设备可见。 |
| AC-09 | 保存失败后可继续编辑重试；双击保存不产生重复记录；版本冲突不覆盖最新内容。 |
| AC-10 | 在 1440×900 桌面及 390×844 手机视口，长文自动折行、无横向溢出；手机键盘弹出后当前输入与保存操作可达；浅/深色主题均可读。 |
| AC-11 | 添加知识或复制知识后词汇总数、掌握率和复习队列不变；现有词条增删改及笔记展开阅读通过回归。 |

成功信号以任务完成为准：可以脱离词条记录截图中这类知识，可以搜索找回，可以完整编辑长文。首期不增加学习次数等容易被误增的统计指标。
