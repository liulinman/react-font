# 知识笔记与长笔记交互方案

状态：已确认并实施，2026-10-10。配套需求见 [prd.md](prd.md)。以下为低保真布局，不代表已上线界面。

## 1. 知识记录怎么写

采用“标题 + 正文”起步，分类和辅助字段渐进补充。正文旁提供“插入记录模板”，仅在空正文时直接填入；已有内容时追加到末尾并明确提示，不覆盖输入。模板属于可选辅助，不强制填写每一项。

推荐模板：

```text
知识点：

我的原理解：

正确理解：

容易混淆的地方：
```

以下是根据截图主题拟写的记录示例，不声称是截图完整原文：

```text
标题：find it + 形容词 + to do：it 的作用
分类：句型

正文：
知识点：在 I find it difficult to get up early 中，it 是形式宾语，
真正说明“什么事情很困难”的内容是 to get up early。

我的原理解：把 it 当作指代前文某个动作的普通代词。
正确理解：先识别 find it + 形容词 + to do 结构，
再看不定式所表达的事情，不机械地向前寻找 it 的指代对象。

例句与解释：
I find it difficult to get up early.
我觉得早起很困难。困难的事情是“早起”。

来源：雅思阅读课程 · 第 1 课 · 2026-10-10
关联单词：可留空
```

快速记录时直接粘贴整段解释即可。不要为记录这一条知识先创建一个名为“find it…”的假单词。

## 2. 桌面知识列表

```text
知识笔记                                     [＋ 新建笔记]
记录语法、句型、易错点和阅读方法

[搜索标题、正文、例句、来源________________] [分类：全部 ▾]

find it + 形容词 + to do：it 的作用                    句型
it 是形式宾语，真正说明具体事情的是后面的不定式……
来源：雅思阅读课程                         更新于 10-10
──────────────────────────────────────────────────────
其他记录……

共 N 条                                     [上一页] [下一页]
```

每条摘要最多两行，完整内容在详情阅读。只截断摘要，不截断存储内容。首次进入为空时说明“把学到的语法、句型和易错点记在这里”，提供新建按钮；筛选无结果时提供清空筛选。

列表 → 详情采用可直接访问的独立页面。返回恢复列表位置和筛选；桌面首期不引入多栏嵌套编辑器。

## 3. 完整详情与编辑

详情顶部为返回、标题、分类、编辑和更多操作，主体按“正文 → 例句与解释 → 来源 → 关联单词”排列。无值的辅助区不显示。正文自然排版，整页阅读，不把长内容限制在小卡片内。

编辑布局：

```text
[返回] 新建知识笔记                              [保存]
标题 *  [____________________________________________]
分类    [其他 ▾]

正文 *                                [插入记录模板]
┌────────────────────────────────────────────────────┐
│ 粘贴老师的解释，或写下你的理解……                     │
│ 内容随输入向下增长                                  │
└────────────────────────────────────────────────────┘

[补充例句、来源和关联单词 ▾]
```

新建默认收起辅助字段；编辑已有辅助内容时展开，避免误以为数据丢失。标签始终存在，不能只用占位文字表达字段含义。保存成功转到详情，失败留在编辑页并保留全部输入。删除位于详情的更多菜单，确认框显示标题，成功后返回原列表。

## 4. 原单词笔记的专注编辑

原表单的笔记标题旁增加“展开编辑”。进入后替换表单主体为专注编辑内容，避免叠加第二层模态框；其他字段草稿继续保留。

```text
[返回表单] preserve · 编辑笔记
修改尚未保存，返回表单后点击“保存单词”提交
──────────────────────────────────────────────────────
笔记正文……
可完整阅读、选中、粘贴、修改，保留原换行
正文自然增长，内容区统一滚动
```

桌面使用接近视口高度的编辑区域，移动端全屏。进入时定位原光标位置；返回后恢复笔记区域位置。返回表单不是取消修改；关闭整个编辑流程才触发放弃修改提示。

在词库展开阅读区，将“编辑笔记”和“复制为知识笔记”并列显示。复制跳转知识新建页，顶部提示“已复制原笔记，保存后原词条内容仍保留”。关联单词可移除，标题需补填。

## 5. 移动端与状态规则

- 工具页增加知识笔记入口，内部为列表 → 详情 → 全屏编辑，复用分类及字段语义。
- 输入字号至少 16px，触控目标至少 44px，安全区域留白；焦点和保存操作不被键盘或底栏遮挡。
- 加载失败显示重试，不能伪装为空列表；记录不存在与无权访问使用不泄露其他用户内容的提示。
- 有修改时返回提示继续编辑或放弃修改；保存中禁用重复提交，不显示提前成功。
- 不做自动摘要或改写；模板、复制和手动输入均保留用户原文。

## 6. 实施拆分建议

3. 补移动端入口、完整读写和键盘适配。
4. 实现关联单词与旧笔记复制，联调失败重试、删除及统计隔离。
