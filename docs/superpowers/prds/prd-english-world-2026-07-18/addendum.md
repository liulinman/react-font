# 技术与产品补充：Word Journey

## 采用方案

- 后端在 Memory Map 聚合层批量读取最多 12 个词最近 90 天的 `recite_history`、相关微语境任务和 attempt。
- 不新增持久化阶段表；每次根据事实推导，保证新错误可以立即回退阶段。
- 语境证据通过任务 `wordsJson` 与 attempt `resultsJson.targetWord` 关联，所有记录都必须属于当前用户。
- 返回值包含阶段枚举、面向用户的 `label/reason`、下一步动作、建议时间和最近证据，不要求前端复制规则。

## 规则优先级

1. 最新复习记录为错误 → `needs_review`。
2. 最新错误之后有微语境通过、但没有跨时段独立答对 → `repairing`。
3. 最新复习记录正确，但缺少跨时段双次正确或中译英证据 → `check_later`。
4. 最近 30 天至少跨两个本地自然日正确，且至少一次中译英，且最后一次为正确 → `stabilizing`。
5. 无历史 → `needs_review`，原因明确为“还没有独立回忆证据”。

MVP 按 UTC+8 展示自然日，后端阶段算法只使用事件间隔（至少 8 小时）判断跨日证据，避免服务器时区漂移。后续若设置页提供 IANA 时区，再升级为用户时区自然日。

## 备选方案及放弃原因

- **新增 `word_learning_state` 表：** 状态会与已有 history 重复，并引入补偿和回放问题；当前读取范围小，无必要。
- **直接复用 `englishLevel`：** 等级缺少证据语义，也可能被手动修改。
- **直接上 FSRS：** 历史量和评分粒度不足；先积累可信逐词事件。
- **在首页增加全新模块：** 会继续堆叠仪表盘卡片；Memory Map 更符合用户心智。

## 隐私与可靠性

- 新接口不返回用户原始答案，只返回正确性、方向、时间和有限标签。
- 没有任何新的 AI 调用、后台任务或定时器。
- JSON 解析失败的单条语境记录被忽略，不影响 Recite 证据。
- 接口失败时 Memory Map 仍展示基础词信息和可用行动，不伪造时间线。
