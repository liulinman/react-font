# PRD：English World 可解释词汇掌握轨迹

## 0. 文档目的

本 PRD 定义 English World 在薄弱词语境修复闭环之后的下一轮桌面端迭代。它基于[市场研究](../../research/market-english-world-word-journey-2026-07-18.md)，供产品、设计、前后端与测试直接实施；技术取舍见同目录 `addendum.md`。

## 1. 愿景

English World 已经能发现错词、安排微语境并在次日复查，但用户仍需自己推断“这个词现在到底怎么样”。Word Journey 把分散的学习记录变成一条诚实、可解释、能行动的词汇轨迹。

产品不输出神秘掌握分，也不把一次正确称为永久掌握。每个阶段都必须能回答：依据是什么、证据发生在何时、下一步做什么。

## 2. 目标用户与旅程

### 2.1 待完成任务

- 当系统再次推荐一个词时，我想知道它为什么出现。
- 完成语境练习后，我想知道这证明了什么、还没有证明什么。
- 我不想理解算法，只想看到一个可信阶段和一个最值得做的动作。
- 当记录不足时，我希望系统承认“不足”，而不是显示虚假高分。

### 2.2 关键用户旅程

**UJ-1：小林判断 `resilient` 是否还需要复习。** 小林从“今天”的记忆地图进入完整页，在弱词队列看到 `resilient · 修复中`。选中后，详情说明“答错后已完成语境练习，还缺一次至少间隔 8 小时的复查”，时间线依次列出答错和语境通过。行动中心只突出“安排间隔复查”，小林无需猜测是继续做语境还是手动标记掌握。

**UJ-2：小林查看一个没有历史的新词。** 轨迹明确显示“待巩固 · 还没有独立回忆证据”，时间线使用空状态而不是模拟事件，推荐“开始定向复习”。

## 3. 术语

- **学习证据**：已有 Recite 或微语境记录中与某个词直接关联的事实，不包含新生成的预测。
- **词汇轨迹**：一个词的当前阶段、解释、建议和最近学习证据集合。
- **阶段**：`待巩固`、`修复中`、`待复查`、`趋于稳定`之一，可随新证据回退。
- **独立答对**：在 Recite 中提交并由后端判定正确的逐词答案。
- **主动回忆证据**：方向为中译英的独立答对。
- **语境通过**：微语境题中与目标词明确关联的正确结果，不等同长期掌握。
- **跨时段正确**：同一词至少两次独立答对，且两次间隔不少于 8 小时。
- **推荐动作**：系统基于当前词汇轨迹给出的唯一主要行动。

## 4. 功能需求

### 4.1 词汇轨迹聚合

#### FR-1：为弱词批量返回轨迹

系统为 Memory Map 当前最多 12 个弱词返回词汇轨迹，实现 UJ-1、UJ-2。

**可测试结果：**

- 单次请求批量查询，不产生逐词 N+1。
- 只读取当前用户拥有的词和学习记录。
- 查询窗口为最近 90 天，时间线每词最多 5 条。
- 返回稳定阶段枚举以及中文标签、原因、推荐动作和建议时间。
- 无历史时返回真实空证据，不生成模拟事件。

#### FR-2：使用可逆阶段规则

系统依据学习证据确定阶段，且最新错误优先于更早正确。

**可测试结果：**

- 无历史或最新 Recite 为错误时为“待巩固”。
- 最新错误后有语境通过、但没有跨时段独立答对时为“修复中”。
- 最新 Recite 正确、但缺少跨时段正确或主动回忆证据时为“待复查”。
- 最近 30 天存在跨时段正确且至少一次为主动回忆、最新 Recite 正确时为“趋于稳定”。
- 新错误发生后，“趋于稳定”立即回退为“待巩固”。
- 手动 `englishLevel` 不得覆盖事实阶段。

#### FR-3：归因语境证据

系统只把明确属于目标词的微语境结果加入轨迹。

**可测试结果：**

- 任务、attempt 和词均属于当前用户。
- 只读取微语境任务，不把普通长文练习混入修复轨迹。
- 以题目结果中的 `targetWord` 进行大小写不敏感的完整文本匹配。
- 同一 attempt 同一词只生成一条聚合证据：全部正确为“语境通过”，否则为“语境待加强”。
- 损坏或缺失 JSON 被安全忽略，不影响 Recite 轨迹。

### 4.2 Memory Map 体验

#### FR-4：队列展示阶段

弱词队列每项展示阶段标签，不再用静态 `Lv` 作为主要状态。

**可测试结果：**

- 选中态、hover、键盘焦点和阶段标签具有清晰视觉层级。
- 四个阶段不能只依赖颜色区分。
- 接口失败时显示基础词信息和“证据暂不可用”，不回退模拟轨迹。

#### FR-5：详情展示解释和证据时间线

用户选择词后立即看到阶段说明和最多 5 条证据。

**可测试结果：**

- 阶段卡包含阶段、原因和建议时间。
- 每条证据包含类型、面向用户的文案和本地化时间。
- Recite 证据区分中译英与英译中；不展示原始用户答案。
- 无证据时展示可操作空状态。

#### FR-6：只突出一个推荐动作

行动中心根据词汇轨迹突出唯一推荐动作。

**可测试结果：**

- `review` 进入定向 Recite，并只携带当前词 ID。
- `context` 进入 Context Lab，并携带当前词作为自定义来源。
- `wait` 不伪造可点击学习任务，显示下一次建议时间；保留次级入口供用户自主选择。
- 主要动作的文案必须与后端 `nextAction` 一致。

#### FR-7：移除无证据的永久掌握捷径

完整页不再把“标记为已掌握”作为主要行动。

**可测试结果：**

- 行动中心不显示一键把词设置为 Lv3 的主按钮。
- 词库原有等级编辑能力不在本次删除，但不参与词汇轨迹计算。
- “趋于稳定”文案明确说明仍可能因后续错误回退。

## 5. 非目标

- 不实现 FSRS、遗忘概率、预测记忆半衰期或“最佳复习日”。
- 不新增连续打卡、提醒、社交和排行榜。
- 不新增造句、口语评分或新的 AI 生成任务。
- 不重写 Recite、Context Lab 或词库等级系统。
- 不把轨迹阶段用作医学、教育评估或考试能力结论。

## 6. MVP 范围

### 范围内

- 后端批量词汇轨迹聚合与权限校验。
- 四阶段透明规则和最近证据时间线。
- Memory Map 队列、详情和行动中心改造。
- 定向 Recite / 自定义 Context Lab 的现有导航复用。
- 单元、组件、集成回归和桌面端浏览器验收。

### 范围外

- 首页新增独立轨迹卡片：先验证完整页理解度。
- 持久化词级状态表：现有数据规模无需复制事实。
- 个性化时区设置：MVP 以 8 小时间隔定义跨时段。
- 学习效果因果声明：需要更长周期和真实样本。

## 7. 非功能要求

- 轨迹聚合 P95 目标小于 800ms；数据库查询数量不随词数线性增长。
- 任何记录归因错误或越权读取均阻断发布。
- 新 UI 满足键盘可达、可读焦点和非纯色状态区分。
- 新功能不触发 AI 调用，Context Lab 不可用时 Recite 轨迹仍可展示。
- 前端在 1440px 及以上桌面宽度保持三栏信息层级；小屏允许单列降级但不做专项重设计。

## 8. 成功指标

**主要指标**

- **SM-1：推荐动作启动率** — 从词汇轨迹点击主要动作的会话 / 查看有可执行动作轨迹的会话，先记录基线，目标首月不低于 25%。验证 FR-5、FR-6。
- **SM-2：解释可理解性** — 可用性抽测中，8/10 用户能在 10 秒内正确回答“为什么系统推荐这一步”。验证 FR-4、FR-5。

**质量指标**

- **SM-3：阶段事实一致性** — 抽检 100 个词，阶段与源记录一致率 100%。验证 FR-1 至 FR-3。
- **SM-4：轨迹可用率** — 成功返回轨迹请求 / 合法请求不低于 99.5%。验证 FR-1。

**反指标**

- **SM-C1：不得优化“趋于稳定”占比** — 阶段分布是结果，不是增长目标，防止降低规则门槛。
- **SM-C2：不得把同日一次正确称为掌握** — 任一出现均阻断发布。
- **SM-C3：新增 AI 请求数必须为 0** — 轨迹是解释层，不是新的生成消费。

## 9. 开放问题

无发布阻塞问题。真实数据达到每用户每词数百次复习后，另立项目评估 FSRS。

## 10. 假设索引

- 用户已授权本轮自主决策与实施；实现后以浏览器成果验收。
- 现有 Memory Map 是首发入口；由 SM-1 和可用性抽测验证。
