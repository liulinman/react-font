# 管理端 VitePress PRD 阅读模块

本轮用户确认将原学习端阅读器移至管理端，使用真实 VitePress。正式来源仍为 `docs/prd/`。本文件替代上轮普通用户登录后自定义阅读器方案；旧测试证据只对应旧实现。

## 实现

- 管理端增加产品需求区块与阅读器，可内嵌/独立阅读。学习端删除入口、路由和自定义正文组件。
- 后端从生成的PRD快照构建VitePress，来源文件校验SHA256。私有站点只进入后端镜像，公开静态目录不复制。
- `/api/admin/prd/` 每个请求复用AdminAuthGuard验证admin_token，所有成功响应private/no-store，路径解析限制在私有站点，不允许任意文件读取。
- 正式PRD内链接保留，范围外原件/图片不引入。VitePress管理模块导航、全文搜索、小节目录与深链。
- 不提交、不推送、不部署。

## 验证计划

- 真实AdminAuthGuard覆盖匿名、普通用户、有效/失效管理员对HTML/JS/搜索数据/映射的请求。
- 管理端组件与入口回归、前后端和文档构建、来源快照核对。
- 浏览器访问实际构建站点，验证中文搜索、侧栏、章节与深链；退出后直接资源请求拒绝。
