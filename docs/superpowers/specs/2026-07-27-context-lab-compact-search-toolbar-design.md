# AI 语境实验室紧凑搜索工具栏设计

## 目标

优化练习包列表顶部的搜索与来源筛选区域，使搜索控件更完整、单行布局更紧凑，并保持现有查询、清空和来源筛选行为不变。

## 方案

- 将 `Input.Search` 改为带前置搜索图标的普通可清空输入框，移除右侧独立搜索按钮及其拼接边框。
- 桌面宽度下使用单行工具栏：搜索框约占 45%，来源分段筛选占剩余空间。
- 输入内容继续即时更新现有搜索状态，不新增提交步骤，不修改后端接口。
- 来源筛选继续使用现有 `全部 / 薄弱词 / 核心 / 随机 / 手输` 选项，并保持各项等宽。
- 搜索或筛选生效时，结果数量和“清空搜索”继续显示在工具栏下方。
- 低于现有响应式断点时改为上下两行，避免搜索框和筛选项被压缩。

## 视觉规则

- 搜索框与分段筛选统一为 36px 高度和 7px 圆角。
- 搜索图标使用现有 Ant Design 图标，置于输入框左侧。
- 输入框聚焦态沿用产品蓝色边框和轻量聚焦阴影。
- 工具栏不增加外层卡片、说明文字或额外按钮，保持任务列表的工作台风格。

## 验收

- 桌面宽度下搜索与筛选稳定在一行，输入框不再显示独立搜索按钮。
- 窄屏下工具栏切换为两行且无溢出、遮挡或文字截断。
- 输入、清空、来源筛选、结果数量和空状态行为与现有功能一致。
- 相关组件测试通过，并通过桌面与窄屏截图检查。
