# English World 词库笔记展示优化设计

## 背景与目标

桌面词库的笔记列位于表格右侧，用户需要横向滚动后再把鼠标移到“查看笔记”上，才能通过悬浮框阅读内容。卡片模式虽然避免横向滚动，却只显示“有笔记”，仍然看不到正文。

本次优化让笔记在两种桌面视图中都能就地阅读：

- 卡片模式直接展示笔记摘要，长笔记可以在当前卡片内展开。
- 列表模式从最左侧展开当前词条的完整笔记，不再依赖右侧笔记列和悬浮框。
- 记住用户上次选择的列表或卡片模式。

本次不修改笔记字段、接口、增删改流程和移动端词库。移动端已有卡片内笔记及展开能力，继续保持现状。

## 设计决策

### 笔记判定

只有 `englishNote` 去除首尾空白后仍有内容的词条才显示笔记入口。展示时保留原始换行和正文，不修改后端数据。

### 卡片模式

卡片中的“有笔记”状态文字替换为笔记内容块：

- 内容块位于释义和学习状态下方、引用信息上方。
- 默认显示两行正文；使用 Ant Design `Typography.Paragraph` 的可折叠 `ellipsis` 自动判断真实溢出，只有内容超出两行时才显示“展开”。
- 展开后显示完整正文和“收起”，内容自然换行，不创建内部滚动区域。
- 每张卡片独立维护展开状态，允许同时展开多条笔记。
- 引用入口继续保留在卡片底部；没有笔记但有引用时，卡片结构和行为不变。
- 批量管理模式不改变笔记阅读行为，笔记按钮不会选择或取消选择卡片。

### 列表模式

列表使用 Ant Design Table 的可展开行能力：

- 展开按钮位于表格最左侧，带笔记的词条同时在单词下方显示“有笔记”提示。
- 没有笔记的词条不显示可操作的展开按钮。
- 点击按钮后，在原词条正下方显示完整笔记；再次点击后收起。
- 允许同时展开多条笔记，方便对照阅读。
- 展开内容保留换行并自动折行，不使用最大高度或内部滚动条。
- 展开区提供“编辑笔记”按钮，复用现有编辑词条弹窗并载入当前记录。
- 不启用点击整行展开，避免与文本选择、链接、掌握程度快捷编辑和操作按钮冲突。

现有独立“笔记”列及其 hover Popover 被展开行取代。`englishNote` 数据和编辑字段继续保留，其他业务字段与列保持不变。移除该列还能减少表格的最低横向宽度，但本次不重排其他列。

### 视图偏好

用户切换列表或卡片视图时，将选择写入浏览器本地存储。下次进入词库时读取该值：

- 有效值为 `list` 或 `card`。
- 缺失、不可读取或值无效时回退到 `list`。
- 存储失败不阻断切换，当前会话仍正常工作。

该偏好仅用于当前浏览器，不新增后端用户配置。

## 组件与状态边界

### `EnglishWorld`

继续负责词库视图和词条操作，并新增：

- 列表展开行的渲染与“编辑笔记”行为。
- 视图偏好的初始化与持久化。

笔记展开状态不需要跨分页持久化。换页后，已经不在当前数据集中的词条不展示；重新进入页面时全部恢复为收起状态。

### 笔记展示组件

新增聚焦于展示的桌面笔记组件，避免继续扩大 `EnglishWorld` 的渲染职责：

- 卡片笔记组件接收词条名称和正文，使用 `Typography.Paragraph` 管理两行摘要及展开/收起状态。
- 列表展开内容组件接收完整词条和 `onEdit` 回调，只负责正文布局与编辑入口。
- 两个组件共享有效笔记判定，均不请求接口、不修改数据。

卡片展开状态由每个笔记组件独立维护，因此天然支持同时展开多条；组件卸载后恢复为收起状态。

### `useColumns`

移除独立笔记列和 hover Popover。单词单元格在词条含有效笔记时增加紧凑提示，但不负责展开状态和笔记正文渲染。

### 视图偏好工具

用一个无 UI 的小型工具封装本地存储键、有效值校验、读取和写入。组件只消费 `list | card`，存储异常在工具内部降级，便于单元测试覆盖。

### 样式

新增桌面卡片笔记块、展开行和笔记提示样式，使用现有 English World 颜色变量与间距体系。长单词和长笔记必须使用 `overflow-wrap: anywhere` 或等效规则，深色主题沿用现有主题变量。

## 数据流

1. 词库接口继续返回 `WordList.englishNote`。
2. 卡片渲染器根据有效笔记决定是否显示摘要和展开按钮。
3. 列表通过 `rowExpandable` 判断是否允许展开，通过 `expandedRowRender` 渲染正文。
4. 用户点击“编辑笔记”后复用 `handleEdit(record)`，保存仍走现有词条更新请求。
5. 更新成功后沿用现有刷新流程，列表展开区和卡片摘要从刷新后的记录读取最新笔记。

没有新增接口、数据库字段或数据迁移。

## 可访问性与交互细节

- 卡片的“展开/收起”是原生按钮，提供 `aria-expanded` 和能识别词条名称的可访问名称。
- 列表展开按钮沿用 Table 的键盘交互，并为含笔记和不含笔记的行提供明确状态。
- “编辑笔记”按钮可通过键盘聚焦，不触发行收起或其他卡片动作。
- 正文保留换行，颜色对比度使用现有正文和次要正文变量。
- 收起状态只限制视觉行数；完整内容仍可通过展开按钮访问。

## 异常与边界

- `englishNote` 为 `undefined`、空字符串或仅空白字符：按无笔记处理。
- 笔记在当前卡片宽度内没有超过两行：不显示卡片展开按钮，直接展示完整内容。
- 超长连续字符串：在卡片和展开行内强制换行，不撑破容器。
- 本地存储被禁用或抛出异常：静默回退，不影响页面渲染和视图切换。
- 编辑后笔记被清空：刷新数据后卡片笔记块、列表提示和展开能力一起消失。
- 删除已展开词条或切换分页：由最新数据源决定渲染，不保留失效的展开内容。

## 验证方案

### 组件测试

- 有笔记的卡片默认显示摘要，点击后显示完整正文，再次点击后收起。
- 短笔记不显示展开按钮。
- 多张卡片可以独立展开。
- 列表中有笔记的词条可以展开，并显示完整换行正文。
- 无笔记或只有空白笔记的词条不能展开。
- 多个列表行可以同时展开。
- 展开区点击“编辑笔记”会打开现有编辑弹窗并载入对应词条。
- 切换视图会持久化有效偏好；无效值和存储异常回退为列表。

### 回归验证

- 表格中的单词链接、发音、掌握程度快捷编辑、引用和删除继续工作。
- 卡片批量选择和批量设置掌握程度继续工作。
- 桌面深色主题下笔记块与展开行可读。
- 在 1440px 和 1920px 视口确认无需横向移动即可找到笔记展开入口。
- 移动端词库笔记展示没有变化。
- 运行 English World 相关 Vitest 测试与生产构建。

## 非目标

- 不新增富文本、Markdown、图片附件或笔记搜索。
- 不自动生成、总结或改写笔记。
- 不把展开状态同步到其他设备或后端用户配置。
- 不调整移动端现有笔记交互。
