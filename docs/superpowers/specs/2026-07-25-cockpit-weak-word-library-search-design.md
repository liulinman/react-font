# 今日薄弱词跳转词库自动查询设计

## 目标

用户在「今天」页点击任意「今日薄弱词」后，直接进入词库，并只按该英文词条自动查询。目标页需要立即呈现与截图一致的状态：英文输入框已回填、其他筛选条件为空、列表展示当前查询结果。

## 交互

「今日薄弱词」中的每个词条都是可点击、可聚焦的独立控件。点击 `culinary` 后导航到：

```text
/englishWorld/words?englishWord=culinary
```

词条继续保留现有红色或橙色掌握度外观，并增加鼠标指针、键盘焦点和明确的无障碍名称。空状态「状态稳定」仍为普通标签，不可点击。

## 方案选择

采用 URL 查询参数传递目标词，而不采用路由内存状态或浏览器临时存储。

- URL 参数可以刷新、前进后退和复制复现，且目标状态可直接测试。
- 路由内存状态在刷新后丢失。
- 临时存储会把一次导航意图泄漏到后续访问，清理时机不明确。

参数名使用 `englishWord`，与词库表单字段和后端筛选字段一致，减少额外映射。

## 组件与数据流

1. `CoachSummaryPanel` 新增单词点击回调，只负责呈现可交互词条并上报英文文本。
2. `LearningCockpitPage` 接收词条文本，进行 URL 编码后导航到词库路由。
3. `EnglishWorld` 在词库页面读取 `location.search` 中的 `englishWord`。
4. 参数存在且去除首尾空白后非空时，词库重置表单，回填英文输入框，并调用现有 `search`，筛选对象只包含 `englishWord`。
5. `useWordList` 继续负责请求序列保护、分页复位、加载态与结果更新，不新增后端接口。

这一流程会清除类型、中文、时间、音标和掌握程度等其他条件，确保跳转结果只由被点击的词决定。参数缺失或为空时保持现有词库默认加载行为。

## 边界与错误处理

- 使用 `URLSearchParams` 读取参数，支持空格、连字符和短语等需要编码的词条。
- 点击不同薄弱词时，以最新 URL 参数重新触发查询。
- 查询失败沿用 `useWordList` 的现有失败处理，不新增重复消息。
- 不改变手动查询、重置、分页、列表/卡片视图和移动端行为。

## 验收标准

- Given 「今天」页已经加载薄弱词，When 用户点击其中一个词，Then 地址变为带编码后 `englishWord` 参数的词库地址。
- Given 用户直接打开带 `englishWord` 参数的词库地址，When 页面加载，Then 英文输入框显示该词并自动发起只包含该词的筛选请求。
- Given 词库地址带有空白或空参数，When 页面加载，Then 不触发无意义的空词自动查询。
- Given 用户使用键盘浏览，When 焦点到达薄弱词，Then 能识别并激活该查询入口。

- 在 `EnglishWorld.test.tsx` 覆盖查询参数回填、清空其他条件和自动筛选请求。
