# 词库批量生成语境实验室题目设计

日期：2026-08-03
状态：已完成产品确认

## 目标

用户在词库卡片视图进入批量管理、选择 3–20 个词后，可以在当前页配置雅思难度和生成模型，直接创建语境实验室练习包。任务提交成功后立即进入语境实验室，并持续看到该任务的生成状态。

## 范围

本次包含：

- 扩展词库卡片视图现有批量工具栏。
- 新增批量生成配置弹窗。
- 复用现有 `POST /context-lab/generate-task` 接口。
- 新增来自词库批量生成的语境实验室入口语义。
- 展示目标任务的等待、生成、成功和失败状态。
- 前端单元测试与一条关键 Cypress 流程测试。

本次不包含：

- 词库列表视图的批量生成入口。
- 数据库或后端接口变更。
- 题型、文章生成规则或判分逻辑变更。
- 跨页保留批量选择。

## 用户流程

1. 用户在词库卡片视图点击“批量管理”。
2. 用户选择当前页的词条。
3. 批量工具栏在“批量设为”操作前显示主按钮“生成语境题”。
4. 已选少于 3 个词时按钮禁用，并通过辅助提示说明“至少选择 3 个词”。
5. 已选超过 20 个词时，点击按钮提示“每次最多选择 20 个词，请减少选择”，不打开弹窗。
6. 选择 3–20 个词时打开“生成语境练习”弹窗。
7. 用户确认所选单词，选择雅思难度和模型，然后点击“开始生成”。
8. 创建成功后关闭弹窗、清除批量选择，并跳转到该任务的语境实验室页面。
9. 语境实验室突出显示目标任务及其生成状态；任务成功后提供“开始练习”。

## 配置弹窗

弹窗包含：

- 所选数量：`已选 N/20`。
- 所选词标签列表；内容超出固定高度时在标签区内部滚动。
- 雅思难度：5–9 分，每 0.5 分一档，默认 7 分。
- 生成模型：DeepSeek 或 GPT，默认 DeepSeek。
- 取消按钮和主操作“开始生成”。

开始生成后主操作进入加载状态，并阻止再次提交。请求失败时弹窗保持打开，保留选词和配置，显示服务端错误；用户可以直接重试。

## 数据流

词库页根据 `selectedCardIds` 从当前 `wordList` 提取词条，保留页面显示顺序，并使用 `englishWord` 组成请求：

```ts
{
  sourceType: "custom",
  words: selectedWords,
  ieltsBand,
  modelProvider
}
```

请求复用现有 `contextLabCreateTask`。接口返回 `taskId` 后跳转：

```text
/englishWorld/context-lab?source=word-library&taskId=<taskId>
```

`source=word-library` 用于区分现有的单词来源文章深链。语境实验室读取该入口时：

- 通过 `contextLabDetail` 加载目标任务。
- 将目标任务设为 `currentTask`。
- 如果历史列表尚未包含它，将它插入列表顶部。
- 保持来源文章预览和练习弹窗关闭。
- 高亮对应练习包卡片。
- 当任务处于等待或生成中时，在练习包列表上方显示活动任务状态区。
- 继续使用现有 SSE 订阅更新该任务；成功后练习包卡片显示“开始练习”，失败后显示错误。失败任务不自动复用侧栏中的其他生成条件。

未带 `source=word-library` 的 `taskId` 链接继续执行现有“打开单词来源文章”行为，保持兼容。

## 错误与边界

- 0–2 个词：不允许打开配置弹窗。
- 21 个及以上：不创建任务，明确提示数量上限。
- 创建请求处理中：禁用重复提交。
- 创建失败：保留弹窗状态和选择，显示接口错误。
- 任务详情加载失败：语境实验室显示友好提示，页面与历史列表仍可使用。
- 异步任务生成失败：显示任务错误；用户可以返回词库重新发起，或在语境实验室重新配置后生成。
- SSE 暂时断开：保留现有手动刷新能力。
- 页面切换、分页、退出批量管理继续清除选择，遵守当前批量选择行为。

## 测试策略

### 词库页单元测试

- 少于 3 个词时“生成语境题”不可用。
- 超过 20 个词时提示上限且不打开弹窗、不发请求。
- 3–20 个词时弹窗显示准确数量和单词。
- 修改难度和模型后，请求载荷准确。
- 请求处理中重复点击只创建一个任务。
- 请求失败后弹窗和配置保留。
- 请求成功后清除选择并导航到带 `source=word-library` 和 `taskId` 的 URL。

### 语境实验室单元测试

- 词库入口加载正确任务，不打开来源文章预览。
- 目标任务不在历史列表时被加入并高亮。
- 等待或生成中的任务显示活动状态。
- SSE 成功事件更新目标任务并显示“开始练习”。
- 原有 `taskId` 来源文章深链行为不变。

### 浏览器验收

使用 Cypress 覆盖：进入卡片批量模式，选择词条，打开弹窗，配置并提交，确认 URL、目标任务和生成中状态正确。

## 验收标准

- Given 用户选择 3–20 个词，when 配置难度和模型并提交，then 系统只创建一个包含准确单词和配置的自定义语境任务。
- Given 任务创建成功，when 页面跳转到语境实验室，then URL 包含来源和任务 ID，页面显示该任务的生成状态。
- Given 目标任务通过 SSE 变为成功，when 页面收到更新，then 对应练习包显示“开始练习”。
- Given 用户选择少于 3 个或超过 20 个词，when 尝试生成，then 系统不会调用创建接口，并给出相应限制反馈。
- Given 创建接口失败，when 错误返回，then 弹窗、选词和配置保持不变，用户可以重试。
- Given 用户从已有词条引用打开带 `taskId` 的语境实验室链接，when 链接不含 `source=word-library`，then 仍打开原有来源文章预览。
