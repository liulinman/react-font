# MCP笔记交互差异

featureId: notes/mcp-notes · 2026-10-28
依据：本轮用户确认与正式PRD。沿用McpAccessCard、Ant Design checkbox/Modal/Tag及现有品牌，不引入新视觉方向。

设置页创建授权的原“允许操作”增加：查询笔记、新增笔记、修改笔记、新建笔记文件夹；默认仍仅查询单词，旧授权不扩权。帮助说明已有目录自动归类、建目录和修改先确认；授权列表与审计显示新操作中文标签。原加载、失败重试、密钥仅一次显示、撤销流程复用。

对话状态示例（设计diff，无独立新页面）：
1. AI列出现有“语法/从句”目录→新建“定语从句”笔记→返回ID与目录。
2. 无目录→展示“建议新建：语法/从句，是否建立？”→同意才调用确认建目录→保存；拒绝保持草稿，不建目录。
3. 编辑→展示原正文/新正文和目录/关联词等变化→询问确认→确认才保存；冲突回读新版并重新预览。

验收桌面1440×900：checkbox标签完整、键盘可选择、提交实际notes scopes、列表标签及审计、错误不显示秘密。聊天确认行为由客户端AI执行，服务端凭证约束不能证明人类已读或同意。
