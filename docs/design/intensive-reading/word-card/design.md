# 精读浮动词卡 r01
沿用当前阅读工作台白底、绿色文字和细边框，属于已有界面的局部扩展。用户指定可拖拽卡片并授权实施，不引入新的整页视觉方向。

点击词后初始位于右下方，宽360px、距边缘16px，最大高度70vh。顶部“我的词库”作为拖动手柄，右侧关闭；标题为查询词，下方依次音标/词性、释义、笔记。笔记沿用NoteContent，缺字段有简短提示。无背景遮罩、不抢走阅读区域的滚动。手柄可聚焦，通过方向键移动，Escape关闭；关闭恢复原点击焦点。后续查询不移动卡片。

状态diff：加载→词条/未收集/失败（重试）。词条只读；高亮点击仍显示右侧笔记编辑。原文选区不触发查词。卡片内长内容滚动，拖动限制在可见窗口，窗口缩小自动收回。关联FR01–05；实际浏览器截图归本轮交付ui-review。

## r02 AI词形识别
用户明确修订查询顺序；保留原拖拽布局。加载为“AI正在识别原型并查询词库”，结果主标题为词典原型，并显示“原文词：sprawls → 原型：sprawl”。未知词只在AI确定原型且本人词库无记录时出现；AI不确定/失败分别提示并提供重新识别/重试。原句采用所点位置前后有限上下文，同词换上下文刷新内容但不移动卡片。短语不做AI改写，仍完整匹配。

## r03 发音入口
音标同行右侧复用词库圆形扬声器按钮；可访问名称含实际匹配词头。使用现有加载/重试状态，不抢走卡片拖动和关闭动作。未知、不确定或加载状态没有已匹配词条，不显示此按钮。

## r04 缺词时继续查询与收词
缺词提示下放“查询本句含义”；点击进入当前卡片内加载态，完成显示原型、本句中文简义、实际原句语境、简短用法与“AI释义，仅供参考”。确认按钮“添加到词库”，成功改为原有已收集展示及发音。已有词在其他窗口收集时直接显示已存词，不覆盖。AI不确定/失败可重试，过期提示重新查询；生成期间不显示添加按钮，添加中按钮禁用并显示状态。切词保留位置但重置此子流程，关闭后不重开；已确认的保存即使关闭仍可能完成。复用现有绿色细边框按钮，不增加遮罩或页面跳转。
