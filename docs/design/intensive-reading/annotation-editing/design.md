# 精读编辑体验局部diff r01
依据正式核心PRD FR20–22/AC13–15及本轮用户三组反馈，不更换既有品牌/三栏设计。操作路径：列表卡片→同一section内编辑→原位保存/收起；保留key/id与筛选，正在编辑项暂时保留在筛选列表。只在表单超出视野时调整右侧滚动，正文位置不动。标题/音标等词卡功能保持。

编辑标题与保存状态同行，引用最长130px内部滚动，输入约4行可调整，颜色/分类/疑问沿用原组件。输入在后台保存中继续可用，错误和重试贴近表单。只禁用提交/切换等会产生冲突的动作。关闭恢复同条编辑按钮焦点，条目不再符合筛选时恢复当前筛选按钮。

阅读区去掉READ CLOSELY、大材料标题、段落元信息与分隔留白；原文第一项从正常顶部内边距开始。顶栏保留材料名和字号按钮，原文中的真实标题保留。用户明确不要截图框内内容，不需额外视觉方向确认。仅桌面3规定视口。

## r02 巡检修复
中间卡片保存仍原位，不重排列表；输入只更新表单，正文复用已有渲染。阅读位置等待前次写入后保存，状态不伪装成功。材料库在搜索/加载显示状态，旧结果待加载完成再可点击；无匹配与空库分别提示，失败显示重试。创建中固定字段，词卡显示真实受保护错误；文章加载失败可直接重试。保持原有配色、三栏和字号位置，不新增视觉方向。
