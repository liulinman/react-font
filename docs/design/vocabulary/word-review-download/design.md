# 单词复习资料下载设计

## 桌面入口

词库工具条新增「下载单词」。点击后显示小型对话框，依次为「范围」「格式」、词数及前三条的三列表、取消和下载。沿用词库当前页勾选。未勾选时禁用已勾选选项，尚未应用筛选时禁用当前筛选。数据加载期间禁用下载，空态及失败反馈位于原来的预览位置，词库内容仍保留。

## 文件

沿用用户确认的 A4 精简样稿。最上面是一行小号 Freewing 标识和右对齐词数。下面直接是表格，英文单词加粗，单词列用竖线分隔；轻色表头和交替底色，三列名称和文件内行顺序统一。Word 表格可编辑。Excel 第一行就是表头，支持冻结和筛选。个人样稿保存在工作区 output/pdf，仅作设计参考。
