# Chrome 阅读查词与网页引用

状态：产品流程已在对话中确认，本文记录设计细节供实施前核对。

## 阅读时的操作

桌面 Chrome 中选中一个英文单词，右键选择「查本句含义」。选区附近打开一张轻量词卡，页面保持可滚动。卡片按顺序展示所选词及原形、本句中文含义、完整原句和来源页标题，标题缺失时使用域名。词卡支持 Escape 和关闭按钮。另一次查询取代上一次，迟到的结果不打开已关闭的卡片。

| 状态 | 主要动作 | 结果 |
| --- | --- | --- |
| 查询中 | 关闭 | 继续阅读，后台返回不会重新打开词卡 |
| 词库里没有该词 | 加入词库 | 创建词条并保存本次引用 |
| 已有词条，本次引用尚未保存 | 保存本句 | 保留既有词条，新增本次引用 |
| 该引用已经保存 | 查看来源 | 打开来源网页 |
| 查询或保存失败 | 重试 | 保留词和原句，准确展示失败状态 |
| 尚未授权或授权过期 | 连接 English World | 在账号页面授权，完成后可继续操作 |

英文句子和网页标题按纯文本渲染。网页标题或原句较长时卡片保持在视口内，内容区可滚动，保存和关闭仍可操作。首次连接账号时，先说明选中的词和邻近文本会发送给 English World 生成释义，用户同意后才发送。

## 词库里的来源

在桌面词条详情增加「原文出处」。每条引用显示本句释义、原句和可点击的来源标题。来源链接在新标签页打开。安全校验无法保留文章地址时，卡片提示改用文章的公开链接后重试。已有词库词条继续保有本来的笔记和学习记录，同一原形可关联多条引用。

例：先在新闻里收藏银行义的 bank，再在游记里查到河岸义。词库里仍是一条 bank，主动保存后两条引用各自保留释义、句子和来源。重试同一次保存不会产生另一条引用。

## 设计范围

用户确认了网页原地查词、一键加入 English World 个人词库、保存来源链接并保留多个主动收藏的出处。第一版建议使用桌面 Chrome 普通 HTTP(S) 网页内可选中的正文，采用本地加载方式。网页标题作为链接文案、「保存本句」作为已有词条的动作名称，属于设计细节。选区取词、词卡信息层级参考现有精读卡片，出处列表沿用桌面词库详情。
