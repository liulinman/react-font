# Freewing 教师端课堂原型

版本 r03，2026-11-11 用户确认进入研发。r03 调整班级群的视觉层级。适用电脑端教师和学生。业务来源为[教师端课堂与阅读作业 PRD](../../../prd/classroom/features/teacher-classroom/prd.md)。

打开 [交互原型](prototype/index.html)，从「进入课堂 → 邀请学生 → 以样例学生打开」开始。切回教师，打开原课堂，可对已有作业补发，或从「新建作业」完成审核和发布。原型用同一浏览器中的样例数据演示教师和学生，切换角色后可继续操作。导入和出题展示预置结果，成绩按原型中的作答更新。

## 页面与交互

| 页面 | 操作和反馈 | PRD |
|---|---|---|
| 我的课堂 | 主操作为创建课堂。列表提供课堂名称、成员数和已发布数。空列表提示建班。 | FR-01、FR-02 |
| 课堂详情 | 默认阅读作业列表。学生名单和班级群为并列入口。邀请框可复制链接、更新链接并演示学生打开。更新前确认，旧链接失效。 | FR-02、FR-03 |
| 班级群 | 老师从课堂进入，学生入班后可从结果页或「老师发的题」进入。聊天沿用 Freewing 的浅蓝与浅灰，自己的消息在右侧，其他人的消息在左侧，昵称和时间放在气泡旁。底部固定输入区，课堂标题旁的「群成员」按钮展开名单，可插入表情，Enter 发送、Shift + Enter 换行。原型演示文字消息、历史记录和班外访问提示。 | FR-12、AC-11 |
| 学生入班 | 已登录学生打开有效链接即加入，结果页显示班级和「老师发的题」入口。再次打开显示已加入，失效时提示联系老师。未登录的生产流程先登录，再回到原邀请自动入班。 | FR-04、AC-02、AC-03 |
| 作业草稿 | 左侧编辑文章、题目、答案和解析，右侧入口导入 PDF／图片或用 AI 出题。审核后进入学生预览。生产态在材料处理时保留任务状态，失败后提供重试。 | FR-05、FR-08、FR-10 |
| 发布 | 学生预览后确认课堂和接收人数。课堂无有效学生时提示邀请学生，草稿保留。生产态发现名单变化时重新确认，重试或刷新显示真实发布状态。 | FR-06、FR-07、FR-08 |
| 补发 | 已发布行可补发，只列出尚未收到的本班学生。补发后已提交人数和原成绩继续可见，接收人数按实际新增更新。 | FR-09 |
| 成绩 | 从已发布作业打开成绩，首行展示接收、已提交、未提交和平均分。表格按学生显示状态和分数。 | FR-11 |
| 学生作业 | 每份作业标明课堂，待完成时进入作答，提交后查看解析。生产态复用现有阅读工作区。 | FR-07 |

界面沿用 Freewing 标志、蓝色主操作和浅色工作区。教师作业和成员使用表格，课堂名称、作业状态和主要操作位置固定。学生预览用阅读区排版。发布与补发使用确认框展示接收范围。

原型主要演示已开通教师和已登录学生的路径。教师开通入口、邀请默认有效期、退班和移除成员规则仍见 PRD 待确认项。文件处理服务、AI 调用、真实登录回跳、跨账号和服务端权限需要实现阶段验收。
