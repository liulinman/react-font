# 浏览器业务用例

所有用例运行前独立重置测试库，主用户已有单词 `resilient / 有韧性的`。脚本：`apps/english-world/cypress/integration/core.cy.ts`。

| 编号 | 优先级 | 操作 | 可观察预期 |
|---|---|---|---|
| AUTH-001 | P0 | 页面输入账号密码并登录，刷新 | 进入今日复习；刷新后仍可操作；真实当前用户接口返回主用户 |
| AUTH-002 | P0 | 页面输入错误密码 | 显示错误，停留登录页 |
| WORD-001 | P0 | 粘贴已有词 resilient 和新词 mitigate，解析预览，确认冲突，继续导入 | AI 替身响应经过真实后端解析；确认前只有原有词；确认后新增一个词；刷新后真实查询共两个词 |
| REVIEW-001 | P0 | 开始指定单词复习，输入 resilient，快速连续点击两次提交，刷新结果页 | 仅发送一次提交请求；结果 URL 有 sessionId；刷新显示 100.00%；真实历史只有一个会话和一条答题记录 |

后端 `test/integration/core.integration-spec.ts` 同时覆盖以上核心编号，并补充 AUTH-003（退出登录）、WORD-002（空导入拒绝）、WORD-003（用户词库隔离与同词共存）、REVIEW-002（空答案拒绝）。同编号在不同层验证不同断言，以对应脚本为准。

服务端提交幂等、未提交答案恢复、真实 AI 异常联调、移动 Safari／iOS 与离线场景尚未纳入首期通过数量。以后新增用例保持“编号—业务预期—脚本”一一可追踪，历史 Bug 修复应新增针对性回归断言。
