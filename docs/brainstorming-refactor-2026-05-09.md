# Brainstorming Session: 项目重构

**Date:** 2026-05-09
**Objective:** 重构 react-font 项目：样式架构、代码规范、迭代效率、单词列表 UI
**Context:** pnpm monorepo (Turborepo)，React 18 + Vite + TypeScript + Tailwind v3 + antd 5.x。当前样式方案混杂（5种并存），无 Prettier，内联 style 泛滥，单词列表列过多需横向滚动

## Techniques Used

1. SWOT Analysis — 评估当前状态
2. SCAMPER — 生成创造性改进方案
3. Reverse Brainstorming — 识别失败路径

## Ideas Generated

### Category 1: 样式架构（3 层规则）

- 布局/间距/颜色 → Tailwind class
- antd 组件定制 → ConfigProvider theme token + antd-style createStyles
- 禁止内联 style={{}}（仅允许动态计算值）
- 删除普通 CSS 文件，迁移到 Tailwind + antd-style
- 引入 clsx 统一 class 拼接

### Category 2: 代码规范落地

- 引入 Prettier + .prettierrc
- ESLint 规则渐进收紧（先 warning 后 error）
- 添加 lint-staged + husky pre-commit hook
- 建立 @font/ui 组件开发规范文档

### Category 3: 单词列表 UI 重构

- 列可见性切换（核心列常驻：序号/单词/释义/掌握程度/操作）
- 紧凑/舒适密度切换
- 掌握程度颜色边条（行左侧色条）
- 弹性高度（flex: 1 + overflow: auto）替换硬编码 calc
- 移动端卡片布局
- 单词列点击跳转百度 → 改为内嵌详情面板

### Category 4: 迭代效率提升

- 提取通用 hook：useEnumMap、useFilterForm
- 提取通用组件：FilterField、DensitySwitch → @font/ui
- dayjs 替代 moment
- 统一格式化函数模块 formatters.ts
- FormFieldGroup 提取到 @font/ui

## Key Insights

### Insight 1: 样式方案分层治理

**Description:** 三层层级——布局用 Tailwind，组件定制用 antd-style，全局主题走 ConfigProvider
**Source:** SWOT + SCAMPER
**Impact:** High
**Effort:** Medium
**Why it matters:** 解决 5 种样式方案混用的根本问题，后续开发者有明确规则可循

### Insight 2: 先规范后重构

**Description:** 先落地 Prettier + lint-staged 作为基础设施，再逐步重构代码
**Source:** Reverse Brainstorming
**Impact:** High
**Effort:** Low
**Why it matters:** 没有工具保障的规范是空话，先建护栏再修路

### Insight 3: 单词列表可配置化

**Description:** 列可见性切换 + 密度切换 + 弹性高度，让表格自适应使用场景
**Source:** SCAMPER (Adapt + Modify)
**Impact:** Medium
**Effort:** Medium
**Why it matters:** 解决"UI 太丑"和"列太多"两个问题，用户可自定义显示

### Insight 4: 弹性布局替换硬编码

**Description:** 用 CSS flex 自然填充替换所有 calc(100vh - ...) 硬编码
**Source:** SCAMPER (Substitute)
**Impact:** Medium
**Effort:** Low
**Why it matters:** 一处改全局生效，不再因 header 高度变化而到处调 calc

### Insight 5: 统一格式化层

**Description:** 枚举映射、时间格式、Tag 颜色全部收敛到 formatters.ts
**Source:** SCAMPER (Combine)
**Impact:** Medium
**Effort:** Medium
**Why it matters:** 减少重复代码 60%+，新增字段只需加一行配置

### Insight 6: 分阶段交付

**Description:** 每阶段 ≤ 2 天工作量，独立 PR 可合入，降低回归风险
**Source:** Reverse Brainstorming
**Impact:** High
**Effort:** N/A (流程约定)
**Why it matters:** 避免长分支地狱，每阶段可独立 review 和测试
