# 雅思听力规格

Feature: review/ielts-listening。来源：docs/prd/review/features/ielts-listening/prd.md及docs/design/review/ielts-listening/design.md。用户授权审核后研发，指定Inspera原型；PRD本轮修订解决题源/范围/设备/入口默认值。

## 场景

- S01：学生选择部分和题型创建个人AI原创材料，主题选填且默认空。未指定时服务端按Part/题型选取合适场景，整套分别选题并保存供重试复用；指定时使用用户主题，仍受Part形式与质量门禁约束。四部分逐一准备，每部分10分；失败保留已完成部分并可重试。答案与台词在服务器保存，准备完成后公开题目投影。
- S02：结构门禁验证题数、编号、文本限长、填空映射、选项、地图坐标与答案，地图以同一服务端场景图生成路线/题位/答案并确定性验证，AI复核名称与背景；其他材料独立AI复核实际台词与题干一致性；不合格拒绝使用。
- S03：学生选择训练或模拟创建尝试。开始前音频可用；训练可重播慢速，模拟逐段一次，结束后120秒检查；音频或刷新中断永不标严格完成。
- S04：六题型使用稳定编号作答；保存与标记带版本，旧写入被拒绝。地图SVG不执行AI HTML，select和文字输入可用。
- S05：交卷冻结当前答案；服务器按固定评分键与限词规则计分，幂等保留结果。多选组按选项集计分但重复选项不得得分。
- S06：结果显示原答案、标准答案、证据和原文。再练创建新尝试，历史结果不变。词库/笔记主动进入现有流程。
- S07：管理员导入原创材料包、发布/停用，已开始的尝试冻结版本；普通用户不能使用管理接口，互查记录拒绝。
- S08：列表、生成失败、保存失败、提交失败、音频错误、无权限和恢复有明确界面；付费调用受既有预算约束。

## 验证与边界

纯规则测试、真实MySQL/API隔离测试、浏览器交互和真实供应商分别取证；替身不证明AI质量。无需新的外部服务。官方素材不内置。结构化数据只渲染文本/SVG几何；不接受远程音频URL或可执行HTML。模拟不宣称正式Band或30分钟等效。

## 腾讯云双人音色扩展（2026-10-29）

新生成材料冻结语音供应商；Part 1/3 结构化台词标记 A/B，拼接后必须与校验原文完全一致，材料与评分仍以原文及固定证据为准。地图规划题从同一地图事实生成双人台词并验证路线。Part 2/4 独白使用 YunLeo。腾讯 API 每段不超过 450 字符，按句子边界切分并按原顺序播放；密钥加密且仅管理员可配置，真实调用受限制与缓存保护。旧材料不改变，未完成的测试与上线单独记录。

### 2026-11-01 作答稳定性修订

- 当前路由记录 ID 与已加载记录不一致时只显示读取状态；不得展示旧作答结果及其解析、原文。
- 连续换段不插入会使题纸位移的进度行；浏览器换源发出的暂停事件不覆盖换段中的播放状态。真实失败仍可见并可恢复。
- 复盘分为答题解析、原文、回听三个区域，默认解析；只有已交卷才挂载复盘，切换区域暂停回听。
- 题纸与导航参考用户 Inspera 样题；官方格式来源及本站训练设计区别见 docs/design/review/ielts-listening-usability/design.md。


## 2026-11-04 多样性修订（用户已批准研发）

来源：正式PRD FR17–20/AC15–18；docs/design/review/ielts-listening-diversity/design.md。此修订替代旧S02固定地图与混合配比，保留其他S01–S08以及历史ready/pending材料兼容。

- S09（FR17/AC15）：每Part三套以上混合方案，10计分位且多选成组，专项不换类型。新增表格category和流程stage只含题面结构，不含答案；存在真实分类/阶段且服务端验证、公开投影白名单、前端语义呈现。
- S10（FR18/AC16）：八张空间图分四家族，每张支持route/landmark/relative；受控英语由空间事实产生，校验几何、入口、唯一路线和答案，AI仅补不矛盾背景。所有地图与既有导入形状继续渲染。
- S11（FR19/AC17）：使用owner最近20份document摘要，组合/主题按最久未用选择，规范化内容查重于配音前；校准样本记录误拒/误放，高相似候选额外语义核对（仍消耗既有上限），拒绝保留原因但不自动额外付费。
- S12（FR20/AC18）：创建短事务锁user行，先命中requestId后分配sectionPlans，付费生成不持锁；旧草稿付费前补方案，已pending材料不替换。公开material只保留题面字段，不输出方案、历史摘要及答案。

验证：Jest规则/服务，真实MySQL隔离API并发/幂等/拒绝配音断言，React语义结构与浏览器图面；真实供应商与试听单列，不以替身证明质量。工程实现与任务见docs/superpowers/plans/2026-11-04-ielts-listening-diversity.md。
