# Feature Specification: 知识笔记 MCP

featureId: notes/mcp-notes · changeId: 2026-10-28-mcp-notes · 2026-10-28
来源：docs/prd/notes/features/mcp-notes/prd.md；用户本轮明确授权完整研发，复用此前确认的行为。

## User Scenarios & Testing
### US1 (P1) 查询与直接归档
读取当前用户笔记和文件夹；AI选择已有合适目录，新建笔记后可在网站读取同一条记录。保留中文、Markdown、例句、来源、关联词。
### US2 (P1) 先确认再建立文件夹
没有合适目录时展示建议名称与父目录；预览不创建。收到用户明确同意后创建，再按US1保存。拒绝时不创建。语义选择由客户端AI负责，不声称服务端自动分类质量。
### US3 (P1) 笔记修改先预览确认
展示完整旧值、新值及变化字段；确认后仅应用预览内容，保留ID并递增版本。取消不写入。其他设备修改后须重新预览。
### US4 (P1) 安全与兼容
独立笔记权限；旧词库授权不自动获得笔记权限；跨账号不可见。过期/撤销/跨授权/跨动作确认拒绝；重复请求不重复写入。既有词库功能保持兼容。

## Requirements
- 继承正式PRD全部FR/AC，见同目录traceability.json；查询分页、关键词、分类、文件夹与关联词过滤。
- 新建笔记必须指向已有且属于本人的文件夹；不接受隐式建目录；修改可改变目录但仍须确认。
- 新建文件夹与笔记修改的预览有效10分钟；确认字段为true，凭证绑定账号、授权、动作和不可变负载。
- 标题120、正文30000、例句10000、来源1000、关联词最多20，沿用既有笔记分类。
- 无变化拒绝；失效目标、版本冲突、无权限、非法输入不产生业务写入。
- 测试使用一次性MySQL和合成账号；浏览器Cloud与SDK协议证据分开。

## Key Entities
笔记（用户/版本/文件夹/关联词）、文件夹（用户/父目录）、独立授权、预览、幂等操作和审计摘要。

## Success Criteria
1. 已有目录保存后笔记正文与归属一致，无重复记录。
2. 未确认新建目录或修改，业务数据零变化。
3. 确认重试只生效一次，旧版本确认零覆盖。
4. 非本人和未授权访问全部拒绝；原词库专项无新增回归。

## Assumptions
工程选择：四个笔记权限（读/新增/修改/建文件夹）；本次无删除工具；沿用现有授权管理界面，仅扩展权限选项及操作说明，不改变布局。真实AI的目录判断及用户是否同意，仍由客户端对话负责。
