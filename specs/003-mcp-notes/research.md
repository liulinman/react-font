# 技术决策与现状核对

- 复用已安装官方MCP SDK 1.26.0和现有无会话Streamable HTTP入口，不引入第二个MCP服务或OAuth。
- 复用KnowledgeNoteService，新增可选共享事务参数，HTTP原调用保持独立事务；MCP操作采用READ COMMITTED以避免等待用户文件夹锁前建立旧快照。
- 沿用用户文件夹互斥行，使网页与MCP目录/归属写入串行；确认还核对笔记版本与已展示的前后路径。
- 新增mcp_note_preview表避免把笔记目标塞入词库word_id；新增scope不改旧授权记录，迁移可重入。
- 文件夹重名按实际MySQL utf8mb4_unicode_ci比较。预览与确认间若出现完全同名目录，可复用该已有目录；排序等价但展示名不同则要求重新选择，不替换用户已见名称。
- 无外部AI调用；目录语义选择和人类确认由客户端负责，不能以服务器布尔参数证明。
