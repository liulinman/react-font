# 教师端课堂与阅读作业

来源：[课堂 PRD](../../docs/prd/classroom/features/teacher-classroom/prd.md)和[用户确认的 r03 原型](../../docs/design/classroom/teacher-classroom/design.md)。

- S1（FR-01～04，AC-01～03）独立教师端使用 Freewing 账号，管理员开通教师资格。老师只能管理自己的班级。登录学生通过有效邀请直接入班，重复访问只创建一条成员记录。链接由教师主动轮换。
- S2（FR-05～08、FR-10，AC-04、05、07、09）课堂阅读练习复用现有导入、生成、审核、作答与分发服务。发布前确认班级有效成员，服务端校验同一名单并拒绝班外分发。
- S3（FR-09、11，AC-06、08、10）老师补发已发布作业给本班成员，分配与已有成绩分别保存。成绩页复用阅读统计口径。
- S4（FR-12、AC-11）群聊仅对教师和已入班学生开放。消息按服务端顺序读取，同一用户同一请求标识最多一条，失败可用原标识重试。

本轮采用独立授权表，邀请持续有效直到轮换，首期提供发文字和表情。成员退出、移除、教师撤回与逐题统计按 PRD 待决范围处理。
